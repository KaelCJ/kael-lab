01 · HUMAN FIRST

技术品牌的起点，
是人的真实目标。

Lanox 不从模型清单开始，而从目标、授权、判断和可验证结果开始。Agent 的价值，是让人的意图更快变成可信行动。

BRAND PRINCIPLEHuman-centered. Agent-powered. Evidence-backed.

人定义方向，Agent 提供执行，证据支撑判断。

02 · GENERAL AGENT

第一类产品，
让执行可观察。

Codex Workbench 从本机工作目录与 Session 出发，组织 Thread、Turn 和流式事件，并向可恢复、可授权与持续运行演进。

PRODUCT VALUE看得见正在做什么，也知道如何继续。

停止、关闭、历史和交付边界必须清楚。

03 · VERTICAL PRODUCTS

第二类产品，
让领域能力可使用。

Nest 知识库让答案回到可靠来源；创意领域 Agent 把创意方法变成可恢复、可签收的生产流程。更多领域产品可沿同一边界演进。

VERTICAL KNOWLEDGENest 知识库

目录、文档、问答、来源与追问。

VERTICAL AGENT · BUILDING创意领域 Agent

方法、生产、恢复与交付。

04 · FRAMEWORK

共享的是运行能力，
不是产品灵魂。

Agent Framework 提供 Session、Context、Checkpoint、能力端口和执行证据。领域方法、用户流程和最终装配仍属于各自产品。

FRAMEWORK RULE复用基础，保留产品差异。

Framework 不能吞并领域语义，也不能成为所有模块的组合根。

05 · ENTERPRISE DEPTH

工程深度，
通过真实 Agent 形成复利。

Jugg / Nest 的治理、知识、组件和场景经验进入 Agent 产品，被真实任务消费、验证和回流，企业能力才从库存变成持续价值。

COMPOUNDING LOOP能力 → 产品消费 → 运行证据 → 知识校准

没有真实消费和证据，资产数量不等于产品价值。

06 · TRUST

最后一层竞争力，
是可以被信任。

模型、数据和运行提供基础，安全身份与可观测效果横切全栈。品牌承诺最终必须落到稳定、成本、质量、证据和真实用户结果。
