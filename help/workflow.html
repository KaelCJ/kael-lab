START OR CONTINUE

真实使用时，你只需要从这三句话开始

新目标：创建

NEW

先查重，再建立唯一目标；先整理，不默认实施。

为这个目标创建工作项。先查是否已有同一目标；保存我的原始表达，整理当前需求和验收标准。先不要修改代码。

旧目标：继续

RESUME

编号、代办或代码现场都可以进入，但先回读当前事实。

继续 W-<编号>。回读当前需求、方案、执行记录、测试证据和工作树，再告诉我准确恢复点；暂不修改。

本轮：授权

SCOPE

查看、修改、验证、提交和发布不是一件事。

允许修改帮助页并做本地浏览器验证；不要修改产品源码，不要提交或发布。范围变化时先停止并说明。
WORK ITEM ANATOMY

同一个工作项里，每类事实由谁负责

固定的是职责，不是文件数量。简单任务可以很短，复杂目标在所属目录继续拆分。

README

当前入口

简介与产物导航；不复制完整状态和正文。

SOURCE / REQ

为什么做

原话保留纠正历史；需求维护当前范围与 AC。

SOLUTION

怎样满足

方案、取舍、代价、反例、影响和回退。

EXECUTION

实际做了什么

计划、真实动作、偏差、失败与恢复点。

TEST

怎样证明

自动检查、真实测试、人工确认分开。

OUTPUT

交付给谁

人最终使用、审阅或发布的真实产物。

STATUS

是否仍是代办

进行中或完成；完成不等于质量或发布。

ARCHIVE

是否移出活动区

可恢复移动，不是完成、删除或清空。

SESSION HYGIENE

Session 太长时怎样收口

先把稳定事实写回

PERSIST
  • 用户补充与纠正进入来源
  • 当前范围和 AC 更新需求基线
  • 确认的取舍进入方案
  • 真实动作、失败和恢复点进入执行
  • 检查与测试证据进入测试入口

再手动做归档检查

MANUAL

调用 $nest-archive-check，检查 Session 事实是否唯一归属、编号与目录是否唯一、引用是否冲突、目标是否仍未完成。适合时才归档；需要继续时恢复原工作项。

ROADMAP
未来可以自动提醒

当前仍是手动触发。自动提醒不能擅自执行物理归档或删除。

THE RULE
AI 负责扩大执行能力，人负责保持目标和判断主权

流程不是为了增加表格，而是让 Agent 可以更大胆地自动执行，同时让任何人都能知道它为什么做、做到哪里、什么失败了、什么仍要人决定。
