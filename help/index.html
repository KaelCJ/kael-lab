WORK ITEM BASICS

任何正式协作，先创建或绑定唯一工作项

聊天是本轮交互，工作项才是可恢复的目标上下文。它让下一个 Session 知道为什么做、确认了什么、已经做了什么、什么还没证明。

第一次：查重后创建

ENTRY 01

说清目标，并要求先查现有工作项。同一目标已经存在时继续原编号，不新建竞争项。

为“优化知识问答来源体验”创建工作项。先查重；整理原始需求、当前需求与验收标准，暂不修改代码。

回来继续：三种入口

先把稳定事实写回唯一工作项，再检查编号、目录、引用和未完成目标。它不是清空上下文按钮；自动触发仍是未来方向。

PRODUCT GUIDE · EXECUTION

Codex Workbench：让一次 Agent 执行可观察

工作目录决定事实边界，Session 是运行连接，Thread 保存多轮任务上下文，Turn 是一次具体输入。停止 Turn 与关闭 Session 不是同一动作。

01 · WORKDIR

选择工作目录

确认它就是本轮项目。帮助页不会读取本机路径。

02 · SESSION

建立运行连接

连接成功不代表 Thread 已创建或任务已完成。

03 · THREAD / TURN

继续上下文

新目标创建 Thread；一次 Turn 说清目标、范围和不做项。

04 · EVENTS

观察与停止

看状态、文本与工具动作；需要越权或证据不足时停止。

先读取项目入口并查看当前工作树，只报告与当前目标相关的事实；不要修改文件、提交或发布。
