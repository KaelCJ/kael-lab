# 性能基准测试指南

## 测试准备

1. **启动游戏**：在浏览器中打开 `game/static/dotarogue/index.html`
2. **打开控制台**：按 F12 或右键 → 检查 → Console
3. **启用性能监控**：在控制台输入 `enablePerfStats()`
4. **查看监控数据**：每秒会在控制台打印一次性能表格

## 监控指标说明

| 指标 | 含义 | 优化目标 |
|------|------|----------|
| FPS | 每秒帧数 | 60 |
| Enemies (ms) | 敌人更新耗时 | < 2ms |
| Bullets (ms) | 子弹更新耗时 | < 3ms |
| Skills (ms) | 技能更新耗时 | < 2ms |
| BaseAttack (ms) | 普攻更新耗时 | < 1ms |
| Render (ms) | 渲染耗时 | < 8ms |
| Total (ms) | 总帧时间 | < 16.67ms (60 FPS) |

## 测试场景

### 场景 1：初期（1-5 波）

**目标状态**：
- 敌人数：10-20
- 子弹数：5-10
- 特效数：10-20

**操作步骤**：
1. 选择任意英雄进入游戏
2. 完成第 1-5 波战斗
3. 在第 3 波和第 5 波记录性能数据

**记录模板**：
```
场景 1 - 第 3 波
FPS: ___
Enemies (ms): ___
Bullets (ms): ___
Total (ms): ___
```

### 场景 2：中期（10-15 波）

**目标状态**：
- 敌人数：40-60
- 子弹数：15-25
- 特效数：30-50

**操作步骤**：
1. 继续游戏到第 10-15 波
2. 在第 10 波和第 15 波记录性能数据

### 场景 3：后期（16-20 波）

**目标状态**：
- 敌人数：80-100
- 子弹数：25-40
- 特效数：50-80

**操作步骤**：
1. 继续游戏到第 16-20 波
2. 在第 18 波和第 20 波记录性能数据

### 场景 4：Boss 战

**目标状态**：
- Boss + 小怪：1 + 50
- 子弹数：30-50
- 特效数：100+

**操作步骤**：
1. 在 Boss 战斗中记录性能数据
2. 特别关注技能密集释放时的表现

## 测试建议

- **浏览器**：使用 Chrome 进行测试（DevTools 性能工具最完善）
- **分辨率**：桌面测试使用 1280×720 窗口
- **背景应用**：关闭其他标签页和应用，避免干扰
- **多次测试**：每个场景至少测试 2 次，取平均值
- **不同英雄**：测试 2-3 个不同英雄（如 Bulwark、Conductor、Luna）

## 关闭监控

测试完成后，在控制台输入 `disablePerfStats()` 关闭监控。
