### ✅ 优化 1.2：数组操作优化

**实施内容：**
- 将 `filter().sort()[0]` 模式改为线性查找最小值
- 避免创建临时数组和完整排序的开销

**优化位置：**
1. `game.js:2911` - 闪电链目标查找（Mjollnir）
   ```javascript
   // 优化前：filter + sort + [0]
   current = run.enemies.filter(...).sort(...)[0];
   
   // 优化后：线性查找
   current = null;
   let minDist = 190;
   for (const e of run.enemies) {
     if (e.dead || struck.has(e)) continue;
     const d = distance(e, from);
     if (d <= minDist) { minDist = d; current = e; }
   }
   ```

2. `game.js:3001-3014` - 瞄准目标查找（getTarget）
   - 两处 filter+sort 改为线性查找

**预期效果：**
- 减少数组分配和排序开销
- 预计 FPS 提升 10-15%

**验证状态：** ⏳ 待实际测试

### ✅ 优化 1.3：敌人死亡清理优化

**实施内容：**
```javascript
// 优化前：创建新数组
run.enemies = run.enemies.filter(e => !e.dead);

// 优化后：原地删除
for (let i = run.enemies.length - 1; i >= 0; i--) {
  if (run.enemies[i].dead) {
    run.enemies.splice(i, 1);
  }
}
```

**受影响位置：**
- `game.js:2789-2795` - updateEnemies 结束时清理

**预期效果：**
- 减少内存分配和 GC 压力
- 后期大量敌人死亡时效果明显

**验证状态：** ⏳ 待实际测试

### ✅ 性能监控系统

**实施内容：**
- 添加性能监控框架，默认关闭不影响性能
- 通过 `window.enablePerfStats()` 启用
- 每秒输出一次性能表格：FPS、各子系统耗时
- 通过 `window.disablePerfStats()` 关闭

**监控指标：**
- FPS（帧率）
- Enemies (ms) - 敌人更新耗时
- Bullets (ms) - 子弹更新耗时
- Skills (ms) - 技能更新耗时
- BaseAttack (ms) - 普攻更新耗时
- Render (ms) - 渲染耗时
- Total (ms) - 总帧时间

**使用方法：**
```javascript
// 启用监控
enablePerfStats()

// 关闭监控
disablePerfStats()
```
