# 性能优化快速验证指南

## 🎮 快速启动验证

### 1. 启动游戏（1 分钟）

```bash
# 游戏已在后台运行
# 打开浏览器访问：http://localhost:8000/game/
```

### 2. 启用性能监控（立即）

打开浏览器控制台（F12），输入：

```javascript
window.enablePerfStats()
```

每秒会输出性能表格：

```
┌─────────┬────────┬────────┬────────┬────────┬────────┐
│  FPS    │Enemies │Bullets │Skills  │Render  │Total   │
├─────────┼────────┼────────┼────────┼────────┼────────┤
│  58.3   │  3.2ms │  1.8ms │  1.1ms │  4.5ms │ 12.4ms │
└─────────┴────────┴────────┴────────┴────────┴────────┘
```

### 3. 核心验证（5 分钟）

**测试 1：基础功能（2 分钟）**
1. 选择任意英雄（如 Kael）
2. 进入第 1 波游戏
3. 检查：
   - ✓ 移动流畅（WASD）
   - ✓ 攻击正常（鼠标点击）
   - ✓ 子弹正常命中敌人
   - ✓ HUD 正常显示（HP、Mana、经验）

**测试 2：后期性能（3 分钟）**
1. 使用作弊码快速到第 15 波（如果有）或正常游玩
2. 观察性能监控输出
3. 检查：
   - ✓ FPS ≥ 50（目标：60）
   - ✓ Bullets (ms) < 3ms（空间分区效果）
   - ✓ 游戏流畅，无明显卡顿

## 🐛 常见问题排查

### 问题 1：游戏无法启动

**可能原因：**
- JS 语法错误
- 模块导入失败

**排查：**
```javascript
// 检查控制台是否有错误
// 查看 Network 标签，确认所有资源加载成功
```

### 问题 2：子弹不命中敌人

**可能原因：**
- 空间分区查询半径不足
- 对象池重置不完整

**排查：**
```javascript
// 检查空间分区是否工作
console.log('Spatial Grid active:', !!run.spatialGrid);

// 检查子弹属性
console.log('Sample bullet:', run.bullets[0]);
```

### 问题 3：FPS 未达到预期

**可能原因：**
- 浏览器限制
- 其他后台进程占用资源

**排查：**
- 关闭其他浏览器标签
- 使用 Chrome Performance 工具分析瓶颈
