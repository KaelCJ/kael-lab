# 众神之王 · 音效设计

> 设计状态：Concept / 待实现
> 当前项目使用 Web Audio 原创合成；本文件先记录事件、节奏和音色，不代表已有音频文件。

被动用短促静电噼啪和空间颗粒声；主动先给全场低频轰鸣，再叠加落雷尖峰与尾部余响。

## 事件清单

| 事件 | 建议事件 ID | 设计要求 |
| --- | --- | --- |
| 被动触发 | conductor-passive | 短、清楚、不能盖过武器声。 |
| 主动施放 | conductor-active | 施放起音要和其他角色区分。 |
| 主动持续 / 命中 | conductor-active-hit | 对密集命中限流，保留节奏层次。 |
| 受击 | conductor-hurt | 与技能声分离，保持低音量。 |
| 台词 | conductor-voice-* | 可关闭；无台词时玩法信息仍完整。 |

音效不复制 Dota、Warcraft 或其他作品的采样、旋律和语音。
