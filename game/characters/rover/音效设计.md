# 矮人火枪手 · 音效设计

> 设计状态：Concept / 待实现
> 当前项目使用 Web Audio 原创合成；本文件先记录事件、节奏和音色，不代表已有音频文件。

被动用细短的瞄准确认音；主动用一次装填咔嗒、短促后坐力和七个分层弹丸声。整体以矮人火枪的金属机械质感为主。

## 事件清单

| 事件 | 建议事件 ID | 设计要求 |
| --- | --- | --- |
| 被动触发 | rover-passive | 短、清楚、不能盖过武器声。 |
| 主动施放 | rover-active | 施放起音要和其他角色区分。 |
| 主动持续 / 命中 | rover-active-hit | 对密集命中限流，保留节奏层次。 |
| 受击 | rover-hurt | 与技能声分离，保持低音量。 |
| 台词 | rover-voice-* | 可关闭；无台词时玩法信息仍完整。 |

音效不复制 Dota、Warcraft 或其他作品的采样、旋律和语音。
