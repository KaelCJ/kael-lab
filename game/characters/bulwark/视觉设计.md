# 刚背兽 · 视觉设计

> 设计状态：首图 PNG 为 Concept；可编辑 SVG 源图与 9 张静态运行帧已接入游戏，真实动作验证记录在角色总 README 与工作项。

## 第一阶段：精致手绘卡通单角色图

首图保留精致 2D 手绘卡通小角色方向，参考 Kingdom Rush 的小尺寸辨识与表现；War3／DotA1 原型可作为精确轮廓与动作回源。此前 32×32 像素 SVG 仅作历史方案，当前运行使用分层 SVG 与静态动作帧。

刚背兽按 DotA1 的 Rigwarl / Bristleback 野猪人原型重新绘制：粗壮兽躯、野猪口鼻与獠牙、宽厚背部密集刚毛。最关键是厚背棘刺剪影，服务于被动“刚背”的后背减伤与主动“刚毛齐射”的表现。

略俯视三分之四视角，转身露出大半背部，头部回看使脸和獠牙仍可辨；头在上、双脚在下，全身居中，尖刺与身体周围保留少量透明边距。深色轮廓、夸张但有力量感的比例、少量明暗分组优先于细碎毛发。本图不额外增加手持武器，以身体与天然刚毛表达战士身份。

当前 PNG 按刚背兽的 War3／DotA1 原型重绘；后续允许精确参考或接入已核对许可的外部角色资源。输出真正透明背景 PNG，无文字、UI、水印、场景或地台。

首图已通过用户授权的 Lanox Image2 生成。当前审阅图为 [bulwark-idle-v1-clean.png](art/concept/bulwark-idle-v1-clean.png)，透明背景来自本地色键去除，并非模型原生透明；[原始生成图](art/concept/bulwark-idle-v1-source.png) 与初次透明处理版本都已保留。完整提示词、实际提交文本和制作状态见 [bulwark-idle-v1.prompt.md](art/concept/bulwark-idle-v1.prompt.md)。

已查看原图、透明图和 128px／64px 预览：野猪脸、两枚獠牙、厚躯与刺背可辨，全身及主要尖端完整，无明显洋红背景残块或大面积误删。初次 alpha 处理的画布边角残留半透明灰点，已仅清理背景像素后另存 clean 版；原先不透明的角色像素没有改变。

当前 Concept 的已知表现边界：视角偏三分之四背侧，俯视感较弱；毛发与棘刺细节比目标小角色更密，64px 下眼睛、皮带和细毛合并，远侧手臂辨识减弱。少数尖刺和獠牙外沿仍可见极细的偏黄绿／暗色边线，需在后续实机背景中复核。

## SVG 待机运行资源

[bulwark-hero.svg](art/runtime/bulwark-hero.svg) 使用可编辑 256×384 分层矢量：野猪口鼻、双侧獠牙、粗壮兽躯与背部刚毛形成可辨轮廓。`hero-motion` 和 `hero-body` 提供呼吸与重心摆动，`hero-weapon` 让天然背刺扇轻摆，`hero-accessory` 提供腰间亮点。源图的 SMIL 只用于编辑预览；Canvas 使用无 SMIL 的 `idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、攻击三阶段和 `skill` 静态帧，主动技特效由 `game.js` 绘制。
