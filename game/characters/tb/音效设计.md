# 灵魂守卫 · 音效设计

当前已接入 Web Audio 合成事件，角色没有独立音频或语音文件。不引入 Warcraft／DotA 的采样、台词或旋律。

| 事件 | 当前实现与后续方向 |
| --- | --- |
| 双刃普攻 | 沿用 `blade` 合成音，视作一轮攻击，不因双刃造型多算两次命中。 |
| 恶魔变身 | `skill-tb`：锯齿波 85→210Hz 与三角波 420→95Hz 组合，绑定成功施法。 |
| 邪能弹 | 沿用 `pulse` 合成音；没有另行导入音频采样。 |
| 魔影出现 | `tb-image`：正弦波 380→710Hz，绑定生成／刷新魔影事件。 |
| 魔影消失／还原 | 独立收尾音仍为 Concept；当前没有专用事件。 |

上述属于源码接入事实，没有声音听测结论。音量、同屏叠加、静音与暂停恢复的验证边界统一见 [游戏 README](../../README.md)；台词仍按 [台词](台词.md) 的 Concept 状态保留。
