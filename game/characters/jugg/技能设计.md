# 剑圣 · 技能设计

> 设计状态：Concept / 待实现
> 技能槽固定为一个主动和一个被动；当前游戏仍是四技能结构，接入前不能把本稿写成 Current。

## 被动：跃空斩

- 方式：被动
- 规则：每 5 次有效近战攻击准备一次跳劈；锁定 260 范围内最近敌人，跃起后落地造成半径 60 的物理伤害 24 + 近战伤害加值 ×1.0，并获得 0.28 秒短暂无敌；触发间隔不低于 3 秒。

## 主动：剑刃风暴

- 方式：主动
- 规则：持续 2.2 秒，半径 138，每 0.2 秒造成 8 + 近战伤害加值 ×0.35 的范围物理伤害；期间移速 +20%、接触伤害降低 35%；冷却 14 秒。

## 联动与操作

被动自动记录战斗状态，主动技能保留 Q 键和触控按钮入口。数值是第一版平衡起点，须在真实波次中验证后再进入当前实现文档。
