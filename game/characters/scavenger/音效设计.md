# 炼金术士 · 音效设计

> 设计状态：Concept / 待实现
> 当前项目使用 Web Audio 原创合成；本文件先记录事件、节奏和音色，不代表已有音频文件。

被动用硬币落入玻璃瓶的轻响和短促确认音；主动用玻璃瓶晃动、投掷破裂、腐蚀气泡和低沉持续音。整体使用地精工坊的金属、玻璃和化学气泡质感。

## 事件清单

| 事件 | 建议事件 ID | 设计要求 |
| --- | --- | --- |
| 被动触发 | scavenger-passive | 短、清楚、不能盖过武器声。 |
| 主动施放 | scavenger-active | 投瓶起音和破裂声要清晰。 |
| 主动持续 / 命中 | scavenger-active-hit | 腐蚀脉冲限流，避免连续噪声。 |
| 受击 | scavenger-hurt | 与化学音效分离，保持低音量。 |
| 台词 | scavenger-voice-* | 可关闭；无台词时玩法信息仍完整。 |

音效不复制 Dota、Warcraft 或其他作品的采样、旋律和语音。
