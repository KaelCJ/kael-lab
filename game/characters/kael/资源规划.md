# Kael（召唤师）· 资源规划

> 状态：Current（SVG 角色帧及风、陨石模块已接入）

Kael 当前使用已接入运行时的 SVG 角色帧和 Canvas 程序化法术特效，不依赖技能图标或音效文件。资源规划保留后续美术与音频协议；灰色“未开放”头像仍不能冒充已完成角色资源。

## 运行资源

- 目录中保留血精灵前视、侧身分层源图及各 9 张静态动作帧；`HERO_ART`／`HERO_POSE_ART` 映射无球战斗帧，`kael-portrait.svg` 是带三球的标题头像。战斗三球由 `drawKaelOrbs()` 按游戏时间在身体前后绘制；脚点、尺寸、减动效与重生成见[视觉设计](视觉设计.md)。保持 `kael` 运行 ID 不变。
- 当前 Kael 地面角色、技能姿态和六个当前法术战场特效分别由 SVG 运行帧与 Canvas 程序效果表达；后续替换资源时保持 `kael` 运行 ID 和技能状态契约。寒冰之触、幽灵漫步、灵动迅捷、阳炎冲击仅保留在历史设计记录，不属于当前资源目录或随机池。

- 混沌之风已消费 `js/game/effects/wind.js` 及 `game/art/effects/wind/` 下的 SVG 碎叶／气流片、PNG 尘雾，与独立风预览共用。两套战斗主题使用同一模块；缓存、脚点、时间、失败回退与具体消费者契约见[通用战斗特效](../../core/通用战斗特效.md)。
- 混沌陨石已消费 `js/game/effects/meteor.js`，由程序化岩壳、裂缝、阴影与 `fire.js` 组合；烟纹理复用 `game/art/effects/fire/png/smoke.png`，不复制到角色目录，也没有新增陨石位图。游戏页缓存一个组合渲染器，未就绪或失败时使用简化岩石；预览新增陨石并默认选中，单独管理自己的缓存。位移、时间、抬升、两主题排序、减动效与生命周期统一回源[陨石契约](../../core/通用战斗特效.md)。当前六项法术共用正式技能实现；四项历史候选不创建新的资源条目。

## UI 与音效

- 当前 HUD 使用文字技能槽和“最近法术”状态，暂停页可读六个当前法术池的文字说明；独立图标仍待制作。
- 随机成功与主动回响目前共用合成音色并通过提示符号区分；专属音色仍待制作，不能把现有英雄音效登记为 Kael 专属音效。

后续美术资源接入后仍须从 `games.html` 进入，在桌面、390×844 竖屏和 844×390 横屏复核角色头像、静态资源、随机被动、主动重放、技能姿态、焦点、控制台和横向溢出。本轮已真实核对选人、初始禁用、被动结果、主动回响、暂停法术池和两种移动视口布局；六项当前法术逐一触发、地图主题矩阵、长局和真实手机硬件仍单独列为未覆盖。

新版混沌陨石另完成预览、桌面及触控模拟的自然施放与主动回响、暂停、两主题和转屏短流程，证据见[游戏 README](../../README.md)。未覆盖全部地形／遮挡组合、战斗简化岩石回退、完整战斗减动效、真实手机与长局性能；已有其他法术记录不扩大上述结论。
