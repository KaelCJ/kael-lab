# Kael（召唤师）· 视觉设计

状态：Current（血精灵造型与三元素球已接入）。真实流程的验证范围见[游戏 README](../../README.md)，素材接线见[资源规划](资源规划.md)。

## 用户确认的身份特征

以 Warcraft III／DotA1 的血精灵卡尔为原型：金色长发、修长尖耳、白皙面孔、红金高领法袍与披风；冰蓝、雷紫、火橙三颗元素球独立悬浮于头顶周围。用发色、尖耳、长袍和三球在小尺寸下共同表达身份。原蓝甲、白胡须、长杖与腰部光环已退出。

当前 SVG 是按上述特征在仓库重绘，未带入官方模型、贴图或音频。名称与种族回源[英雄资料](../../../dota/英雄.md)；未改变六项当前法术的随机与回响施法规则，也不把三颗装饰球解释成可操作的元素配方。

## 源图、运行帧与头像

两张 256×384 分层源图为 `art/runtime/kael-hero.svg`、`kael-side.svg`，脚点约 (128,366)，头与身体保持同一视口；三球在独立 `#kael-orbs` 组。前视与右向侧身各生成9张静态战斗帧，生成时剔除该组。标题网格与详情实际消费另生成的 `kael-portrait.svg`，保留三颗静态球。共两源图、18帧与1头像，源图不直接充当战斗帧。

离线生成器只需对卡尔调用，浏览器不依赖Python：

```text
python -c "from game.characters.build_pose_frames import build; build('kael')"
python -c "from game.characters.build_side_pose_frames import build; build('kael')"
```

手臂、手掌、披风、双腿随既有姿态帧运动；普攻以手势施法，侧身为独立画稿，向左镜像。仍没有独立背面或完整八方向帧。

## 头顶环绕球

战斗的 `drawKaelOrbs()` 属于卡尔角色表现，直接由 `game.js` 的 `drawPlayer()` 消费，不是通用元素攻击特效。每个卡尔恰好三球，相位间隔120度；冰／雷／火使用不同颜色及冰纹、折线、火焰小纹样。

环绕中心在角色局部坐标 (0,-64)，半径横20、纵5，球半径约3.5；为86单位高的现有角色留出额头上方空隙。球按前后深度分别在身体前后绘制，跟随角色位置、起伏与轻微倾斜；抵消身体左右镜像，换方向不反转环绕。球不会进入冲刺残影，不在静态战斗帧中重复出现。

相位读取对局秒数，每秒1.45弧度；暂停或离开战斗后不推进。减少动态效果时固定相位，仍随角色移动。没有独立计时器、随机调用、额外伤害或碰撞；固定3球，不据此声称真实手机或密集场景性能达标。加载失败时原有程序化角色回退也保持金发红袍与三球身份，实际失败流程另列验证范围。
