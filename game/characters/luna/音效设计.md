# 月之骑士 · 音效设计

> 运行状态：Current / Web Audio 技能与弹射事件已接入；语音与细分音效仍属 Concept

当前音效由 [`game.js`](../../../static/js/game/game.js) 原创合成，无独立音频采样文件，沿用游戏音效开关和同事件至少 60 毫秒的触发间隔。

## 当前事件

| 运行事件 ID | 触发 | 合成表现 |
| --- | --- | --- |
| `skill-luna` | 月蚀成功施法，以及每道月光落击 | 780→165 Hz 正弦波，叠加延后 0.08 秒的 1180→420 Hz 三角波，形成银亮下落音。 |
| `luna-bounce` | 第一或第二次弹射实际命中 | 960→360 Hz、0.11 秒的短三角波；两跳共用事件和音量。 |
| `pulse` | 基础月刃出手 | 沿用通用远程基础攻击音。 |

当前没有独立的月蚀预警声、第二跳变调声或 Luna 受击声。落点预警的玩法信息由先于伤害出现的视觉圆环传达；关闭音效后仍可读取。

## 后续声音方向（Concept）

可进一步制作低频月相展开、独立的预警上升音和第二跳较轻的回弹音；实现前不把这些细分事件写成已存在的运行事件。六句原创台词见[台词](台词.md)，目前未录制、未接入。

音效不复制 Dota、Warcraft 或其他作品的采样、旋律和语音。当前源码事件已核对，浏览器短流程不能代替密集敌潮下的完整听感验收。
