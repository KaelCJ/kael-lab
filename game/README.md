# 星核幸存者

《星核幸存者》是 Kael Lab 游戏空间的第一款原创网页游戏。仓库根目录的 `games.html` 是游戏选择入口，本目录的 `index.html` 是这款游戏的游玩入口。后续游戏应有各自的目录与入口，不叠加到本游戏的脚本中。

## 当前实现

- 纯 HTML、CSS、JavaScript 和 Canvas，使用浏览器原生 Web Audio 合成可关闭的原创音效；武器开火、技能、冲刺、受击、宝箱和精英／首领预警按事件使用不同音色，并限制密集战斗音效的触发频率。无服务端、账号、打包步骤或外部运行依赖。
- 俯视角生存肉鸽：20 波敌潮，移动与自动攻击、角色专属技能、冲刺、拾取材料和宝箱、升级选择、波间商店、武器合成与出售、失败和通关结果。波末未拾取材料按 80% 折算货币、经验全额获得；未拾取宝箱自动回收。每波结束先显示本波击败、材料、宝箱和等级结算，并用读秒明确进入宝箱、升级与商店；商店标明下一波编号，点击后再经过“下一波”倒计时才开战。
- 4 名驾驶员、3 个战场、3 档难度、标准与速战两种节奏；极限模式提高敌潮频率、敌人上限与玩家附近最低敌人数。武器、改装和敌人定义位于 `game.js`。三张战场各有固定的树、石头、河流布局和专属像素图。树、石头、河流阻挡角色与敌人移动；敌人会使用流场和局部绕行探测避开障碍，卡住时主动重算路线。树和石头还阻挡飞行弹，河流不阻挡飞行弹。
- 四名驾驶员各有四个开局可用的专属技能：一个主动技、三个自动或被动技。自动技能不再依赖“被打”才触发：装甲匠按附近敌人数持续减伤并自动反击，导电师按电荷自动释放回流，拾荒鸦的护层在持续时间内提供减伤。16 项技能事件会触发角色专属战场反馈；四个主动技另有各自的像素效果图。桌面战斗界面显示四项技能状态；手机竖屏隐藏武器栏和画面切换按钮，武器改在暂停页查看，右侧主动按钮保留冷却秒数。
- 画面提供“像素风／初版”切换：`art/pixel/` 有 105 张原创像素 SVG，覆盖角色、敌人、武器、改装、升级、技能图标与效果，以及三张地图各自的地砖、树、石头、河流、陷阱和选择预览。`art/` 原有 10 张科幻卡通样张构成覆盖不完整的初版；缺图处回退到 Canvas 图形或文字图标。两套画面共用地图布局和碰撞数据，切换不改变玩法。切换在标题、战斗 HUD 和暂停界面可用，画面选择记入本地设置；材料、宝箱、弹丸和其他战斗特效按主题绘制。玩家头部和主体保持直立，以左右镜像和脚步／攻击帧表达动作，子弹与技能按实际攻击方向绘制。动画是少帧姿态与程序反馈，尚无完整多方向逐帧动画。视觉边界与资源协议见 `core/视觉规范.md`。
- 桌面支持 WASD / 方向键移动、右键单击目的地后绕开地形自动前往、Q 主动技能、空格冲刺、Esc 暂停；战斗界面有可见的技能和冲刺按钮。手动移动或冲刺会取消右键目的地。手机横竖屏都使用左侧虚拟摇杆和右侧技能、冲刺按钮，转屏时对局继续。
- `localStorage` 的 `kael-lab-starcore-survivor-v1` 保存音效、画面、节奏、难度、按角色/战场/难度划分的最佳波次及通关次数。正在进行的对局只在当前页面内存中，刷新后不能续局。

玩法借鉴生存肉鸽类型，但名称、角色、场景和表现为本项目原创内容；不是《土豆兄弟》或其 DLC 的官方移植。

## 文件与入口

- `index.html`：标题、选择界面、战斗 HUD、波次结算读秒、宝箱、升级、商店、暂停和结果界面，以及无 JavaScript 提示。
- `game.css`：游戏界面、横竖屏手机布局、触控控件和安全区域适配。
- `game.js`：游戏数据、Canvas 绘制、战斗循环、输入、商店与本地记录。
- `art/`：初版原创科幻卡通 SVG 样张；`art/pixel/` 是当前角色、敌人、武器、改装、升级、技能、地图与陷阱的原创像素 SVG，均可编辑并供静态页面直接加载。
- `core/核心玩法.md`：玩法要素的聚合入口；角色、装备、武器、属性、技能、商店、地图、天赋、掉落与结算分别使用中文命名的文档，区分当前实现与设计目标。
- `core/协作上下文.md`：供新会话读取的已确认设计决定、当前边界与回源顺序；新决定要同步到对应专题。
- `core/界面与交互.md`：当前页面流程、桌面与触控操作、响应式布局和待实现界面。
- `core/视觉规范.md`：主题素材 ID、当前换皮覆盖范围、像素视觉规范和后续史诗奇幻方向。
- `../games.html`：游戏选择页；`../index.html`：Kael Lab 首页。

## 本地运行与检查

在仓库根目录运行静态服务器，例如 `python -m http.server 4173`，打开 `http://localhost:4173/games.html`，再选择《星核幸存者》。游戏页面的物理地址是 `http://localhost:4173/game/index.html`。

修改游戏后，在桌面浏览器和手机横竖屏分别检查：从选择页进入、角色与战场选择、画面切换、开始战斗、键盘/右键/摇杆移动、主动技能与冲刺、拾取宝箱回血、波末自动回收与 80% 货币结算、波次结算读秒与下一波倒计时、逐箱收下或拆解、升级与商店、暂停左侧属性/武器及全部技能进度、手机顶部紧凑状态与主动按钮冷却、转屏继续对局及返回。三张地图分别检查地砖、树、石头、河流、陷阱和预览图；操作角色、敌人、飞行弹及右键绕行核对阻挡规则，并查看角色专属技能反馈。画面切换要在标题、战斗、暂停和实际可到达的结算界面检查资源与布局，并核对当前对局状态不丢失；同时检查音效开关、键盘焦点、控制台错误、静态资源路径及禁用 JavaScript 时的基础说明。商店、后期波次或通关若未实际走到，应如实标明验证范围。

角色姿态检查需覆盖上下左右移动、自动攻击与主动技能：两套画面中头部始终在身体上方，左右镜像不改变攻击方向与命中范围。读秒期间检查 Esc 暂停、恢复，以及页面失焦后暂停；竖屏屏外敌人不能占用可见近场补怪的最低数量。

本轮验证：真实浏览器从游戏选择页进入，在桌面 1280×720、竖屏 390×844 和横屏 844×390 检查战斗与暂停；观察四名像素角色和初版拾荒鸦的移动／攻击姿态。标准和极限均走完速战第一波，覆盖波末统计、读秒暂停／恢复、宝箱、升级、商店、下一波提示与自动进入第二波；赤沙废港实测右键双向绕水。静态路径、DOM 接线、语法和差异检查通过，控制台无错误或警告，无 JavaScript 时说明和返回链接可读。三地图绕障、近场落点与导电师自动技能另做源码函数回归；这些回归不代替实机流程。尚未覆盖 20 波通关、所有角色与地图组合、真实手机硬件，以及窗口失焦读秒的真实切窗操作。

## 新游戏的扩展方式

新游戏创建独立目录和自己的页面资源，在 `games.html` 增加可进入的选择项，并从该游戏返回选择页。为新目录写明玩法、操作、当前实现及局部 Agent 规则；不要把尚未制作的游戏标成可玩。
