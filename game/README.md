# 星核幸存者

《星核幸存者》是 Kael Lab 游戏空间的第一款原创网页游戏。仓库根目录的 `games.html` 是游戏选择入口，本目录的 `index.html` 是这款游戏的游玩入口。后续游戏应有各自的目录与入口，不叠加到本游戏的脚本中。

## 当前实现

- 纯 HTML、CSS、JavaScript 和 Canvas，使用浏览器原生 Web Audio 生成可关闭的音效；无服务端、账号、打包步骤或外部运行依赖。
- 俯视角生存肉鸽：20 波敌潮，移动与自动攻击、角色专属技能、冲刺、拾取材料和宝箱、升级选择、波间商店、武器合成与出售、失败和通关结果。波末未拾取材料按 80% 折算货币、经验全额获得；未拾取宝箱自动回收。主动拾取和自动回收宝箱都会回血，并在波末依次开出永久改装，可收下或拆解为材料。
- 4 名驾驶员、3 个战场、3 档难度、标准与速战两种节奏；武器、改装和敌人定义位于 `game.js`。
- 四名驾驶员各有四个开局可用的专属技能：一个主动技、三个自动或被动技。战斗界面显示技能与主动技冷却；暂停界面左侧显示当前属性和技能。商店通用技能尚未实现。
- 桌面支持 WASD / 方向键移动、右键单击目的地后自动前往、Q 主动技能、空格冲刺、Esc 暂停；战斗界面有可见的技能和冲刺按钮。手动移动或冲刺会取消右键目的地。手机横竖屏都使用左侧虚拟摇杆和右侧技能、冲刺按钮，转屏时对局继续。
- `localStorage` 的 `kael-lab-starcore-survivor-v1` 保存音效、节奏、难度、按角色/战场/难度划分的最佳波次及通关次数。正在进行的对局只在当前页面内存中，刷新后不能续局。

玩法借鉴生存肉鸽类型，但名称、角色、场景和表现为本项目原创内容；不是《土豆兄弟》或其 DLC 的官方移植。

## 文件与入口

- `index.html`：标题、选择界面、战斗 HUD、宝箱、升级、商店、暂停和结果界面，以及无 JavaScript 提示。
- `game.css`：游戏界面、横竖屏手机布局、触控控件和安全区域适配。
- `game.js`：游戏数据、Canvas 绘制、战斗循环、输入、商店与本地记录。
- `core/核心玩法.md`：玩法要素的聚合入口；角色、装备、武器、属性、技能、商店、地图、天赋、掉落与结算分别使用中文命名的文档，区分当前实现与设计目标。
- `../games.html`：游戏选择页；`../index.html`：Kael Lab 首页。

## 本地运行与检查

在仓库根目录运行静态服务器，例如 `python -m http.server 4173`，打开 `http://localhost:4173/games.html`，再选择《星核幸存者》。游戏页面的物理地址是 `http://localhost:4173/game/index.html`。

修改游戏后，在桌面浏览器和手机横竖屏分别检查：从选择页进入、角色与战场选择、开始战斗、键盘/右键/摇杆移动、主动技能与冲刺、拾取宝箱回血、波末自动回收与 80% 货币结算、逐箱收下或拆解、升级与商店、暂停左侧属性、转屏继续对局及返回；再检查键盘焦点、控制台错误、静态资源路径及禁用 JavaScript 时的基础说明。商店、后期波次或通关若未实际走到，应如实标明验证范围。

## 新游戏的扩展方式

新游戏创建独立目录和自己的页面资源，在 `games.html` 增加可进入的选择项，并从该游戏返回选择页。为新目录写明玩法、操作、当前实现及局部 Agent 规则；不要把尚未制作的游戏标成可玩。
