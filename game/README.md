# DotaRogue

《DotaRogue》是 Kael Lab 游戏空间的第一款网页游戏，定位为受 Dota 启发的生存肉鸽。`static/index.html` 是游戏选择入口，`static/dotarogue/index.html` 是游玩入口；图鉴、特效预览和统一设计工作台分别为 `static/dotarogue/equipment.html`、`effects.html` 与 `studio.html`。后续游戏在 `static/` 下使用独立目录与入口，不叠加到本游戏的脚本中。

DotA 英雄与装备参考资料位于 [docs/dota/英雄.md](docs/dota/英雄.md) 与 [docs/dota/装备.md](docs/dota/装备.md)。它们属于游戏设计回源，不是当前游戏的运行素材或已实现清单。核心专题与角色设计归入 `docs/core/`、`docs/characters/`；实际行为仍以正式源码与页面核对。

《DotaRogue》的页面、样式、脚本和运行素材统一归 `static/dotarogue/`：CSS 在 `css/`，JavaScript 在 `js/`，运行图片、角色帧、纹理和音频在 `assets/`。来源清单、Concept／对照图、可编辑源与离线生成器统一归 `docs/sources/`，不改变原许可；浏览器运行资源只保留 `static/dotarogue/assets/` 中的一份。路径解析边界见[正式静态资源约定](../shared/docs/README.md)。不保留旧页面路径、跳转页或兼容目录；资源移动后先从仓库根目录运行 `python -B -X utf8 scripts/check_static_paths.py`，再从选择页实际核对动态图片、音频、特效、工作台 iframe 与源码链接。

## 无尽模式的难度依据

参考来源：[Brotato Wiki · Endless Mode](https://brotato.wiki.spellsandguns.com/Endless_Mode)。这是公开 Wiki 的算法描述，尚未核实手机版具体版本的源码；本游戏采用其中的增长曲线，并按自己的战斗和经济规则调参。阶段目标、平衡护栏和验收边界见[高难无尽模式设计](docs/core/高难无尽模式设计.md)。

Wiki 还描述了受击无敌时间按 `max(1,F)` 缩短、消耗品掉率按 `1+F` 降低，以及百分比生命伤害在高波数衰减。因此原作第 60 波受击保护的理论时长只有初始值的约 1.7%，碰撞容易连续造成伤害。当前游戏的受击保护、冲刺保护和宝箱沿用现有战斗规则；本轮接入的是下述敌人、敌潮、材料与商店曲线。

无尽模式前 20 波的额外因子为 0；`w > 20` 时计算 `F=((w-20)(w-19)/200)×(2+0.2×max(0,w-35))`。该因子不设终点上限，35 波之后继续加速增长；以下倍率额外叠加在本游戏原有的波次／难度成长之上：

| 波次 | F | 敌人生命 ×(1+2.25F) | 敌人伤害 ×(1+F) | 敌人速度 ×(1+min(1.75,F/13.33)) |
| --- | ---: | ---: | ---: | ---: |
| 30 | 1.10 | 3.475 | 2.10 | 1.083 |
| 40 | 6.30 | 15.175 | 7.30 | 1.473 |
| 50 | 23.25 | 53.313 | 24.25 | 2.744 |
| 60 | 57.40 | 130.150 | 58.40 | 2.750 |
