# 星核幸存者 · 核心玩法设计

本目录是《星核幸存者》玩法要素的聚合入口。设计按元素逐项讨论；每份设计稿区分 **Current（当前实现）** 与 **Concept（待设计或待实现）**。当前可运行定义仍在 `../game.js`，设计稿不代表游戏已经采用相应机制。后续确定并实现一个元素时，再把它的运行定义和规则迁入本目录，避免建立没有消费者的空模块。

| 元素 | 当前实现 | 设计进度 |
| --- | --- | --- |
| 角色 | 4 名驾驶员，以初始生命、武器和属性区分 | [角色第一版](characters.md) |
| 装备 | 8 种武器、13 种商店改装；武器可合成和出售 | 待逐项设计 |
| 技能 | 全员共用冲刺；武器自动攻击 | 独立技能体系待设计 |
| 属性 | 13 项局内属性，另有当前生命和最大生命 | 待统一单位、公式、上限与展示 |
| 地图 | 3 个战场主题，共用场地尺寸和危险规则 | 地形与独特地图机制待设计 |
| 天赋 | 尚无天赋或跨局成长系统 | 待确定获得时机与持续范围 |
| 敌人与敌潮 | 8 类敌人、20 波敌潮 | 待逐项设计 |
| 成长与经济 | 局内升级、材料拾取、波间商店 | 待逐项设计 |

## 设计边界

- 角色的初始配置、装备、局内升级、技能和天赋分开定义；同一效果的归属在设计时明确。
- 地图设计包含战场主题、可移动区域、危险区和生成规则；现有主题差异不等同于独立地形。
- 属性先明确名称、单位、默认值、计算方式和上限，再据此校准角色、装备、技能与天赋数值。
- `../game.js` 目前仍负责战斗状态、输入、绘制、商店和本地记录。运行代码迁移时保持纯静态发布及已有记录键兼容。

设计顺序从角色开始，再处理属性、装备、技能、地图、敌人与敌潮、成长与经济、天赋；每项定稿后才进入实现与验证。
