# 当前属性清单

本文件先列《星核幸存者》当前代码已经生效的属性，再记录已确定的目标属性名称与尚待设计的规则。运行数据与计算规则仍在 `../game.js`；目标清单不代表游戏已经实现。

## 当前已实现

游戏有 13 项 `run.stats` 数值，另有独立的最大生命，共 14 项可成长属性。当前生命是局内资源；立即治疗是一次性效果，不计入属性。下表的初始值是公共基础值，各角色另有起始修正。

| 类别 | 属性 | 公共基础值 | 当前作用 |
| --- | --- | --- | --- |
| 生存 | 最大生命 | 随角色为 26～40 点 | 决定生命上限；增加上限时同时恢复等量生命。 |
| 生存 | 护甲 | 0 点 | 受伤按 `基础伤害 × 难度倍率 × 15 ÷ (15 + max(−5, 护甲))` 计算，四舍五入后至少受到 1 点伤害。 |
| 生存 | 闪避率 | 0% | 受伤时先于护甲判定，当前最多 55%。 |
| 生存 | 再生 | 每 5 秒 0 点生命 | 每 5 秒恢复对应点数。 |
| 生存 | 生命窃取 | 0% | 武器直接命中时按概率恢复 1 点生命，当前最多 35%；成功触发后有 0.13 秒间隔。燃烧不触发。 |
| 输出 | 所有伤害 | 0% | 当前实际只加成武器伤害，不加成燃烧持续伤害。 |
| 输出 | 近战伤害 | 0 点 | 加到每次近战武器伤害上。 |
| 输出 | 远程伤害 | 0 点 | 加到每枚远程弹丸的伤害上。 |
| 输出 | 元素伤害 | 0 点 | 加到元素武器伤害上，也参与燃烧伤害。 |
| 输出 | 攻击速度 | 0% | 缩短武器攻击间隔；普通武器最短 0.09 秒，护航浮球最短 0.13 秒。 |
| 输出 | 暴击率 | 5% | 可暴击攻击命中时有概率造成固定的 1.8 倍伤害；燃烧伤害不能暴击。 |
| 行动与资源 | 移动速度 | 0% | 基础移动速度 215，按百分比调整；冲刺倍率与冷却固定。 |
| 行动与资源 | 拾取范围 | 0 距离单位 | 材料和宝箱的吸附半径为 `75 + 拾取范围`。波末自动回收；未捡材料的货币按 80% 折算，经验全额获得。 |
| 行动与资源 | 幸运 | 0 点 | 每点增加 0.5 个百分点的“击杀额外掉落 1 材料”概率；不影响商店，200 点后该概率饱和。 |

现有 14 种升级选择和 13 种商店改装会给这些属性加值，或提供立即治疗。商店属性摘要没有显示“所有伤害”“生命窃取”“拾取范围”，但它们在代码中已经生效。

## 目标属性名称

目标清单为 14 项。名称和区分方式已确定；攻击范围、暴击和吸血的目标数值规则见[武器.md](武器.md)。表中的“当前对应”只说明现有机制。

| 目标属性 | 当前对应与差异 |
| --- | --- |
| 物理攻击力 | 一项统一的攻击力；近战、远程由武器决定，攻击力不再按距离拆分。当前代码仍分近战伤害与远程伤害。 |
| 法术攻击力 | 对应法术伤害；元素是法术的一种表现。当前代码只有“元素伤害”加值，尚无完整的法术伤害分类。 |
| 攻击范围 | 目标为百分比属性，起始 0%、单次升级 +10 个百分点、上限 +60%；每把武器当前仍只有固定范围。 |
| 攻速 | 已有攻击速度属性。 |
| 移速 | 已有移动速度属性。 |
| 吸血 | 已有生命窃取属性。 |
| 回血 | 已有每 5 秒恢复生命的再生属性。 |
| 闪避 | 已有闪避率属性。 |
| 护甲 | 已有护甲属性。 |
| 最大生命值 | 已有最大生命。 |
| 暴击率 | 已有可成长的暴击率属性。 |
| 暴击伤害 | 目标起始 180%、上限 400%；多个特殊暴击同时成立时取最高倍率。当前暴击倍率固定为 1.8 倍。 |
| 拾取范围 | 已有拾取范围属性。 |
| 幸运 | 已有幸运属性。 |

近战、远程、双修是角色的武器使用类别；近战、远程、通用是武器类别。近战角色可获取并使用近战与通用武器，远程角色可获取并使用远程与通用武器，双修角色三类都可获取并使用。类别决定可用武器，物理攻击力仍只有一项。物理与法术是伤害方向，和武器使用类别分别判断。

现有“所有伤害”加成仍在运行，但未列入目标清单；近战、远程、元素伤害词条也需要在实现目标属性时处理。物理／法术攻击力、攻击范围和独立暴击伤害尚未进入代码，现有角色、改装与升级词条仍按当前字段运行。
