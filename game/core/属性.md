# 当前属性清单

## 当前源码规则

`../../static/js/game/game.js` 为角色配置当前／最大生命与当前／最大法力，八名英雄分别配置初始生命。法力统一从 100／100 开始，基础每秒回复 3。另有以下 16 项 `run.stats` 字段；角色初值、升级和装备可能增加其中部分字段。装备合成会移除材料属性，再施加成品属性。这里记录源码计算，不代表八英雄最终构建已完成真实浏览器验收。

| 属性（源码字段） | 公共初值 | 当前作用 |
| --- | ---: | --- |
| 护甲 `armor` | 0 | 降低所受伤害；无其他减伤时使用 `15 / (15 + max(-5, 护甲))`。 |
| 移速 `speed` | 0% | 基础速度 215，按百分比调整；化学狂暴与剑刃风暴另加短时速度。 |
| 物理攻击 `attackDamage` | 0 | 加到远程和近战基础攻击；刚毛、跳劈、剑刃风暴与魂之挽歌也按各自系数取值。影魔另按魂数增加物理攻击。 |
| 法术攻击 `elemental` | 0 | 加到众神之王元素基础攻击，并按各自系数增强静电场、落雷、剑刃风暴和魂之挽歌等。字段仍沿用旧名 `elemental`。 |
| 基础攻击范围 `attackRange` | 0 | 加到每名英雄基础攻击的目标搜索范围及远程弹丸飞行范围；矮人火枪手被动另加 140。 |
| 暴击伤害 `critDamage` | +80% | 直接命中发生暴击时，倍率为 `1 + max(0, 暴击伤害) / 100`，初值为 1.8 倍。 |
| 主动技能冷却缩减 `abilityHaste` | 0% | 成功施放后计算主动冷却，最多按 60% 缩减。 |
| 攻速 `attackSpeed` | 0% | 基础间隔除以 `1 + 攻速 / 100`，实际间隔最短 0.09 秒。 |
| 暴击率 `crit` | 5% | 直接命中暴击，判定上限 90%。 |
| 闪避率 `dodge` | 0% | 受击前判定，上限 55%。 |
| 生命回复 `regen` | 每 5 秒 0 | 每 5 秒回复对应生命。 |
| 拾取范围 `pickup` | +0 | 材料与宝箱的基础吸附范围 75，加上该值。 |
| 幸运 `luck` | 0 | 击杀掉落时额外材料的判定概率为幸运数值的 0.5%，不直接提高宝箱率。 |
| 生命窃取 `lifesteal` | 0% | 非元素基础攻击直接命中时按实际伤害的相应百分比回血，合计上限 65%。 |
| 所有伤害 `damage` | 0% | 每次伤害结算时乘 `1 + 所有伤害 / 100`；技能和装备追加伤害也走该结算。 |
| 法力回复 `manaRegen` | 每秒 3 | 战斗进行时持续回蓝；虚无宝石与坚韧球等装备可增加。 |

普通物理基础攻击原始伤害为角色基础值加物理攻击；众神之王的元素基础攻击原始伤害为其基础值加法术攻击。技能在自己的系数上读取当前物理攻击、法术攻击、魂数和主动强化；随后统一应用所有伤害百分比并四舍五入，最终伤害至少为 1。当前只有基础攻击直接命中判定暴击与吸血，普攻专属装备被动也保持在基础攻击路径。当前升级池明确提供物理攻击 +4、基础攻击范围 +24、法术攻击 +4、暴击伤害 +15%、主动技能冷却缩减 +6% 等成长项。

## 当前边界与待验证

旧远程／近战伤害独立加值已不在本版 `run.stats` 初始化及基础攻击公式中。装备的 `attackDamage` 是角色物理攻击，会按技能系数同时强化基础攻击和物理技能；法术攻击使用代码字段 `elemental`，两者分开。装备、升级和技能的数值是否适合六名英雄，尤其高波数下暴击、魂数与主动技的叠加，尚需真实长局验证。其他未来属性及未进入当前装备池的物品仍是 Concept，不能从设计稿推断为已实现。
