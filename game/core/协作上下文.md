## 角色设计资料索引（Concept 与源码接入）

用户已建立根目录 [dota/英雄.md](../../dota/英雄.md) 作为命名、种族和职业回源。六个角色的独立设计资料位于 [../characters/README.md](../characters/README.md)，每个目录包含角色介绍、技能设计、台词、音效设计、视觉设计和资源规划。

当前确认的对照为：rover＝矮人火枪手，bulwark＝刚背兽，conductor＝众神之王，scavenger＝炼金术士，jugg＝剑圣，sf＝影魔。Razzil Darkbrew 的英雄姓名和炼金师身份来自对照表，表内常用简称为 Alchemist。

六名英雄分别由独立 session 与工作项维护首图，参考或精确对照 DotA1／War3 原型，并用 Kingdom Rush 的小尺寸表现检查可读性。剑圣、刚背兽、炼金术士、矮人火枪手、影魔已有手绘卡通全身待机 PNG，保留源图、透明图和长边 128px／64px 预览；炼金术士图完整呈现地精与食人魔组合。众神之王在四次 Lanox Image2 失败后，按用户新要求另绘[SVG 源图](../characters/conductor/art/runtime/conductor-hero.svg)，仍无 AI PNG。五张 AI PNG 现为 Concept 造型来源，六英雄战斗运行图已统一改为静态 SVG 姿态帧；需要时可继续按 War3／DotA1 原型精确制作或核对授权外部资源。图片目标与验收方法见[视觉规范.md](视觉规范.md#六名英雄的-concept-首图与运行姿态)和各角色记录。提示词或失败任务不代表已有图片。

五张 PNG 使用用户指定的本机 Lanox key 与 Lanox Image2，模型为 `lanox-image-2`；既有异步任务、去背景和图像验收记录见 [角色图片创作流程.md](角色图片创作流程.md)。众神之王的 SVG 是后续单独确认的代码绘制路线，不改变其他五张 PNG 的真实来源。凭据和内部来源路径不进入公开资源。

2026-10-11 的首轮四张 AI 成图为剑圣、刚背兽、炼金术士、矮人火枪手；影魔后续获授权重试成功，也已保存真实源图、透明 PNG 和 128px／64px 预览。众神之王四次 AI 任务均因 `model_service_unavailable` 失败，没有 AI PNG；后续运行 SVG 已写入独立文件。实际资产、静态图像检查和失败记录见 [角色图片制作状态](../characters/README.md#首图制作状态concept)。

用户随后明确要求 AI 与 SVG 各作图一次进行比较。剑圣的[制作方式对照](../characters/jugg/art/comparison/README.md)已保存本轮独立 SVG、浏览器渲染图及统一尺度预览；本轮新 AI 请求和一次重试均失败，因此对照左图明确复用上一轮真实 Lanox PNG。该对照与众神之王后续单独确认的 SVG 路线各自记录，不把 SVG 当作 Lanox 生成图。

六名英雄的设计资料仍标为 Concept。当前工作树的 `../../js/game/game.js` 已定义六名英雄及技能分支，角色图映射引用每人前视、右向侧身各 9 张静态 SVG 运行帧；分层 `hero.svg` 和 `side.svg` 是可编辑源图，不在战斗 Canvas 中消费。这是源码与资源接入状态。前一版曾从 `games.html` 真实走通六名英雄的开局、主动技、暂停，以及手机触控摇杆、技能和冲刺；商店第 2 波也实际购买过一件基础组件。当时 1440×900 桌面流程观察了六人的前视动作及暂停保持，390×844 与 844×390 检查了触控控件及溢出。这些记录早于本轮资源替换。不同地图与主题的长局表现、失焦暂停、真实手机硬件和用户对 Concept 首图的审阅仍未完成。装备首版的源码状态与未完成验收另见[游戏 README](../README.md#本次角色与装备首版的验证状态)。

本轮从六张较精细的前视源图重新生成 54 张前视静态帧，使持武器的手与武器在攻击三阶段一起移动；另为每人绘制独立右向侧身源图，并生成 54 张侧身静态帧。`build_pose_frames.py` 与 `build_side_pose_frames.py` 是相应的重生成入口。两套 86px 拼版已检查轮廓、脚点和握手层级。从带版本参数的 `games.html` 进入六名英雄各自第一波，桌面 Canvas 均观察到前视待机与侧身移动和侧身攻击蓄力／出手／收势，Esc 暂停可用；炼金术士使用初版主题，其余五名使用像素风。独立 Chrome 移动触控环境在 390×844 与 844×390 从游戏选择页触摸进入火枪手第一波，观察到摇杆左右移动、侧身步行、左右镜像及攻击三阶段，未见水平溢出、页面错误或本地资源 4xx；横屏标题首屏修正后可见。禁用 JavaScript 的 800×600 页面基础说明和返回链接可读。其余五名英雄的新版手机动作、每人两主题完整矩阵、独立上下／背面帧、真实手机硬件与长局仍待验收。
