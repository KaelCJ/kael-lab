这是供后续会话回源的**设计决策索引**，不是自动恢复游戏状态或替代源码的“记忆”。处理本游戏先读 `../README.md` 和[核心玩法.md](核心玩法.md)，按任务继续读本目录专题；凡写成“当前实现”的内容，都要以 `../index.html`、`../game.css`、`../game.js`、现有素材和真实页面重新核对。设计共识与运行现状分开记录，讨论过的方向不自动视为已实现。

## 已确认的产品方向

| 决策 | 当前状态与详情 |
| --- | --- |
| 原创公开作品 | 参考《土豆兄弟》的生存肉鸽节奏、武器定位与同名同阶合并；参考 Dota 的角色分工、四技能节奏和法术表达；参考《Kingdom Rush》的小尺寸轮廓和动作反馈。公开角色、名称、图像、数值、技能和音效保持本游戏原创，不使用原作资源或英雄名称。详见[角色.md](角色.md)、[武器.md](武器.md)、[视觉规范.md](视觉规范.md)。 |
| 先保留四名角色 | 巡星者是远程射手，装甲匠是近战剑士，导电师是法术输出者，拾荒鸦保留拾取与刷钱定位；近战刺客留待以后设计。每名现有角色已拥有一个主动技和三个自动／被动专属技能，商店通用技能尚未实现。详见[角色.md](角色.md)、[技能.md](技能.md)、[商店.md](商店.md)。 |
| 武器与属性的目标口径 | 角色目标使用类别为近战、远程、双修；武器目标使用类别为近战、远程、通用。使用资格与物理／法术伤害方向分别判断。目标属性为物理攻击力、法术攻击力、攻击范围、攻速、移速、吸血、回血、闪避、护甲、最大生命值、暴击率、暴击伤害、拾取范围、幸运，共 14 项。当前代码仍使用近战／远程／元素伤害等旧字段；目标规则和 13 把武器目录见[属性.md](属性.md)、[武器.md](武器.md)。 |
| 拾取与波末结算 | 宝箱可回血并在波末逐箱开出本局改装；未拾材料按 80% 折算货币，经验全额获得。当前已接入，具体掉落、自动回收与分支见[掉落与结算.md](掉落与结算.md)。 |
| 波次节奏与可读性 | 每波结束先展示本波统计和自动继续读秒；商店明确显示下一波编号，进入战斗前再显示下一波倒计时。手机竖屏战斗时收起武器栏和画面切换，暂停页查看武器。极限模式通过敌潮频率、敌人上限和近场最低敌人数提高压强。 |
| 一键换皮 | 当前先做原创像素主题；素材按角色、武器等玩法 ID 或技能、升级的现有序号映射，换皮时须保持映射关系。另一套“初版”可切换但覆盖不完整。以后可设计原创史诗奇幻主题，借鉴经典奇幻氛围，不复制《魔兽世界》等作品的资产。详见[视觉规范.md](视觉规范.md)、[界面与交互.md](界面与交互.md)。 |
| 角色姿态 | 玩家头部和主体始终直立，不随移动或攻击方向整体旋转；当前以左右镜像、脚步／攻击帧和朝向目标的攻击特效表达方向。两套画面一致，尚无独立上下朝向帧。详见[视觉规范.md](视觉规范.md)。 |
| 地图与声音 | 三张地图已有地面、树、石、河流和陷阱图，静态障碍参与移动碰撞；声音用浏览器 Web Audio 原创合成，不引用 Dota、Warcraft 或 WoW 原音频。详见[地图.md](地图.md)、[视觉规范.md](视觉规范.md)。 |
