# 技能设计边界

## 当前实现

角色当前只有初始生命、武器和属性修正，没有角色专属技能，也没有商店通用技能。武器自动攻击，所有角色都能冲刺。等级提升时从三项属性升级中选择一项。战斗按键与触控界面尚无独立技能操作。

## 目标结构（尚未实现）

- 每名角色设计四个专属技能，体现自己的战斗定位。专属技能绑定角色，不能从商店购买，也不计入武器槽；是否开局全部可用待等级规则确定。
- 通用技能由商店提供，所有符合其说明的角色都可获取。它们不复制角色专属技能的核心效果。
- 武器负责持续攻击，近战、远程、通用是其获取与使用类别；物理、法术是伤害方向。技能应注明伤害方向或明确写为无伤害效果。
- 四技能先采用一个主动技、两个自动或被动技、一个自动触发的标志技。主动技使用一个新操作，通用冲刺仍有自己的按钮；手机战斗区因此需要一个新增技能按钮。具体冷却、等级和解锁时机后续校准。
- 通用技能首版优先采用自动或被动触发，避免每买一个技能就增加一个操作按钮。通用技能持有上限与重复购买效果在商店规则中确定。

四名现有角色分别定位为远程物理射手、近战剑士、拾取经济角色和法术输出者，定位见[角色.md](角色.md)。近战刺客以后再设计。以下均为原创技能草案；触发次数、冷却、范围、伤害与成长值尚未定，也没有进入游戏代码。

## 巡星者：远程物理射手

| 技能 | 使用方式 | 效果 |
| --- | --- | --- |
| 测距标定 | 主动 | 自动标记当前射程内较远的敌人；对目标的远距离物理武器攻击获得伤害收益，无目标时不消耗冷却。 |
| 稳轨 | 被动 | 持续移动后，下一次远程物理武器命中获得额外暴击率。 |
| 掠线 | 自动 | 累计一定次数远程物理武器攻击后，沿攻击方向追加一发造成物理伤害的穿透弹。 |
| 星点合围 | 自动标志技 | 累计远程物理武器命中后，向多个不同敌人发射造成物理伤害的追踪弹；同一次多弹攻击最多累计一次。 |

## 装甲匠：近战剑士

| 技能 | 使用方式 | 效果 |
| --- | --- | --- |
| 破围斩 | 主动 | 朝移动方向，静止时朝附近敌人，完成一次短距离斩击；沿途造成物理伤害。与冲刺分别冷却。 |
| 踏稳 | 被动 | 周围有多名敌人时积累防护，受伤时消耗防护降低该次伤害。 |
| 回锋 | 自动 | 累计一定次数近战物理武器攻击后，追加一次造成物理伤害的侧向短弧横扫。 |
| 裂阵反击 | 自动标志技 | 一段时间内承受足够伤害后，发出造成物理伤害的环形剑气并击退附近普通敌人，有触发间隔。 |

## 拾荒鸦：拾取经济角色

| 技能 | 使用方式 | 效果 |
| --- | --- | --- |
| 磁流召回 | 主动 | 短时扩大自身拾取范围并吸引附近材料；没有直接伤害。 |
| 拾荒分红 | 被动 | 波内由玩家拾取一定数量的材料后，额外获得商店货币，不额外获得经验。波末自动回收的材料不触发该收益。 |
| 废件护层 | 自动 | 波内由玩家拾取材料并积累到门槛后，获得一层短时防护；没有直接伤害。 |
| 满载运转 | 自动标志技 | 本波通过玩家拾取积累到较高门槛后，短时提高物理攻击力、法术攻击力与攻击速度；每波有触发次数限制。没有直接伤害。 |

这里的“玩家拾取”是波内材料被角色接触并计入材料收益，包括磁流召回吸附后接触的材料；宝箱不计入拾荒鸦的材料拾取次数。波末自动回收材料按 80% 折算货币、经验全额获得，不触发拾荒鸦的额外收益。

## 导电师：法术输出者

| 技能 | 使用方式 | 效果 |
| --- | --- | --- |
| 极差场 | 主动 | 在自身位置放置短时场域，进入或停留的敌人按间隔受到法术伤害。 |
| 蓄电 | 被动 | 法术武器或技能命中积累电荷；同一次攻击命中多个目标也只积一层。 |
| 绝缘回流 | 自动 | 受击时消耗部分电荷降低该次伤害，并向附近敌人反击一次法术伤害，有冷却。 |
| 过载边界 | 自动标志技 | 电荷满后消耗，向周围扩展两圈可见脉冲，对范围内敌人造成法术伤害。 |

技能造成的伤害已标明物理或法术；技能伤害是否可暴击尚未确定。武器攻击范围与固定半径技能分别计算。上述触发效果均需要在实际战斗、手机操作和敌潮密度下验证。
