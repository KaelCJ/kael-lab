# 装备

## 当前源码规则

六名英雄各有不占格的自动[基础攻击](武器.md)。对局装备容量为 **12 格**；基础组件、中间件和成品各占 1 格，持有后立即获得其属性及适用的被动效果。旧武器槽、同名同阶合并和旧改装已退出当前装备池，没有独立的背包／装备切换层。

`../../js/game/equipment.js` 当前定义 **34 件装备：21 件基础组件、5 件中间件、8 件成品**。等级涵盖 1～5 级，其中动力鞋是 3 级成品、先锋盾是 4 级成品。商店以组件为主，另有少量中间件和成品可直接购买；宝箱只开基础组件。商店可见全部 13 条固定配方，材料齐全时手动免费合成。配方不是可获得的卷轴，不占格；合成消耗指定装备并以结果装备的属性和被动替换。满格时若合成后格数下降，仍可操作。满格不能购买或收下宝箱装备，宝箱可拆解；持有装备可在商店出售。

组件池在完成第 3 波后加入 2 级组件；商店各类商品的分波次概率、价格和刷新规则见[商店.md](商店.md)。逐件等级、基础价格、属性、全部配方和被动效果见[装备逐件设计.md](装备逐件设计.md)。

| 方向 | 当前合成链与成品用途 |
| --- | --- |
| 连锁闪电 | 秘银锤 + 加速手套 → 漩涡；漩涡 + 鹰角弓 → 雷神之锤。普攻概率连锁。 |
| 近战分裂 | 治疗指环 + 虚无宝石 → 坚韧球；大剑 + 阔剑 + 坚韧球 → 狂战斧。近战普攻分裂，成品不保留回蓝。 |
| 物理暴击 | 阔剑 + 攻击之爪 → 水晶剑；水晶剑 + 恶魔刀锋 → 大炮。提高物理攻击和暴击。 |
| 物理攻速与闪避 | 鹰角弓 + 短棍 + 闪避护符 → 蝴蝶。提高物理攻击、攻速和闪避。 |
| 生存格挡 | 小圆盾 + 活力之球 + 治疗指环 → 先锋盾。增加生命、护甲、回血并概率格挡。 |
| 吸血续航 | 铁艺头盔 + 吸血面具 → 支配头盔；支配头盔 + 希梅斯特的掠夺 → 撒旦之邪力。低血量自动狂热。 |
| 法术主动强化 | 魔力法杖 + 法师长袍 + 艺人面具 → 空明杖；精气之球 + 空明杖 → 蓝杖。提高法术与法力，并强化已有主动技能。 |
| 机动攻速 | 速度之鞋 + 加速手套 + 活力之球 → 动力鞋。提高生命、移速和攻速。 |

这些装备沿用经确认的 DotA 中英文名称；**本游戏的价格、配方、层级、属性和触发规则是改编**，不能从原作资料推断。源码已接入；真实短流程已从 `games.html` 走通第 1 波结算到第 2 波战斗，确认商店购买、出售、12 格背包和配方面板操作。逐条合成的材料消耗、属性替换、被动战斗和长局平衡仍待验收。

## 继续逐件设计

风杖、死灵书和完整 DotA 物品池仍是 Concept，不属于当前 34 件。新增装备按[装备逐件设计.md](装备逐件设计.md)逐件确认成品用途、配方、单件价值和触发规则；代码接入后仍需从游戏入口实际验证。
