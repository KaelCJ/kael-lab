# 角色

## 当前源码规则

`../../js/game/game.js` 已定义六名可选择的英雄。每人有一套开局自带、不占 12 个装备格的自动基础攻击，以及一个主动技和一个被动技；通用冲刺另计。下表是源码配置。动作资源已接入当前入口，完整远征与长局数值仍未验收。

| 运行 ID | 显示名称 | 角色定位 | 初始生命 | 初始属性修正 | 基础攻击 |
| --- | --- | --- | ---: | --- | --- |
| `rover` | 矮人火枪手 | 远程物理、远距点杀与散弹清群 | 34 | 移速 +8% | 远程单发 |
| `bulwark` | 刚背兽 | 近战物理、背向承伤与刚毛反击 | 44 | 护甲 +3 | 近战挥砍 |
| `conductor` | 众神之王 | 法术远程、静电削血与全场落雷 | 32 | 无 | 单目标元素电弧 |
| `scavenger` | 炼金术士 | 近战物理、经济成长与化学狂暴 | 38 | 幸运 +12、拾取范围 +30 | 近战挥砍 |
| `jugg` | 剑圣 | 近战物理、跃空斩与旋转清场 | 38 | 移速 +8% | 近战挥砍 |
| `sf` | 影魔 | 远程物理、收魂成长与魔法魂波 | 32 | 无 | 远程魂弹 |

基础攻击的伤害、间隔和射程见[武器.md](武器.md)，主动和被动的实际公式见[技能.md](技能.md)。`rover`、`bulwark`、`conductor`、`scavenger` 沿用既有运行 ID，`jugg`、`sf` 是新 ID；本地最佳波次按角色 ID 区分。商店装备对六名英雄共用，物理攻击平值强化物理基础攻击，法术攻击强化元素基础攻击和相关技能；狂战斧的分裂仅由近战基础攻击触发。

## 命名和美术边界

六名英雄的命名、种族和职业回源见[角色设计包](../characters/README.md)与根目录 `dota/英雄.md`。玩法数值、剧情、台词和音效按《星核幸存者》的需要改编；角色图像、武器、动作和技能姿态可以按 Warcraft III／DotA1 原型精确参考，也可以使用已核对来源与许可的外部资源。角色首图、运行图、动作图和音频各有独立制作状态，不能因设计包存在就认定全部已接入或通过实机审阅。

| 运行 ID | 设计包记录的种族与原型身份 |
| --- | --- |
| `rover` | 人族／矮人火枪手 |
| `bulwark` | 中立／野猪人战士 |
| `conductor` | 人族／矮人山丘之王、雷霆战士 |
| `scavenger` | 中立／地精炼金师与食人魔搭档 |
| `jugg` | 兽族／兽人剑圣 |
| `sf` | 中立／火元素、火焰领主 |

五名英雄已有 Lanox Image2 生成的待机 PNG，保留在各自 Concept 目录；众神之王的 PNG 任务失败后另行绘制了 SVG。六名英雄现各有一张分层 SVG 可编辑源图，以及 9 张无 SMIL 的静态运行帧：`idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、`attack-windup`、`attack`、`attack-release` 和 `skill`。`game.js` 按游戏时间和移动、冲刺、攻击、技能状态选择帧，两套画面共用；源图可含 SMIL 预览动画，但不由战斗 Canvas 直接消费。基础攻击按蓄力、出手、收势三阶段切换，命中事件落在出手帧；远程英雄另绘独立弹道，近战英雄按职业绘制基础武器和挥砍，主动技能使用独立施法姿态及战场特效。首轮桌面浏览器已看到六人的各类帧进入 Canvas，暂停后帧保持不变；完整多方向逐帧动画、骨骼系统、独立语音及采样音频尚未制作，现有战斗音效由 Web Audio 合成。

## 后续目标与验证

动作帧已从 `games.html` 进入桌面浏览器实际观察：六名英雄均能进入待机、两步行、冲刺、攻击三阶段和技能姿态，暂停时帧保持；动作资源请求返回 200，静态 SVG 可解析。390×844 与 844×390 目前只核对触控控件和无横向溢出，尚未覆盖真实手机硬件。仍需在两套画面、全部角色与地图组合中连续观察小尺寸辨识度、脚点和镜像，并补做远征、无尽长局及失焦暂停验证。角色包中与本源码数值或机制不同的“初始配置建议”“技能设计”保留为历史方案，不能代替当前运行规则。
