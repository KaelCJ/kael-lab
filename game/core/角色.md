# 角色

## Kael 的当前实现

Kael（运行 ID `kael`，召唤师／Invoker）已从 `UPCOMING_HEROES` 接入可玩角色。被动“万象轮转”每 5 秒从十个固定法术中随机施放一个；主动“回响施法”消耗 35 法力、基础冷却 8 秒，只重放最近一次成功的被动法术。无记录时主动按钮禁用并显示等待提示；主动重放不会重新随机或覆盖记录，最近法术跨波次保留，重新开始对局时清空。十个法术均有当前版本的范围、延迟、持续、减速、推离或召唤效果，统一使用当前法术攻击与全伤害规则。详细字段和数值见 [Kael 技能设计](../characters/kael/技能设计.md) 与 [资源规划](../characters/kael/资源规划.md)。

## Luna 的当前实现

Luna（运行 ID `luna`，月之骑士／Moon Rider）已接入可玩角色。被动“月刃弹射”在首次基础命中后向 190 范围内最多两名未命中敌人弹射，以首次结算伤害的 70%／49% 结算；弹射不额外触发暴击、吸血或普攻装备效果。主动“月蚀”消耗 42 法力、基础冷却 18 秒，以施法位置为中心在半径 430 内约 2.5 秒落下 10 道月光，每名敌人最多命中两道；无范围内目标时不扣蓝、不启动冷却。18 张静态姿态帧、Canvas 月光与月刃、Web Audio `skill-luna`／`luna-bounce` 均已接入，台词语音仍待制作。

桌面选人、资源加载、扣蓝／冷却、预警、移动／冲刺和暂停恢复已做短流程观察，手机全部动作、两主题完整矩阵、长局与逐敌伤害计量仍待验收。字段与边界见 [Luna 技能设计](../characters/luna/技能设计.md)、[资源规划](../characters/luna/资源规划.md) 和[游戏 README](../README.md)。

## 命名和美术边界

八名英雄的命名、种族和职业回源见[角色设计包](../characters/README.md)与根目录 `dota/英雄.md`。玩法数值、剧情、台词和音效按《DotaRogue》的需要改编；角色图像、武器、动作和技能姿态可以按 Warcraft III／DotA1 原型精确参考，也可以使用已核对来源与许可的外部资源。角色首图、运行图、动作图和音频各有独立制作状态，不能因设计包存在就认定全部已接入或通过实机审阅。

| 运行 ID | 设计包记录的种族与原型身份 |
| --- | --- |
| `rover` | 人族／矮人火枪手 |
| `bulwark` | 中立／野猪人战士 |
| `conductor` | 人族／矮人山丘之王、雷霆战士 |
| `scavenger` | 中立／地精炼金师与食人魔搭档 |
| `jugg` | 兽族／兽人剑圣 |
| `sf` | 中立／火元素、火焰领主 |
| `kael` | 血精灵／元素法师、Invoker 原型 |
| `luna` | 暗夜精灵／月光猎手、Moon Rider 原型 |

五名英雄已有 Lanox Image2 生成的待机 PNG，保留在各自 Concept 目录；众神之王的 PNG 任务失败后另行绘制了 SVG。八名英雄现各有前视和独立右向侧身两张分层 SVG 可编辑源图，每套 9 张无 SMIL 静态运行帧：`idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、`attack-windup`、`attack`、`attack-release` 和 `skill`；侧身帧在名称前加 `side-`，每人共 18 张。前视帧保留原有较丰富的造型细节，并让握手与武器在攻击中联动；侧身通过肩、前臂、握手和武器的分层连接驱动。`build_pose_frames.py` 与 `build_side_pose_frames.py` 分别从两张源图生成静态帧。`game.js` 按移动、冲刺或攻击方向的水平分量在前视与侧身间选择，向左镜像右向侧身，再按游戏时间和动作事件选帧；两套画面共用这些资源，源图不由战斗 Canvas 直接消费。基础攻击按蓄力、出手、收势三阶段切换，远程英雄另绘独立弹道，近战英雄按职业绘制基础武器和挥砍，主动技能使用独立施法姿态及战场特效。独立向上、向下及背面朝向帧、骨骼系统、独立语音及采样音频尚未制作，现有战斗音效由 Web Audio 合成。

## 后续目标与验证

旧版九帧资源曾从 `games.html` 进入桌面浏览器观察六名英雄的待机、步行、冲刺、攻击和技能姿态；该记录早于本轮前视细节恢复与侧身接入。本轮前视及侧身共 144 张静态帧已做 XML、无 SMIL 和 86px 拼版检查。从带版本参数的 `games.html` 进入六名英雄各自第一波，桌面实际 Canvas 均观察到前视和侧身移动、侧身攻击蓄力／出手／收势，Esc 暂停可用；炼金术士在初版主题，其余五名在像素风。独立 Chrome 移动触控环境的 390×844 和 844×390 短局仅使用火枪手，摇杆左右移动时观察到侧身步行、左右镜像及攻击三阶段；两种视口均无水平溢出、页面错误或本地资源 4xx。其余五名英雄的新版手机动作、每名英雄的两主题完整动作矩阵、全部角色与地图组合、远征和无尽长局、真实手机硬件及失焦暂停仍未验证。角色包中与本源码数值或机制不同的“初始配置建议”“技能设计”保留为历史方案，不能代替当前运行规则。
