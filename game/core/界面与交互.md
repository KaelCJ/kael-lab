# 界面与交互

本文件记录当前 HTML、CSS 和 JavaScript 提供的界面与操作。游戏选择入口是仓库根目录的 [`games.html`](../../games.html)，游戏页面是 [`game/index.html`](../index.html)；本次角色与装备首版的真实浏览器验收状态见[游戏 README](../README.md#本次角色与装备首版的验证状态)。

## 页面流程

```text
游戏选择页 → 标题与开局设置 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 远征第 20 波胜利：回收与逐箱选择 → 通关结果
                              ├─ 无尽模式：第 20 波后继续进入下一波，直到战败 → 无尽记录结果
                              └─ 战败：失败结果
结果 → 再来一局／返回标题；标题 → 游戏选择页
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级，并以秒数自动继续；商店显示下一波编号，确认后进入下一波读秒。战败不执行波末回收；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和奖励内容详见[掉落与结算.md](掉落与结算.md)。

| 界面 | 当前源码提供的信息与操作 |
| --- | --- |
| 标题与开局设置 | 六名驾驶员及专属技能名称、三张战场、远征／无尽模式、标准／挑战／极限难度、标准／速战节奏、像素风／初版画面、音效开关、简体中文／繁体中文／English、最佳波次和通关次数；可开始或返回游戏选择页。 |
| 战斗 HUD | 波次、倒计时、生命、法力、经验、等级、材料、暂停、当前装备和主动技能／冲刺按钮。宽屏显示更多战场及技能进度信息；画面可切换，拾取和战斗事件有文字与短时反馈。 |
| 宝箱 | 逐个显示基础组件奖励及效果；有空格时可收下并立即生效，也可拆解。12 格满时只能拆解。 |
| 升级 | 每次从三个随机升级中选一项；若积累多个等级，逐次选择。 |
| 商店 | 四个装备商品位，组件为主，按波次低概率出现中间件／成品；可购买、锁定、刷新。展示 12 个装备格、全部 13 条固定配方及手动合成按钮、出售按钮、属性摘要和下一波按钮。材料不足或装备格满时购买按钮禁用；齐料前合成按钮禁用。 |
| 暂停 | 生命、法力、属性、当前装备、基础攻击射程及两项专属技能说明和进度；可换画面、继续、重开或返回标题。 |
| 波次结算与结果 | 显示本波统计及自动继续读秒；远征胜负或无尽抵达波次、击败数、材料、压强因子和角色等级。 |

## 操作与状态反馈

| 设备 | 当前操作 |
| --- | --- |
| 桌面键盘 | WASD／方向键移动，Q 施放角色主动技，空格冲刺，Esc 暂停或继续。角色基础攻击自动进行。 |
| 桌面鼠标 | 右键指定目的地并绕开静态地形；左键临时指定瞄准点。手动移动或冲刺取消右键目的地；技能与冲刺也有可点击按钮。 |
| 手机触控 | 左下虚拟摇杆移动，右下主动技能与冲刺按钮；基础攻击自动进行。 |

主动技能同时要求冷却完成和蓝量足够。战斗界面显示法力条；技能按钮显示蓝耗和冷却，冷却结束但蓝不足时仍不可施放。成功施放才扣蓝和启动冷却；冲刺有独立冷却，不按角色主动技扣蓝。战斗、波次结算读秒和下一波读秒均可用 Esc 暂停；页面失焦或被隐藏时也会暂停这些状态。可操作按钮有键盘焦点样式。禁用 JavaScript 时页面提供基础玩法说明和返回游戏列表的链接。

界面默认简体中文（`zh-CN`），标题页可切换繁体中文（`zh-TW`）或 English（`en`）。语言写入 `kael-lab-starcore-survivor-v1.settings.locale`；旧存档缺少语言字段时回退简体中文。切换语言重新渲染界面，不清除已有对局状态。商店属性摘要当前显示生命、物理攻击、法术攻击、全伤害、攻速和护甲；暂停页还显示暴击、暴击伤害、闪避、吸血、回血、拾取范围、基础攻击射程、法力回复和技能冷却等。统一物理／法术攻击力、可成长攻击范围与独立暴击伤害仍属[属性目标](属性.md)。

## 布局与画面

宽屏标题和暂停页使用分栏；较窄屏幕压缩 HUD 并收起技能卡，暂停页仍可查看全部技能。手机竖屏战斗时收起装备栏与画面切换，保留法力与主动按钮；商店按宽度排成两列或一列。低高度横屏缩小弹窗和战斗按钮，触控设备保留摇杆，并考虑安全区域。

“像素风”是默认主题；“初版”素材覆盖不完整，缺图时使用 Canvas 或符号回退。六名英雄每人 9 张无 SMIL 的静态 SVG 运行帧：两张待机、两张步行、冲刺、攻击蓄力／出手／收势和技能姿态；首版装备图标按[视觉规范.md](视觉规范.md)在两套主题中共用，分层 `hero.svg` 是可编辑源图，可含 SMIL 预览动画但不由战斗 Canvas 消费。战斗 Canvas 按游戏时间和动作事件切换英雄姿态，基础攻击命中落在出手阶段，远程角色有独立弹道，近战角色有职业基础武器和挥砍，技能使用独立施法姿态及 Canvas 特效；暂停时游戏时间停止。运行图尚无独立上下朝向、骨骼系统或完整多方向逐帧动画。

## 待实现与验收

商店通用技能、天赋和后续史诗奇幻主题尚未进入页面。后续装备主动技需在对应单件设计时再决定按钮、蓝耗与操作方式。已从游戏选择页真实检查六名英雄的开局／主动技／暂停，以及标题／战斗／暂停的像素与初版和三种语言切换；当前动作资源还核对了桌面 1440×900 下的待机、步行、冲刺、攻击三阶段和技能姿态，静态资源请求可达，暂停保持所绘帧。390×844 竖屏和 844×390 横屏已检查触控摇杆／主动技／冲刺／暂停、商店和装备网格的无横向溢出；第 1 波商店实际显示低概率成品／中间件比例，并在第 1 波结算到第 2 波战斗中操作购买、出售、12 格背包和 13 条固定配方面板。以上是短流程证据，不代表完整角色矩阵、真实手机硬件或长局通过。
