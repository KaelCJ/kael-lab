# 界面与交互

本文件记录《星核幸存者》**当前实现**的页面、操作和界面状态。游戏选择入口是仓库根目录的 [`games.html`](../../games.html)，游戏页面是 [`game/index.html`](../index.html)；实际显示和行为以页面、`../game.css`、`../game.js` 及真实浏览器为准。玩法数值和未来方案见[核心玩法.md](核心玩法.md)，不要从界面文案推断目标系统已经接入。

## 当前界面流程

```text
游戏选择页 → 标题与开局设置 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 第 20 波胜利：回收与逐箱选择 → 通关结果
                              └─ 战败：失败结果
结果 → 再来一局／返回标题；标题 → 游戏选择页
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级，并以秒数自动继续；商店显示下一波编号，确认后进入下一波读秒。战败不执行波末回收；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和开箱内容详见[掉落与结算.md](掉落与结算.md)。

| 界面 | 当前可见信息与操作 |
| --- | --- |
| 标题与开局设置 | 四名驾驶员及专属技能名称、三张战场、标准／挑战／极限难度、标准／速战节奏、像素风／初版画面、音效开关、当前选择对应的最佳波次和累计通关次数；可开始或返回游戏选择页。角色、战场及选项由脚本生成。 |
| 战斗 HUD | 显示波次、倒计时、生命、经验和等级、材料、暂停、六个武器槽及主动技能与冲刺按钮；宽于 900px 且使用精确指针时还显示战场名、击败数及冲刺倒计时，宽于 680px 且使用精确指针时显示四项专属技能的名称和进度。可在底部切换画面。拾取、技能、陷阱和首领预警使用短时文字提示与战场反馈。 |
| 宝箱 | 逐个显示本箱改装名称和效果；可收下并立即生效，或拆解成材料。剩余箱数可见。 |
| 升级 | 每次从三个随机升级中选一项；若本波积累多个等级，继续逐次选择。 |
| 商店 | 四个武器或改装商品位，可购买、锁定、刷新；显示材料、当前六个武器槽、可用的同名同阶合成／出售操作、简要属性与下一波按钮。材料不足或武器槽无法容纳时购买按钮禁用。 |
| 暂停 | 桌面左侧显示当前生命、属性、当前武器、武器射程及四项专属技能说明和进度；右侧可换画面、继续、重开或返回标题。手机竖屏将操作和属性面板上下排列。 |
| 波次结算 | 显示“第 N 波完成”或“下一波：第 N 波”、本波统计和自动继续读秒；按钮可提前进入下一步。 |
| 结果 | 显示胜利或失败、完成波次、击败数、获得材料和角色等级；可重开或返回标题。 |

## 战斗操作与状态反馈

| 设备 | 当前操作 |
| --- | --- |
| 桌面键盘 | WASD／方向键移动，Q 施放角色主动技，空格冲刺，Esc 暂停或继续。武器自动攻击。 |
| 桌面鼠标 | 右键指定目的地并绕开静态地形；左键临时指定瞄准点。手动移动或冲刺会取消右键目的地。战斗界面的技能和冲刺也有可点击按钮。 |
| 手机触控 | 左下虚拟摇杆移动，右下主动技能与冲刺按钮；武器仍自动攻击。 |

主动技能和冲刺各有冷却。主动技能按钮在冷却时禁用并显示剩余秒数；冲刺按钮在冷却时禁用，宽屏 HUD 另显示冲刺剩余时间。可见的四技能卡显示主动技冷却与自动／被动技进度；窄屏或粗指针布局收起卡片，仍可在暂停页查看说明和进度。战斗、本波结算读秒和下一波读秒均可用 Esc 暂停；页面失焦或被隐藏时也会暂停这些状态，继续读秒后才恢复计时。选项按钮、商店锁定使用选中状态；可操作按钮有键盘焦点样式。禁用 JavaScript 时页面提供基础玩法说明和返回游戏列表的链接。

当前商店属性摘要仍使用“远程／近战／元素”加值；暂停页显示远程、近战及“法术伤害加值”（读取现有元素字段），暴击伤害固定显示 180%。统一的物理／法术攻击力、可成长攻击范围与暴击伤害属于[属性.md](属性.md)和[武器.md](武器.md)中的**目标规则，尚未进入当前 UI 与计算**。

## 布局与画面主题

| 场景 | 当前布局 |
| --- | --- |
| 宽屏且使用精确指针 | 标题内容与设置面板分栏；战斗顶部三段状态、中央四技能卡、底部武器与状态，右侧主动技及冲刺按钮；暂停属性与操作面板并排。 |
| 宽度不超过 680px 或使用粗指针 | 压缩 HUD，隐藏四技能卡；生命、等级和细经验条占据顶部，主动技按钮仍显示冷却秒数。粗指针战斗时显示虚拟摇杆。 |
| 手机竖屏 | 标题改为纵向滚动，角色选项两列；战斗时隐藏武器栏和画面切换按钮，暂停页提供当前武器；商店通常两列，极窄屏改为一列；暂停的操作与属性面板上下排列。 |
| 低高度横屏 | 缩小选择卡、弹窗和战斗按钮，保留技能与冲刺；触控设备还保留摇杆，界面考虑安全区域。 |

“像素风”是默认且素材较完整的主题，`../art/pixel/` 目前有 105 张原创 SVG；“初版”只有 10 张样张，缺图时使用 Canvas 或文字图标回退。标题、战斗 HUD、暂停页可切换画面，选择保存在浏览器本地设置中；两套主题共用角色、地图、碰撞和战斗状态。素材 ID、动作帧与后续换皮要求见[视觉规范.md](视觉规范.md)。

## 当前边界与核对入口

- 商店通用技能和天赋尚无购买或选择 UI；未来史诗奇幻主题也尚无切换项。
- 当前对局只在页面内存中，刷新后回到标题；本地记录保存的是设置、最佳波次及通关次数。
- 修改界面时，从 [`games.html`](../../games.html) 进入，在桌面、手机竖屏与横屏检查本次影响的界面及主题；同时核对键盘焦点、按钮禁用态、控制台、静态资源和无 JavaScript 说明。某一波次或随机奖励未在真实游戏中到达时，记录未覆盖范围，不把文档清单当成实测结果。
