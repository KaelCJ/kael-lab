# 界面与交互

本文件记录当前 HTML、CSS 和 JavaScript 提供的界面与操作。游戏选择入口是仓库根目录的 [`games.html`](../../games.html)，游戏页面是 [`game/index.html`](../index.html)，独立装备图鉴是 [`game/equipment.html`](../equipment.html)；本次角色与装备首版的真实浏览器验收状态见[游戏 README](../README.md#本次角色与装备首版的验证状态)。

## 页面流程

```text
游戏选择页 → 标题与开局设置 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 远征第 20 波胜利：回收与逐箱选择 → 通关结果
                              ├─ 无尽模式：第 20 波后继续进入下一波，直到战败 → 无尽记录结果
                              └─ 战败：失败结果
结果 → 再来一局／返回标题；标题 → 游戏选择页／装备图鉴 → 返回标题
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级，并以秒数自动继续；商店显示下一波编号，确认后进入下一波读秒。战败不执行波末回收；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和奖励内容详见[掉落与结算.md](掉落与结算.md)。

## 永久 Buff 品质（源码已接入）

永久 Buff 使用固定的四档品质：白色普通、蓝色稀有、紫色史诗、橙色传说。商店商品卡、商店已持有 Buff 列表与暂停 Buff 列表均显示品质文字和对应颜色；商店商品区另有四色图例。品质文字跟随简体中文、繁体中文和 English 切换；无 JavaScript 说明也保留四档含义。

品质与购买层数分别显示，重复购买只累计层数，不提升品质；Buff 品质也不等同于装备基础等级或强化等级。当前 Buff 位按完成波次和幸运计算白／蓝／紫／橙概率，命中档内等概率选件；锁定保留品质与价格，购买不立即补货，刷新和新商店按当时幸运重抽未锁定或售罄位置。当前没有保底防重复，品质本身不改变基础价格。具体定义见[永久 Buff 设计](Buff设计.md)。

品质抽取使用 `m=max(0,1+luck/100)`、`B=min(.6,max(0,w-1)×.06×m)`、`P=min(.25,max(0,w-3)×.02×m)`、`O=min(.08,max(0,w-7)×.0023×m)`，四档概率为 `1-B`、`B-P`、`P-O`、`O`；公式回源 [Shop](https://brotato.wiki.spellsandguns.com/Shop)／[Luck](https://brotato.wiki.spellsandguns.com/Luck)，参数为本作独立调节。

本节记录源码接线，不代替实际浏览器验收；本轮桌面、手机横竖屏、两主题、三语言、键盘操作与无 JavaScript 的验证范围及未覆盖项，以游戏 README 的对应记录为准。

## 元素特效预览

标题页及无 JavaScript 说明中提供“元素特效预览”，规范地址为 [`game/effects.html`](../effects.html)。该页为简体中文独立观察页，不继承对局或主题状态；默认陨石，原生单选项可切火、风，返回游戏标题或游戏列表。三者支持播放／暂停、重播、大图／小尺寸及三种衬底；火、风提供 60%–140% 强度，风独有旋向；陨石独有左右运动方向，无效控件隐藏且禁用。火、风小尺寸约 90px，陨石岩石主体约 50px，与战斗一致；陨石固定位置展示虚拟滚动，页面明确其没有伤害或碰撞。陨石与风标记已接入卡尔，独立火页仍为样张。

按钮、滑块和单选项支持键盘／触控。启用系统“减少动态效果”时默认静止；页面不可见后暂停并等待手动播放。元素切换保留暂停偏好、强度、衬底和尺寸，重置当前效果时间。选中元素未就绪时禁用调节和播放，元素选择仍可用；异步旧请求不覆盖当前选择，失败提供该元素重试。无 JavaScript 时隐藏空舞台与选择控件，保留解释和返回链接。

此页没有技能触发；风模块已用于卡尔混沌之风，火模块经陨石组合用于混沌陨石，被动自然抽到后主动回响可再次施放。暂停法术池三语言说明同步直线龙卷风与燃烧滚石。资源与调用责任见[通用战斗特效](通用战斗特效.md)，桌面、手机触控模拟、键盘与无 JavaScript 验证见[游戏 README](../README.md)。

## 成品武器升阶界面（已接入源码）

全部 12 件成品的库存卡片有独立于出售的升阶按钮与展开预览，支持鼠标、触控及键盘 Tab／Enter。预览以三件输入合计为基准，列出产物的单件属性、被动、释放两个空位以及当前角色有效暴击／闪避／冷缩；同名同级不足三件时禁用，Lv.3 显示“已满级”。每次只合并一组，成功后将焦点放到结果卡，播放约 0.45 秒收拢／点亮反馈与可关闭的合成音。减少动态效果时直接显示结果。

HUD、商店和暂停中的全部 12 件成品都显示强化 Lv.，与基础等级及图鉴合成阶段分开。图鉴沿用三个阶段和 38 件装备，提供三档强化对照、三语言文字与无 JavaScript 升阶规则。移动窄屏中的数据与描述可换行，详情无需依赖悬停。真实流程已覆盖满 12 格用 Enter 合出 Lv.2 雷锤、结果卡焦点与后续升阶禁用、第 15 波闪电及 HUD／暂停等级；初版成功状态的桌面和手机横竖屏截图已核对，见[游戏 README](../README.md)。Lv.3、雷锤以外十一件成品高阶、两主题完整特效矩阵和长局平衡仍未覆盖。

## 选英雄界面

标题页选英雄区已接入紧凑头像网格。九名已实现英雄以正常头像和 SVG 运行资源呈现；鼠标、触控或键盘选中其中一名后，显示该英雄的名称、定位和两项专属技能详情，开局使用这九名英雄。四名[已确认候选](角色.md#已确认的候选展示名单concept)只用灰色、明显变淡的通用剪影展示，配有“未开放”状态；它们是静态展示卡，不可选择或开局，也不暗示解锁条件或已经制作完成的立绘。候选名单之外没有灰色空位。

可玩网格下方显示当前选中英雄的详情。桌面将待制作网格横排在两列开局设置下方，手机竖屏将它紧接在选中详情之后。可玩头像保留选中态与键盘焦点；灵魂守卫使用独立 `tb-portrait.svg` 头像，详情显示恶魔变身与魔影；卡尔网格与详情使用含三颗静态元素球的血精灵头像，战斗角色另按游戏时钟环绕三球，暂停后停止；候选卡的姓名和状态为可读文本，不作为选人按钮。状态文案随现有 `zh-CN`／`zh-TW`／`en` 切换，分别使用“未开放”／“未開放”／“Unavailable”。从 `games.html` 进入后的桌面、手机横竖屏模拟视口、键盘选人、开局、控制台与静态资源检查结果记录在[游戏 README](../README.md#本次角色与装备首版的验证状态)；移动尺寸禁用 JavaScript 及真实屏幕阅读器播报尚未验证。

## 灵魂守卫状态读数（源码接入）

沿用现有 Q／触控主动按钮，不增加操作键。变身期间按钮与技能栏显示“恶魔形态”剩余秒数，其余时间显示冷却和 40 法力消耗；变身期间不可再次施放。被动栏显示“蓄影 0～5/6 · 魔影 0～2”，暂停页复用两项技能说明、当前进度及当前形态的基础射程。窄屏沿用收起技能卡的现有布局，可在暂停页查看完整读数。

工作台已加入灵魂守卫的待机、移动、普攻、主动和被动条目，12 秒循环可观察 8 秒变身结束后的还原；正式目录与受控演示边界见[独立设计与预览](独立设计与预览.md)。本节只记录接线，真实桌面／手机操作、两主题视觉与未覆盖项见[游戏 README](../README.md)。

## 操作与状态反馈

| 设备 | 当前操作 |
| --- | --- |
| 桌面键盘 | WASD／方向键移动，Q 施放角色主动技，空格冲刺，Esc 暂停或继续。角色基础攻击自动进行。 |
| 桌面鼠标 | 右键指定目的地并绕开静态地形；左键临时指定瞄准点。手动移动或冲刺取消右键目的地；技能与冲刺也有可点击按钮。 |
| 手机触控 | 左下虚拟摇杆移动，右下主动技能与冲刺按钮；基础攻击自动进行。 |

主动技能同时要求冷却完成和蓝量足够。战斗界面显示法力条；技能按钮显示蓝耗和冷却，冷却结束但蓝不足时仍不可施放。成功施放才扣蓝和启动冷却；冲刺有独立冷却，不按角色主动技扣蓝。战斗、波次结算读秒和下一波读秒均可用 Esc 暂停；页面失焦或被隐藏时也会暂停这些状态。可操作按钮有键盘焦点样式。禁用 JavaScript 时页面提供基础玩法说明和返回游戏列表的链接。

界面默认简体中文（`zh-CN`），标题页可切换繁体中文（`zh-TW`）或 English（`en`）。语言继续写入兼容键 `kael-lab-starcore-survivor-v1.settings.locale`；改名后沿用旧存档，缺少语言字段时回退简体中文。切换语言重新渲染界面，不清除已有对局状态。商店属性摘要当前显示生命、物理攻击、法术攻击、全伤害、攻速和护甲；暂停页还显示暴击、暴击伤害、闪避、吸血、回血、拾取范围、基础攻击射程、法力回复和技能冷却等。统一物理／法术攻击力、可成长攻击范围与独立暴击伤害仍属[属性目标](属性.md)。

## 布局与画面

宽屏标题和暂停页使用分栏；较窄屏幕压缩 HUD 并收起技能卡，暂停页仍可查看全部技能。手机竖屏战斗时收起装备栏与画面切换，保留法力与主动按钮；商店按宽度排成两列或一列。低高度横屏缩小弹窗和战斗按钮，触控设备保留摇杆，并考虑安全区域。

“像素风”是默认主题；“初版”素材覆盖不完整，缺图时使用 Canvas 或符号回退。原有八名英雄每人有前视与独立右向侧身两套无 SMIL 的静态 SVG 运行帧，各 9 张：两张待机、两张步行、冲刺、攻击蓄力／出手／收势和技能姿态。灵魂守卫另有普通／恶魔两形态，每形态前视与侧身各 9 张，共 36 张；九名英雄合计 180 张运行帧。灵魂守卫普通／恶魔显示高度为 98／126 世界单位，视觉体型不改变碰撞半径，魔影复用当前形态的半透明姿态。首版装备图标按[视觉规范.md](视觉规范.md)在两套主题中共用；分层 `hero.svg` 与 `side.svg` 是可编辑源图，不由战斗 Canvas 消费。战斗 Canvas 在移动、冲刺或攻击方向偏水平时选侧身帧，朝左镜像右向帧；其余角度使用前视。游戏时间和动作事件决定具体帧，远程角色有独立弹道，近战角色有职业基础武器和挥砍，技能使用独立施法姿态及 Canvas 特效；暂停时游戏时间停止。运行图尚无独立向上、向下或背面朝向帧、骨骼系统或完整八方向逐帧动画。
