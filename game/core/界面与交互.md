# 界面与交互

本文件记录当前 HTML、CSS 和 JavaScript 提供的界面与操作。游戏选择入口是仓库根目录的 [`games.html`](../../games.html)，游戏页面是 [`game/index.html`](../index.html)，独立装备图鉴是 [`game/equipment.html`](../equipment.html)；本次角色与装备首版的真实浏览器验收状态见[游戏 README](../README.md#本次角色与装备首版的验证状态)。

## 页面流程

```text
游戏选择页 → 标题与开局设置 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 远征第 20 波胜利：回收与逐箱选择 → 通关结果
                              ├─ 无尽模式：第 20 波后继续进入下一波，直到战败 → 无尽记录结果
                              └─ 战败：失败结果
结果 → 再来一局／返回标题；标题 → 游戏选择页／装备图鉴 → 返回标题
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级，并以秒数自动继续；商店显示下一波编号，确认后进入下一波读秒。战败不执行波末回收；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和奖励内容详见[掉落与结算.md](掉落与结算.md)。

## 选英雄界面

标题页选英雄区已接入紧凑头像网格。六名已实现英雄以正常头像呈现；鼠标、触控或键盘选中其中一名后，显示该英雄的名称、定位和两项专属技能详情，开局仍只使用这六名英雄。七名[已确认候选](角色.md#已确认的候选展示名单concept)只用灰色、明显变淡的通用剪影展示，配有“未开放”状态；它们是静态展示卡，不可选择或开局，也不暗示解锁条件或已经制作完成的立绘。候选名单之外没有灰色空位。

可玩网格下方显示当前选中英雄的详情。桌面将待制作网格横排在两列开局设置下方，手机竖屏将它紧接在选中详情之后。可玩头像保留选中态与键盘焦点；候选卡的姓名和状态为可读文本，不作为选人按钮。状态文案随现有 `zh-CN`／`zh-TW`／`en` 切换，分别使用“未开放”／“未開放”／“Unavailable”。从 `games.html` 进入后的桌面、手机横竖屏模拟视口、键盘选人、开局、控制台与静态资源检查结果记录在[游戏 README](../README.md#本次角色与装备首版的验证状态)；移动尺寸禁用 JavaScript 及真实屏幕阅读器播报尚未验证。

## 操作与状态反馈

| 设备 | 当前操作 |
| --- | --- |
| 桌面键盘 | WASD／方向键移动，Q 施放角色主动技，空格冲刺，Esc 暂停或继续。角色基础攻击自动进行。 |
| 桌面鼠标 | 右键指定目的地并绕开静态地形；左键临时指定瞄准点。手动移动或冲刺取消右键目的地；技能与冲刺也有可点击按钮。 |
| 手机触控 | 左下虚拟摇杆移动，右下主动技能与冲刺按钮；基础攻击自动进行。 |

主动技能同时要求冷却完成和蓝量足够。战斗界面显示法力条；技能按钮显示蓝耗和冷却，冷却结束但蓝不足时仍不可施放。成功施放才扣蓝和启动冷却；冲刺有独立冷却，不按角色主动技扣蓝。战斗、波次结算读秒和下一波读秒均可用 Esc 暂停；页面失焦或被隐藏时也会暂停这些状态。可操作按钮有键盘焦点样式。禁用 JavaScript 时页面提供基础玩法说明和返回游戏列表的链接。

界面默认简体中文（`zh-CN`），标题页可切换繁体中文（`zh-TW`）或 English（`en`）。语言写入 `kael-lab-starcore-survivor-v1.settings.locale`；旧存档缺少语言字段时回退简体中文。切换语言重新渲染界面，不清除已有对局状态。商店属性摘要当前显示生命、物理攻击、法术攻击、全伤害、攻速和护甲；暂停页还显示暴击、暴击伤害、闪避、吸血、回血、拾取范围、基础攻击射程、法力回复和技能冷却等。统一物理／法术攻击力、可成长攻击范围与独立暴击伤害仍属[属性目标](属性.md)。

## 布局与画面

宽屏标题和暂停页使用分栏；较窄屏幕压缩 HUD 并收起技能卡，暂停页仍可查看全部技能。手机竖屏战斗时收起装备栏与画面切换，保留法力与主动按钮；商店按宽度排成两列或一列。低高度横屏缩小弹窗和战斗按钮，触控设备保留摇杆，并考虑安全区域。

“像素风”是默认主题；“初版”素材覆盖不完整，缺图时使用 Canvas 或符号回退。六名英雄每人有前视与独立右向侧身两套无 SMIL 的静态 SVG 运行帧，各 9 张：两张待机、两张步行、冲刺、攻击蓄力／出手／收势和技能姿态。首版装备图标按[视觉规范.md](视觉规范.md)在两套主题中共用；分层 `hero.svg` 与 `side.svg` 是可编辑源图，不由战斗 Canvas 消费。战斗 Canvas 在移动、冲刺或攻击方向偏水平时选侧身帧，朝左镜像右向帧；其余角度使用前视。游戏时间和动作事件决定具体帧，远程角色有独立弹道，近战角色有职业基础武器和挥砍，技能使用独立施法姿态及 Canvas 特效；暂停时游戏时间停止。运行图尚无独立向上、向下或背面朝向帧、骨骼系统或完整八方向逐帧动画。

## 待实现与验收

商店通用技能、天赋和后续史诗奇幻主题尚未进入页面。后续装备主动技需在对应单件设计时再决定按钮、蓝耗与操作方式。前一版资源已从游戏选择页真实检查六名英雄的开局／主动技／暂停、主题和语言切换，以及 390×844 竖屏与 844×390 横屏的触控和布局；第 1 波商店与第 2 波购买／出售也曾走通。这些记录早于本轮前视细节恢复和侧身接入。本轮已从带版本参数的 `games.html` 进入六名英雄各自第一波，在桌面实际 Canvas 观察前视待机与侧身移动及侧身攻击三阶段，Esc 暂停可用；炼金术士使用初版主题，其余五名使用像素风。独立 Chrome 移动触控环境在 390×844 和 844×390 从游戏选择页触摸进入火枪手第一波，摇杆左右移动与攻击时观察到侧身步行、左右镜像和攻击三阶段；两种视口无水平溢出、页面错误或本地资源 4xx。横屏标题首屏在 `.title-heading` 对齐修正后复测可见。无 JavaScript 的基础说明和返回链接已在独立环境核对。以上是短流程证据；其他五名英雄的新版手机动作、每名英雄的两主题完整矩阵、真实手机硬件和长局仍未覆盖。
