# 星核幸存者视觉规范

## 主题现状

当前共有 105 张原创像素 SVG，放在 `../art/pixel/`。源图由整数网格上的色块组成，使用透明背景与 `shape-rendering="crispEdges"`；四名角色和八类敌人具有基础图与部分动作帧，每名角色的四项专属技能都有图标。三张地图各有地砖、树、石头、河流、陷阱和选择预览图；四名角色的主动技另有战场效果图。游戏的另一套“初版”素材放在 `../art/`，只有 10 张科幻卡通 SVG，未覆盖全部对象，其余由 Canvas 图形或文字图标补足。两套主题共用玩法文字、操作符号、地形布局和碰撞数据。

## 一键换皮的当前边界

`../game.js` 通过 `selectedSkin` 选择同一个素材 ID 在 `pixel` 或 `draft` 下的路径。标题、战斗 HUD 和暂停页提供画面切换按钮；切换只改变表现资源与界面样式，不改变角色、武器、属性、敌人行为、随机结果或当前对局。画面选择保存在已有浏览器设置中。初版缺少对应图片时沿用已有 Canvas 图形或文字图标。

这套素材 ID 机制目前覆盖角色、敌人、武器图标、改装图标、升级图标、四项专属技能图标、四张主动技战场效果，以及三张地图各自的地砖、树、石头、河流、陷阱和选择预览。16 项专属技能事件共用短时反馈绘制；主动技反馈使用专属效果图，自动或被动技反馈复用对应技能图标。材料、宝箱、弹丸、技能场域和其他特效仍有 Canvas 主题分支。后续增加主题时，必须同时覆盖素材与这些程序绘制分支，再按游戏的真实状态逐屏检查。

换皮以当前素材映射为锚点：角色、武器、敌人、地图和改装按玩法 ID 映射，技能与升级也有按现有序号生成的素材 ID。切换主题时保持这些映射及对象位置、命中范围和数值不变。一个覆盖当前像素主题的后续主题需为现有 105 个素材位置提供对应图像，并配置拾取物、弹丸、技能场域、其他特效及界面的颜色与形状；仅更换 SVG 文件不构成完整换皮。初版只有 10 张样张，地图预览回退为原有符号，地形、陷阱与技能反馈回退为 Canvas 图形；音效不随画面切换。天赋尚未进入游戏，因此没有天赋图标或主题资产。

## 像素素材清单与命名

| 类别 | 数量 | 文件 ID 与用途 |
| --- | ---: | --- |
| 角色动作 | 12 | `rover`、`bulwark`、`conductor`、`scavenger` 各有基础、`-step`、`-attack`。 |
| 专属技能 | 16 | 每名角色四张：`skill-<角色 ID>` 对应主动技；`skill-<角色 ID>-1` 至 `skill-<角色 ID>-3` 对应当前技能列表中后续三个自动或被动技能。用于战斗技能栏和暂停说明。 |
| 武器 | 8 | 与当前八种武器 ID 同名，用于选择、装备和商店图标。 |
| 敌人 | 20 | 八类敌人各有基础图；按已有动作增加 `-step`、`-attack`、`-windup` 或 `-charge`，共 12 张动作帧。 |
| 改装 | 13 | `item-<改装 ID>`，与当前商店改装 ID 对应。 |
| 升级 | 14 | `upgrade-0` 至 `upgrade-13`，顺序与当前升级列表一致。 |
| 地图 | 18 | 三张地图各有 `map-<地图 ID>-ground`、`-tree`、`-rock`、`-water`、`-trap`、`-preview` 六张图；选择预览和战斗场景按同一地图 ID 取图。 |
| 主动技战场效果 | 4 | `effect-<角色 ID>`；四名角色各一张，按技能事件在战场短时显示。其余 12 项自动或被动技能的反馈复用上述技能图标。 |

角色、敌人、武器和图标主要使用 32×32 源视口；首领部分帧为 48×48，新增地图与效果图按用途使用 48×48、48×64 或 64×64 视口。战斗绘制尺寸由游戏代码决定。素材负责轮廓、明暗和身份辨识；站立／移动／攻击帧的选择、朝向、受击闪烁、蓄力提示、陷阱预警与技能短时反馈由游戏代码驱动。当前是少帧动作系统，没有八方向逐帧动画。

玩家角色的头部和主体保持直立，移动或攻击时不将整张角色图随方向任意旋转。方向反馈使用左右镜像和已有脚步／攻击帧；上下移动仍保持头在身体上方。子弹、斩击和技能特效按实际攻击方向绘制，两套画面遵守同一规则。当前没有独立的上下朝向角色帧。

新增同一对象的主题素材时，保持其游戏 ID 与用途不变；同一主题内的基础图、动作帧和图标应共用轮廓特征及配色语义。动作帧缺失时先使用该对象基础图。新增武器、角色或敌人后，按实际消费位置补图并检查小尺寸可读性，不预建没有消费者的占位素材。

## 第一套风格：星港像素

- 方向是星港废土科幻。用厚轮廓、少量主色和清楚的明暗分组表达体积；32×32 的核心身份点必须在战斗缩放后可辨。
- 角色与友方装置以青绿、蓝灰和沙金分组；普通敌人使用锈橙、菌色等不同形体与危险色；精英和首领还靠体型、剪影与蓄力动作区分。
- 像素边缘应保持整数网格感。SVG 源图保留可编辑性，浏览器绘制时关闭平滑或采用适合的低分辨率渲染；在标题选择、战斗和商店三个尺寸上核对，不只看放大的源图。
- 后续补图遵循“玩法定位—黑白剪影—主色—动作帧—实机小尺寸检查”的顺序。观察《Kingdom Rush》的小尺寸可读性和动作反馈方法，不复制其角色、怪物、地图或具体图像。

## 后续主题：史诗奇幻

用户希望未来有一套受经典奇幻游戏氛围启发的主题，可从金属、布料、符文、魔法光效与职业辨识度提炼方向。它目前**没有素材或切换选项**。制作时为本游戏重新设计名称、剪影、配色、装备造型、场景和音色，不复制《魔兽世界》或其他作品的模型、贴图、图标与界面。

| 对象 | 史诗奇幻主题的概念方向（尚未制作） |
| --- | --- |
| 四名角色 | 巡星者用轻甲和测距镜表达射手，装甲匠用重甲与大弧刃表达贴身战斗，导电师用导雷纹和施法姿态表达法术，拾荒鸦用收集背具表达拾取经济；保留四人的轮廓差异。 |

| 武器、改装、升级 | 当前八把武器保持攻击方式和识别点，把外壳改为锻造金属、符文机构或木质构件；改装和升级沿用相同效果与现有素材映射，图标避免与武器混淆。 |
| 技能、场地和界面 | 四人的十六个技能图标对应原效果；电场、追踪弹、冲锋警示等使用原创符文或能量形状。三张地图保留危险规则，分别尝试灰烬废地、菌光遗迹和冰霜残垣的配色；界面装饰使用克制的金属和石纹。 |

这是一套表现方向，不是第二套已经可玩的主题。《Kingdom Rush》可参考的是小尺寸轮廓、颜色分组和动作反馈；当前星港像素图使用清晰的整数色块，与它的手绘卡通画法不同。

新主题应先用一名角色、一种近战武器、一种远程武器、一名普通敌人及一个技能做完整战斗样张，在实际缩放、碰撞和动态状态下通过 Review，再扩展到所有当前对象和界面状态。主题切换继续使用相同素材映射，避免为了美术差异改动战斗规则。

## 声音方向

声音反馈参考 Dota、Warcraft 和《魔兽世界》中动作易辨的做法。当前浏览器用 Web Audio 的振荡器、扫频和短噪声原创合成声音：不同武器、角色主动技、冲刺、受击、宝箱拾取与开箱、精英和首领预警有各自的音色；密集战斗音效有限流，设置中可以关闭。没有采样、截取、重制或引用这些游戏的音频与旋律。当前武器目录没有弓箭，箭声等到相应武器真正接入时再设计和验证。

辨识度的设计顺序是起音、主体、收尾：枪械用短促机械起音和低频主体，闪电用尖锐起音与颗粒噪声，挥砍用扫频和轻碰撞声，宝箱用上扬的两段提示。未来弓箭武器可用弦声起音、短促的飞行气流与命中材质声；目前不生成没有游戏事件触发的箭声。若未来希望声音也随画面主题变化，需要给同一事件配置另一套原创音色，再由画面选择切换。
