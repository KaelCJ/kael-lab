# 商店与可获得内容

## 当前实现

波间商店每次提供四个商品位，可锁定、刷新和购买。当前商品是 8 种武器与 13 种改装；急救胶囊属于改装列表中的立即治疗道具。武器最多占六个槽位，可合成与出售，细节见[武器.md](武器.md)；其他改装购买后立即生效，不占武器槽。宝箱可从 12 种永久改装中开出奖励，在进入商店前收下或拆解，见[掉落与结算.md](掉落与结算.md)。商店没有技能商品，也没有按角色武器类别限制获取。

## 目标商品类别（尚未实现）

| 类别 | 作用与归属 |
| --- | --- |
| 武器 | 近战、远程、通用三种可用类别；是否为物理或法术伤害另行标记。角色类别决定能否获取并使用。 |
| 通用技能 | 商店可提供的战斗能力，不替代角色专属技能；获取后随本局角色使用。 |
| 改装 | 提供目标属性或调整装备效果。当前改装多数是即时属性加成。 |
| 消耗品 | 购买后立即生效或有限次使用；当前急救胶囊已有立即治疗效果。 |

通用技能与专属技能分开：专属四技能已经由角色在开局拥有；商店通用技能仍是目标设计。通用技能拟以自动或被动触发为主，不随购买增加新的操作按钮。可讨论的第一批原创商品如下，均尚未实现：

| 通用技能草案 | 触发与效果 |
| --- | --- |
| 应急护幕 | 生命降到一定比例时，短暂吸收一部分后续伤害，冷却后才能再次触发。 |
| 回收助推 | 拾取一定数量的材料后，短时提高移动速度；不提供拾荒鸦专属的额外货币。 |
| 冲刺余势 | 使用通用冲刺后，下一次武器攻击获得少量攻击范围。 |

建议通用技能单独占两个技能槽，武器仍用现有六槽；重复买到同名技能时升级该技能。四格商店在生成新商品时，应保证至少有一件当前角色可用的武器；若四格都被锁定，则保持锁定商品。技能商品出现概率、价格与升级幅度需结合实际波次和材料收入校准。当前购买、锁定、刷新、合成、出售流程不作更改。

若采用[武器目标目录](武器.md)的 13 把武器，商店生成武器时需按角色的近战／远程／双修资格筛选。目标权重已定为：可与已持有同名同阶武器合成的报价为 3，已持有但暂不能配对的同名武器为 1.5，其他可用武器为 1；当前代码仍为八把武器等概率上架。这样六槽满时仍有机会买到可合并的武器。
