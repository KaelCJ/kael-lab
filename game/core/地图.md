# 地图

## 当前实现

当前可选赤沙废港、荧菌裂谷、蓝霜残骸三个战场。每张地图各有地砖、树、石头、河流、动态陷阱和选择预览六张原创像素 SVG，共 18 张；地图的地色、装饰和危险提示名称也不同。战场选择参与本地最佳记录的区分。

三个战场共用 2600×1700 的场地尺寸、敌潮规则，以及动态陷阱的生成、预警和伤害规则。每张地图在 `../game.js` 中有固定的树、石头和河流坐标，由同一份地形数据驱动绘制、移动碰撞与绕行。树和石头以圆形碰撞范围阻挡角色、敌人和飞行弹；河流以矩形范围阻挡角色与敌人移动，飞行弹可以越过。电弧链、法术场域和爆炸范围是技能效果，暂时不受树石视线影响。角色右键指定的目标若落在障碍内，会调整到可行走位置；直线路径被挡时按导航网格绕行。敌人追击也使用导航网格避开障碍。

动态陷阱按玩家周围位置生成，先预警，随后对范围内的角色造成伤害；像素主题使用对应地图的陷阱图，初版使用 Canvas 图形。陷阱不是静态地形障碍。两种画面主题共用地图布局和碰撞规则；初版缺少地图图片时由 Canvas 绘制地面及障碍。运行定义以 `../game.js` 为准。
