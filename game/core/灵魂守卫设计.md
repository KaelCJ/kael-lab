# 灵魂守卫 · 伊利丹（Current：源码接入）

2026-10-14 用户确认设计并授权实施。灵魂守卫（`tb`）已从候选接入第九名可玩英雄：主动变成远程攻击的大恶魔，被动通过有效普攻生成跟随魔影。以下记录当前源码规则与数值起点；源码接入不代表平衡通过，实际浏览器验证与未覆盖项统一见[游戏 README](../README.md)。

身份沿用[英雄对照表](../dota/英雄.md)：灵魂守卫／靈魂守衛／Terrorblade，暗夜精灵恶魔猎手、伊利丹原型。“伊利丹”用于本作原型说明；不把 Warcraft 人物与 DotA 英雄的设定混为官方同一身份。玩法遵循本作[一主动一被动](技能.md)和[基础攻击规则](武器.md)。

## 核心体验

**近战双刃蓄出魔影，选择时机变成大恶魔，与魔影一起远程集火。**

近战阶段靠走位维持攻击，变身阶段获得安全距离和爆发输出；魔影随本体切换形态，形成明确的配合。成长优先考虑物理攻击、攻速和生存，冷却缩减增加变身频率。没有永久收魂成长或额外操作按钮。

| 初始项目 | 当前配置 |
| --- | --- |
| 生命／护甲 | 36／+1 |
| 法力 | 100，上限 100，基础每秒回复 3 |
| 普通形态 | 双刃近战，基础伤害 14，基础间隔 0.65 秒，基础范围 110 |
| 恶魔形态 | 远程物理邪能弹，基础范围 420，飞行速度 760，普攻原始伤害 +40% |
| 两形态共用 | 物理攻击、攻速、范围成长、暴击、吸血及现有属性上限；不额外改变移速、生命和碰撞半径 |

双刃是一轮普攻的动作表现，不算两次攻击。普通形态沿用近战扇区命中与地形可达性；恶魔弹首次碰到敌人结算，受树石阻挡，不自带穿透、溅射或弹射。所有距离均为世界单位。

## 主动：恶魔变身／惡魔變身／Metamorphosis

- 战斗中按 Q 或触控技能键，消耗 **40 法力**，立即变成大恶魔，持续 **8 秒**；不要求周围有敌人。
- 基础冷却 **24 秒，从成功施放起算**，沿用最高 60% 冷却缩减。变身期间不能再次施放、延长或叠加；蓝量不足、非战斗阶段或冷却未结束时不扣资源。
- 将后续普攻改为远程物理邪能弹，范围由 `110 + 范围加值` 改为 `420 + 范围加值`，同样沿用通用最小范围限制。攻速与攻击节奏保持，不因切换形态补发普攻。
- 无主动强化时，本体原始普攻伤害从 `14 + 物理攻击` 变为 `(14 + 物理攻击) × 1.4`，之后按原普攻规则处理全伤害、目标修正、暴击和吸血。邪能外观不把物理攻击改成法术攻击。
- 主动强化只放大额外的 40% 部分：若现有主动强化倍率为 `A`，则变身倍率为 `1 + 0.4 × A`；施放时记录 `A`，不放大持续时间或射程，不对最终普攻再乘一次主动强化。
- 已有魔影同步变成恶魔，新生成的魔影采用本体当前形态。8 秒结束时，本体与所有魔影同时恢复近战；魔影寿命和蓄影进度不因变身刷新。
- 施放不停止移动或基础攻击，不提供额外回血、无敌或地形穿越。大恶魔的视觉体型不扩大受击范围。

形态切换只影响后续出手：尚未出手的攻击在实际出手时使用当前形态；已经飞出的邪能弹保留发射时的形态、射程与伤害，不因还原凭空消失或改成近战。出手前按当前形态重新检查目标是否有效，失效时取消该次出手且不获得被动进度。

## 被动：魔影／魔影／Conjure Image

**本人每完成 6 次有效普攻，生成一个持续 5 秒的魔影；最多同时存在 2 个，每个以 30% 伤害跟随攻击。**

1. 有效普攻指本人该轮基础攻击至少直接命中一个存活敌人并实际造成伤害。每轮只增加一次进度；近战扫中多人、双刃动作、后续弹射、分裂、装备追击和魔影攻击均不多计。空挥、打墙和未命中不计。达到 6 次后进度归零。
2. 魔影持续跟随本体，不独立索敌、寻路、承伤、吸引仇恨、挡路或拾取。从生成后的下一次本体普攻出手开始，每个现存魔影同步追加一次同方向、同类型攻击；本体未出手时魔影也不攻击。新魔影不补打生成它的那一击。
3. 魔影共用本体的攻击原点、方向、范围和地形判定，左右分身位置只用于表现。近战跟随挥砍，恶魔形态跟随发弹，不能因为分身站在墙边而绕过阻挡。
4. 每个魔影的原始伤害为该次本体**未暴击原始普攻伤害的 30%**，含当前物理攻击与变身倍率；全伤害增幅、目标伤害修正各结算一次，沿用现有取整规则。魔影不复制本体的暴击结果，也不独立暴击或吸血。
5. 魔影不触发雷锤、狂战斧、暗灭施加、冰眼施加、分身斧等普攻装备效果，不累计新的魔影。其击杀照常归属玩家，结算一次正常奖励。
6. 生成时若已有两个魔影，仅把剩余寿命最短者恢复为 5 秒；寿命不相加，不追加即时攻击，不超过两名。变身与还原不触发这一刷新。

这让攻速同时提高本人输出和魔影覆盖率。两名魔影在不考虑暴击、取整和装备额外伤害时，合计追加最多 60% 的普攻原始伤害；变身期间本体与两影合计为普通形态无影的 `1.4 × 1.6 = 2.24` 倍。这是完整命中条件下的瞬时伤害比较，不是实战平均 DPS 或平衡通过结论。

## 装备与状态边界

| 场景 | 当前规则 |
| --- | --- |
| 狂战斧 | 本体近战普攻可触发现有分裂；恶魔远程普攻和所有魔影攻击均不触发。 |
| 分身斧 | 本体沿用原装备计数和一次性幻影追击；装备幻影不增加蓄影进度，魔影也不触发装备幻影。 |
| 弹无虚发 | 保留现有“幻影弹也能弹射”的 Buff 规则：本体与魔影的恶魔弹均可获得该 Buff 的有限弹射，近战不适用。弹射不增加蓄影进度，不额外生成或驱动魔影，不重新触发暴击、吸血或装备。 |
| 雷锤、暗灭、冰眼、吸血 | 本体两形态按对应普攻规则生效；魔影不施加这些效果。目标已存在的易伤仍按通用伤害规则应用一次。 |
| 冲刺 | 沿用冲刺期间不发起新普攻；魔影也不额外出手，既有飞弹继续按原规则运动。 |
| 暂停／失焦暂停 | 变身、冷却、魔影寿命、飞弹和蓄影进度均冻结；恢复后接续。 |
| 波末／新波 | 波末结束变身、清除魔影及所属飞弹、清空蓄影进度；下一波沿用现有主动冷却重置规则。 |
| 本体死亡／重开 | 清除所有变身与魔影状态，不写入长期存档。 |
| 魔影自然消失 | 已出手飞弹可完成原有飞行；不能再产生新攻击。波末或本体死亡仍立即清理。 |

## 操作读数与玩法例子

沿用一个主动按钮和一个被动说明位：主动显示“恶魔形态剩余时间”或“冷却／蓝耗”，被动显示“蓄影 0～5/6 · 魔影 0～2”。这些读数已接入现有技能栏与暂停说明，不新增角色操作键。

例如，近战命中第 6 次后出现第一个魔影；再按 Q，本体和魔影一起变身，后续普攻发出两路邪能弹。继续命中凑够 6 次会出现第二个魔影，形成三路集火；8 秒结束时，所有仍存活的魔影与本体一起恢复近战。玩家也可以先变身解决包围，再在远程攻击中蓄出魔影，不强制先叠被动。

## 验证边界

逻辑验证需覆盖一轮多人命中只计一次、远程飞弹乱序命中不重复计数、新影不补击、两影上限、全伤害不重复乘算、形态切换与地形，以及分身斧／弹无虚发的非递归组合。零缩减时理论变身覆盖率为 `8/24 ≈ 33%`；60% 缩减时冷却为 9.6 秒，最短近战空窗为 1.6 秒，实际覆盖仍受法力、走位与波次影响。

真实流程从 `games.html` 经选人进入战斗，检验近战生存、自然蓄影、变身远程、还原和下一波；检查桌面键鼠与手机横竖屏触控、暂停／转屏、两主题、控制台、资源路径与无 JavaScript 的基础可读性。分别记录普通波、精英、首领与长局平衡，不以工作台或隔离测试代替自然对局。
