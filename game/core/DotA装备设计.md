# DotA 装备资料与本作边界

本文只保留回源入口和采用边界，不保存旧的全量装备提案。DotA Allstars 6.60b 的名称、历史效果和历史配方见仓库资料[装备对照与合成表](../../dota/装备.md)；它是原作资料，不是《星核幸存者》的当前物品清单。

本作当前源码定义的装备、数值、固定配方和效果以[装备逐件设计.md](装备逐件设计.md)为准：**21 件基础组件、5 件中间件、8 件成品，共 34 件装备与 13 条配方**。物理路线包括雷神之锤、狂战斧、大炮、蝴蝶；生存路线包括先锋盾、撒旦之邪力、动力鞋；法术路线包括蓝杖。商店少量直售中间件／成品，宝箱只给基础组件；12 格容量，配方手动免费合成，**没有卷轴物品或卷轴材料，配方不占格**。当前已有 4 级先锋盾与 3 级动力鞋成品。

沿用 DotA 中文与英文装备名是经确认的命名方向；配方结构、效果、价格、等级和数值按本游戏玩法改编，不能从原作资料直接推断本作行为。34 件之外的风杖、死灵书及完整原作物品池尚未进入当前商店、宝箱或合成列表。旧六武器槽、旧改装商品、同名同阶升阶以及卷轴提案不再是本作的装备规则。

上述数量和规则已在源码接入；最终构建的宝箱、购买、合成、持有被动、出售与高波经济仍待从真实游戏入口完成验收。
