# 剑圣 SVG 对照图 v1

> Concept / 未接入游戏。本轮按共同造型题目独立绘制 SVG。新 AI 任务失败，当前与上一轮真实 AI 图进行角色原型对照；不视为相同提示词的两张新图。

[jugg-svg-v1.svg](../../../../sources/characters/jugg/art/comparison/jugg-svg-v1.svg) 为本轮从空白画布手写制作的矢量图。全部可见角色内容由 121 个独立路径或圆形形状组成，配合四个可编辑渐变；没有嵌入 PNG、自动描摹、旧角色图复用或外链依赖，也没有文字、脚本及 `foreignObject`。

画布为 512×768，背景原生透明。绘制了兽人可见脸部、獠牙、高发髻、红橙背旗、深灰护甲、棕色皮革、红腰带与裙片；画面左侧的右手握一把完整长曲刃，画面右侧左手自然半张。没有头盔、面具、盾牌、魔法特效或地面阴影。

实际验证：从本地静态资源 URL 在 Chrome 加载本轮 SVG，HTTP 200，无页面异常，计算画布为 512×768、透明背景；查看了[浏览器渲染 PNG](../../../../sources/characters/jugg/art/comparison/jugg-svg-v1.png)及 128px／64px 的实际缩小预览。渲染不透明边界为 `(85,48)–(469,674)`，角色、旗杆尖、刀尖、双脚完整，四周有安全边距。交付预览统一裁到有效 alpha 边界后等比例放入带留白的方形画布，见[对照说明](README.md)。

64px 下，绿皮兽人、黑色发髻、红橙背旗、两枚白色獠牙与斜向长刀仍可辨认；护甲铆钉、腰带扣、绑腿细节已合并为小色块。表现偏明确轮廓和分组明暗，体积与材质层次受手绘路径数量限制。没有执行游戏端到端测试；此图尚无游戏消费者。
