# 剑圣 · 技能设计

> Current：一主动一被动已接入；本页以当前 heroes.js 和 game.js 为准，统一伤害数值仍待长局平衡。

## 被动：跃空斩 → 连环跃斩 → 无敌斩

每5次本人有效近战攻击后，若没有旋转／跳跃且内部冷却已好，锁定260范围内无遮挡目标，向其跃进最多180。被动形态随现有英雄技能成长阶段进化：

| 英雄等级 | 形态 | 行为 |
| --- | --- | --- |
| 1～4 | 跃空斩 | 跳向一名目标并在落点76范围内完成一次斩击；落地后获得0.28秒短暂无敌。 |
| 5～9 | 连环跃斩 | 一次触发最多连续完成两段跳斩；优先选择本次尚未命中的可达目标，每段落地结算一次技能伤害；每段落地保留短暂无敌。 |
| 10+ | 无敌斩 | 一次触发最多连续完成四段跳斩；从第一次起跳至连段结束保持无敌；目标不足时可回到最近可达目标。 |

每段落地的基础原始技能伤害为 `26 + 技能伤害`，应用一次技能成长。移动、目标选择与落地命中均遵守地形阻挡；每段使用英雄技能来源，不暴击、不触发普攻命中装备，也不递增本人有效攻击计数。触发间隔至少3秒，连段不跨波次、暂停或重新开始保留。

## 主动：剑刃风暴

消耗36法力，基础冷却12秒，旋转3秒，每0.2秒对138范围内无遮挡目标造成 `6 + 技能伤害 × 0.35` 的原始技能伤害；技能成长、主动强化各应用一次。期间普攻继续，接触伤害降低35%。不再重复累加旧物理／法术加值。

## 结算与验证

本人普攻可暴击、普攻吸血并触发命中装备；跃空斩与风暴走英雄技能来源，只触发受限技能吸血，不递归普攻被动。公式接入与真实流程分开记录，验证边界见[游戏README](../../../README.md)和[统一属性](../../core/属性.md)。
