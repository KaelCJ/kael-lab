# 剑圣 · 技能设计

> Current：一主动一被动已接入；本页以当前 heroes.js 和 game.js 为准，统一伤害数值仍待长局平衡。

## 被动：跃空斩

每5次本人有效近战攻击后，若没有旋转／跳跃且冷却已好，锁定260范围内无遮挡目标，向其跃进最多180。0.44秒后在落点76范围内造成 `26 + 统一攻击力` 的原始技能伤害，应用一次技能成长，并获得0.28秒短暂无敌；触发间隔至少3秒。移动与落地命中均遵守地形阻挡。

## 主动：剑刃风暴

消耗36法力，基础冷却12秒，旋转3秒，每0.2秒对138范围内无遮挡目标造成 `6 + 统一攻击力 × 0.35` 的原始技能伤害；技能成长、主动强化各应用一次。期间普攻继续，接触伤害降低35%。不再重复累加旧物理／法术加值。

## 结算与验证

本人普攻可暴击、普攻吸血并触发命中装备；跃空斩与风暴走英雄技能来源，只触发受限技能吸血，不递归普攻被动。公式接入与真实流程分开记录，验证边界见[游戏README](../../../README.md)和[统一属性](../../core/属性.md)。
