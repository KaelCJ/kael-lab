# 影魔 · 音效设计

## 当前接入（2026-10-27）

选择：`firelord-im-lit.m4a`；行动：`firelord-consume.m4a`。行动录音复用于开战、成功主动、精英击杀与胜利。

专属技能当前仍使用既有 Web Audio 合成回退；没有把它标为经典原录音。

共享事件还包括 `hurt`、`dash`、波次、宝箱和结果。事件由 `game.js` 在真实结果处触发；静音、暂停、重开与返回标题清理异步事件。具体限流、来源与未覆盖范围见[声音系统](../../core/声音系统.md)和[音频清单](../../sources/audio/dota1/sources.json)。

当前文件接线与文件解码已完成；人耳听感、密集同屏和真实手机另行记录，不以本设计说明代替验收。
