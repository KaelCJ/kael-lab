# 众神之王 · 技能设计

> 设计状态：历史Concept，保留早期未采用草案。
> 下方旧数值、伤害分类和技能方案不描述当前实现；当前一主动一被动及统一攻击力规则以[技能专题](../../core/技能.md)与英雄源码为准。

## 被动：静电场

- 方式：被动
- 规则：法术武器命中或技能命中时，在目标附近触发静电场；半径 120，造成小额法术伤害；同一目标触发间隔 0.6 秒。

## 主动：全场雷击

- 方式：主动
- 规则：为当前已生成的所有敌人生成雷击标记，0.55 秒后同时落雷；基础伤害 20 + 法术攻击 ×0.9，精英和首领承受 60%；冷却 18 秒。

## 联动与操作

被动自动记录战斗状态，主动技能保留 Q 键和触控按钮入口。数值是第一版平衡起点，须在真实波次中验证后再进入当前实现文档。
