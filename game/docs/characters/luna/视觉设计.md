# 月之骑士 · 视觉设计

> 运行状态：Current / 普通 SVG、DotA1 PNG 姿态、独立月刃与 Canvas 月蚀已接入

## 身份与轮廓

Luna 按 [英雄.md](../../dota/英雄.md) 的月之骑士／Moon Rider 对照设计为骑乘黑色豹子的月光猎手：暗夜精灵骑手坐在四足黑豹背上，银白月刃、深蓝或紫蓝轻甲、月牙形护肩和短披风与豹眼共同组成主要剪影。月刃由三片宽弯刃围绕中央短握柄组成，手持与飞行使用同一套完整刃轮几何。脸部、尖耳、月刃、豹头和四足轮廓要在 100px 战斗显示高度仍可辨认；黑豹是 Luna 的固定坐骑，不拆成第二个角色或独立战斗单位。

前视采用略微俯视的骑乘构图：骑手坐在豹背中央，双腿落在两侧，豹头、耳朵、四足和尾巴在下半部形成宽阔黑色主剪影，月刃向侧前方伸出但不遮住骑手头部。侧身明确豹的朝向和背部曲线；运行源图使用 384×384 透明画布，主动姿态抬起月刃并带局部月环，基础攻击姿态强调骑手手腕、月刃和投掷动作。

## 主动效果：月蚀

[eclipse.js](../../../static/dotarogue/js/effects/eclipse.js) 以银白核心、浅蓝外缘与向下收束的固定细丝绘制透明月光柱，保留柱身下段的小型竖月牙、局部柔光和落点五枚蓝紫微尘。原短线月柱、扩张冲击环、六枚碎月及仅高等级附加的顶部月牙／折线已退出。形态参考经典月蚀实战帧，由本仓库 Canvas 重绘，不宣称原版特效文件移植或一比一还原；录像、观察范围与技术采用边界见[来源记录](../../sources/art/effects/eclipse/README.md)。

施法中心保留半径 430 的低透明度细边界；每道落点先显示半径 52 的柔光与细环，共预警 0.22 秒。普通动效在预警最后 0.09 秒显示由高处向下展开的光柱，接地与既有伤害时点一致，随后在 0.4 秒内消退；下段竖月牙及其柔光在前 0.3 秒退去。柱体上宽下窄，向落点上方延伸 420 世界单位，Lv.1～4／5～9／10+ 只将上缘宽度从 54 调为 58／62，不改变落点与范围。落点仍围绕随机目标偏移，允许空击；Luna 移动不会带走施法区域。

地面边界、预警与落点柔光位于实体之前，月柱位于人物之后、危险提示之前；正式战斗的普通／DotA1 皮肤和工作台像素／初版通过同一游戏宿主消费。页面初始化时自绘一张柱体缓存与一张柔光缓存，实例读取既有 `beam.warning/life`，暂停时保持，不自行推进时间。减少动态效果时省去预落柱与微尘、降低柱体和局部柔光亮度，保留预警、命中位置、下段月牙和消退。参数、生命周期与预算统一见[通用战斗特效](../../core/通用战斗特效.md)。

本轮表现的实际浏览器覆盖以[游戏 README](../../../README.md)与对应验证记录为准；下文旧姿态、月刃及主题验证不能证明本轮月光的完整矩阵或长局通过。

## 被动效果：月刃弹射

基础月刃与两次弹射都显示完整的银白三弯刃轮；首次命中后朝附近未命中目标飞行，弹射尾迹改为淡蓝色，武器形状与尺寸保持一致。弹射是有飞行时间和地形碰撞的独立投射物，外形与装备链式闪电分开；两次弹射共用 `luna-glaive.svg`，没有独立的第二跳美术文件。

月刃 SVG 为 96×96、`viewBox="-48 -48 96 96"`，握柄中心为局部原点。Canvas 以飞弹世界坐标为中心绘制 26 单位的方形素材，相机和 DPR 由战场统一处理；旋转读取 `run.totalTime`，转向和弹射保持同一旋转相位，暂停时冻结。减少动态效果偏好下保留飞行和命中，只停止刃轮自转。选中 Luna 或开局时经 `HERO_POSE_ART` 懒加载并复用图片缓存；图片不可用时 Canvas 绘制同轮廓三弯刃与握柄。基础攻击、弹射及 Luna 的装备幻影追击共用该外形，幻影仍沿用原有透明度和装备尾迹，不能触发月刃弹射。

## 资源边界

普通皮肤素材包保留两张 384×384 的分层 SVG 源图、18 张无 SMIL 静态姿态帧和一张 96×96 月刃 SVG，共 21 张：前视 `luna-hero.svg`、右向侧身 `luna-side.svg`，以及待机、行走、冲刺、基础攻击三阶段和技能姿态。20 张角色图都把骑手、马具与四足黑豹绘在同一透明画布中；源图仅使用仓库内路径、渐变和透明背景，没有外链、脚本或外部模型。静态帧由 `build_pose_frames.py` 与 `build_side_pose_frames.py` 生成，并已接入 `HERO_ART`／`HERO_POSE_ART`；独立月刃作为同目录的角色武器素材供 Canvas 消费。工作台像素／初版共用这些运行帧；正式 DotA1 皮肤消费已认可的模型 PNG 与显示适配，来源和映射见[DotA1 来源契约](../../sources/characters/dota1/README.md)。朝左时镜像右向侧身。

普通皮肤前视保留骑手的银白月刃、月牙头饰、紫蓝轻甲和短披风，并突出豹眼、豹耳、背部和四足；侧身单独绘制骑手坐姿、豹背曲线、豹头和向前伸出的月刃，不把前视图旋转代替侧身。`skill` 帧叠加局部月环来表达月蚀施法，基础攻击帧由握柄连接手腕并随手臂投掷。月蚀地面光与月柱由 `eclipse.js` 绘制，飞弹尾迹仍归宿主，飞行中的实体月刃消费独立 SVG；本轮没有新增运行图片、第三方模型或纹理。

此前三弯刃替换已检查 21 张 SVG 的边界与几何一致性、18 帧生成可重复性及 100px 深浅背景拼版，并从真实入口观察桌面、手机横竖屏与两主题的月刃旋转、自然弹射和暂停。逐组覆盖与未覆盖项统一记录于[游戏 README](../../../README.md)。这些是对应旧构建的证据；全部姿态动态组合、分身装备实际获取后的月刃、真实手机硬件和长局仍待验收。
