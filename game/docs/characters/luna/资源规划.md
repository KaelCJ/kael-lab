## 已制作的运行资源

- `../../sources/characters/luna/art/source/luna-hero.svg`：384×384 前视分层源图，包含坐在黑豹背上的骑手、豹头、四足、月刃、护肩、披风和月牙装饰。
- `../../sources/characters/luna/art/source/luna-side.svg`：384×384 右向侧身分层源图，明确骑手坐姿、豹背、豹头和四足；左向由运行代码镜像。
- `../../../static/dotarogue/assets/characters/luna/luna-glaive.svg`：96×96、`viewBox="-48 -48 96 96"`，银白三弯刃与中央短握柄；角色源图中的手持武器嵌入同一几何，飞弹以握柄中心定位。
- 每套源图已生成 `idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、`attack-windup`、`attack`、`attack-release`、`skill` 九张无 SMIL 静态帧，共 18 张；生成器已登记 Luna 的动作摆幅与月环／月刃亮度提示。
- 源图与 Canvas 消费的静态帧均不包含 SMIL 动画元素，不包含脚本或外部资源；动作由游戏时钟切换静态帧。
- `HERO_ART`／`HERO_POSE_ART` 已消费 18 张静态帧；两套主题共用，侧身朝左时镜像。两张源图供编辑和预览，不由战斗 Canvas 直接消费。
- 基础攻击、弹射与 Luna 的装备幻影追击由 Canvas 消费独立月刃 SVG，绘为 26 世界单位并随游戏时间自转；选人或开局时懒加载并复用，缺图回退到程序化三弯刃。暂停冻结，减少动态效果偏好下停止自转；弹射沿用同形武器并显示淡蓝尾迹。月蚀范围、落点预警、月柱、碎月与飞弹尾迹仍由 Canvas 程序绘制。
- Web Audio 已接入 `skill-luna`（施法与落月）和 `luna-bounce`（弹射命中），无需外部音频文件；详见[音效设计](音效设计.md)。
