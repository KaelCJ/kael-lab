# 灵魂守卫 · 视觉设计

> Current：36 张运行姿态与选人头像已接入，两套主题共用。

## 轮廓与来源

普通形态使用紫灰皮肤、黑色眼罩、后掠尖耳、两支长弯角、墨色长发、胸臂绿色纹路和双月刃。大恶魔有更宽的肩胸、深蓝灰躯体、翼膜、巨角、爪足与掌心邪能，当前显示高度从 98 增至 126 世界单位。大体型只影响画面，不扩大碰撞。

身份参考 Warcraft III／DotA1 的伊利丹与灵魂守卫辨识点；实际 SVG 几何是本次独立绘制，没有导入官方资源、外部开源代码或 AI 图片。暗边线、少量主色和明暗分组沿用本作运行图风格。静态角色无需通用元素模块；手掌邪能是角色姿态局部形状，不是独立弹道效果。

## 几何与动作契约

- 全身源图与帧为 `384×384`，透明背景，脚底基准 `y=354`；画布下方保留 30 单位安全边距。`game.js` 使用 `bottom = 16 + height * 30 / 384`，补偿透明留白后两形态脚底都保持在相同世界偏移，不随变身抬升。
- 前视与右侧身分别绘制解剖、脸部、手臂和翅膀，侧身不是旋转前视。向左由调用方镜像；没有独立背面、上视或下视。
- 每形态每视角九帧：`idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、`attack-windup`、`attack`、`attack-release`、`skill`。手、握柄与双刃作为同一动作连接；恶魔改为爪与掌心邪能。
- 人物脚点保持同一基准；移动通过腿部开合、手臂摆动、翼展变化表达。游戏决定帧与时间；暂停时素材本身没有独立动画。
- `tb-portrait.svg` 使用同一前视路径裁取上身，供选人使用。它有意裁去小腿，不作为全身战斗帧。
