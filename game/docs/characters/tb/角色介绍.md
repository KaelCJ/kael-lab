> Current：已开放选人并接入近战、恶魔变身与魔影；台词语音仍为 Concept。

运行 ID 为 `tb`，中文／繁体／英文显示为灵魂守卫／靈魂守衛／Terrorblade。身份按 [英雄对照](../../dota/英雄.md)：暗夜精灵恶魔猎手，伊利丹作为外观原型，不将 Warcraft 人物与 DotA 英雄合称为官方同一身份。

玩法是双刃近战蓄出魔影，主动变成大恶魔，与仍存活的魔影一起远程集火。初始生命 36、护甲 +1、法力 100、法力回复每秒 3；基础攻击 14、间隔 0.65 秒、近战范围 110。完整机制以 [灵魂守卫设计](../../core/灵魂守卫设计.md) 和当前游戏定义为准。

本角色包的两形态、前视与独立右侧身各九张静态运行帧，以及独立选人头像已接入游戏。普通／恶魔分别以 98／126 世界单位高度显示，脚底固定对齐。资源为本仓库原创路径绘制，没有直接引入外部模型、贴图或录音。
