# Kael（召唤师）· 视觉设计

状态：Current（血精灵造型与三元素球已接入）。真实流程的验证范围见[游戏 README](../../../README.md)，素材接线见[资源规划](资源规划.md)。

## 用户确认的身份特征

以 Warcraft III／DotA1 的血精灵卡尔为原型：金色长发、修长尖耳、白皙面孔与分层高领长袍；冰蓝、雷紫、火橙三颗元素球独立悬浮于头顶周围。普通皮肤保留既有红金袍；2026-10-28 根据用户纠正，DotA1 皮肤改为白色外袍、紫色内衬与金色饰边，保留普通版的表情和完整姿态几何。用发色、尖耳、长袍和三球在小尺寸下共同表达身份。原蓝甲、白胡须、长杖与腰部光环已退出。

当前 SVG 是按上述特征在仓库重绘，未带入官方模型、贴图或音频。名称与种族回源[英雄资料](../../dota/英雄.md)；未改变六项当前法术的随机与回响施法规则，也不把三颗装饰球解释成可操作的元素配方。

## 源图、运行帧与头像

两张 256×384 分层源图为 `../../sources/characters/kael/art/source/kael-hero.svg`、`kael-side.svg`，脚点约 (128,366)，头与身体保持同一视口；三球在独立 `#kael-orbs` 组。前视与右向侧身各生成9张静态战斗帧，生成时剔除该组。另生成的 `kael-portrait.svg` 保留三颗静态球，作为旧版头像素材保留；2026-10-27 起标题网格与详情改用 `assets/art/dota1/heroes/kael.png` 经典头像，来源与权利状态见[经典图标来源](../../sources/art/dota1/README.md)。共两源图、18帧与1头像，源图不直接充当战斗帧。

上述源图与运行帧属于普通皮肤，保留红金配色。DotA1 白袍版的 18 张运行帧位于 `game/static/dotarogue/assets/characters/dota1/kael/`，由 `../../sources/characters/dota1/geometry.py` 处理普通版几何和配色，再由 `build_skin.py` 生成；对应前／侧分层源图保存在该来源包的 `art/source/`。全部姿态统一水平适配以容纳伸手动作，纵向脚点与命名姿态变换沿用普通版。

离线生成器可用 `--hero kael` 只处理卡尔，默认直接写入 `game/static/dotarogue/assets/characters/kael/`；`--output-root <目录>` 可指定角色输出根目录。浏览器不依赖 Python：

```text
python3 game/docs/sources/characters/build_pose_frames.py --hero kael
python3 game/docs/sources/characters/build_side_pose_frames.py --hero kael
```

手臂、手掌、披风、双腿随既有姿态帧运动；普攻以手势施法，侧身为独立画稿，向左镜像。仍没有独立背面或完整八方向帧。

## 头顶环绕球

战斗的 `drawKaelOrbs()` 属于卡尔角色表现，直接由 `game.js` 的 `drawPlayer()` 消费，不是通用元素攻击特效。每个卡尔恰好三球，相位间隔120度；冰／雷／火使用不同颜色及冰纹、折线、火焰小纹样。

环绕中心在角色局部坐标 (0,-64)，为86单位高的现有角色留出额头上方空隙。普通皮肤的轨道半径为横20、纵5，球基础半径3.5；DotA1 皮肤改为横24、纵7，球基础半径4.8，使头顶三元素更容易辨认。两套皮肤均按深度微调球尺寸，按前后深度分别在身体前后绘制，跟随角色位置、起伏与轻微倾斜；抵消身体左右镜像，换方向不反转环绕。球不会进入冲刺残影，不在静态战斗帧中重复出现。

相位读取对局秒数，每秒1.45弧度；暂停或离开战斗后不推进。减少动态效果时固定相位，仍随角色移动。没有独立计时器、随机调用、额外伤害或碰撞；固定3球，不据此声称真实手机或密集场景性能达标。程序化角色回退也区分普通红袍与 DotA1 白袍，并保留金发和三球身份，实际失败流程另列验证范围。

## 冰墙、炽魂、雷电与震荡波的当前表现

寒冰之墙由 `game.js` 的 `drawSkillGround()` 绘制，炽魂由 `drawKaelSpirit()` 绘制，像素风和初版共用。冰墙中心位于 `240 + 敌人半径` 内最近有效敌人的施放时位置，沿垂直于施法方向的局部 y 轴覆盖全长 480、半宽 36 的命中区域，持续 10 秒；7 块交叠尖角冰块、底部冰堆、白蓝高光与少量冰屑随生成和消散变化。可见冰堆与等级细节读取同一半长、半宽，命中判定另计敌人半径；多道墙独立到期。

两个炽魂由 Canvas 绘为可辨识的小火怪：深红身躯、带尖角的头部、浅色眼睛、四肢和向后拖出的火焰尾巴。2026-10-30 视觉尺度增至 1.3、地形碰撞半径 11.7、持续 12 秒；朝目标转向并在攻击时伸出 0.28 秒火焰爪光，目标处保留命中脉冲。基础与高等级装饰跟随同一坐标、尺度和朝向。它们只追击玩家 440 内的附近目标，无目标时向各自跟随锚点归队；离玩家超过 440 后进入回归，返回至玩家 100 内才重新追击。数量仍为两只，重复召唤替换旧实例，每 0.7 秒攻击一次及原始伤害系数不变。程序化轮廓不引入独立外部素材，两主题共用；工作台 Kael 每 14 秒重置，实际验证范围仍以游戏 README 为准。

电磁脉冲按“雷电命中、命中点爆炸与残电”表现：施放时对 `280 + 敌人半径` 内的目标各结算一次伤害并返还 12 点法力，从卡尔向每个受影响敌人拉出持续 0.3 秒的加粗蓝白锯齿雷束。命中点爆炸半径为 `max(42, 敌人半径 + 40)`，按 `0.12 + min(目标序号, 6) × 0.012` 秒延迟开始，0.24 秒展开，开始后在 0.9 秒内淡去双层雷环、放射闪电与碎光。雷束、爆炸及残电均是命中反馈，不追加伤害或回蓝；基础与高等级绘制共用真实事件寿命。

震荡波沿施放时锁定的原点和方向推出三道弧形冲击波，半角 0.95 弧度（全角约 109°）、波带全宽 12，三道依次错开 0.14 秒，各用 0.72 秒推进至 300，总持续 1 秒。深冰蓝外弧、白蓝内弧及高等级细节都读取本次波前的 `waves.radius/alpha`；减少动态效果时仍保持真实波前位置。战斗循环按前后波前扫掠区域结算，每敌每次施放最多伤害一次并沿施法方向推离 70，绘制不增加命中；`kaelBlasts` 允许多次施放独立并存。两套主题与工作台共用，暂停随游戏时钟停止。本次数值和时序需独立验证，旧构建截图不能证明已通过。
