# Kael（召唤师）· 资源规划

> 状态：Current（SVG 角色帧及风、陨石模块已接入）

Kael 当前使用已接入运行时的 SVG 角色帧和 Canvas 程序化法术特效，不依赖技能图标或音效文件。资源规划保留后续美术与音频协议；历史候选名单不属于当前角色资源。

## 运行资源

- `game/docs/sources/characters/kael/art/source/` 保留血精灵前视、侧身分层输入；各 9 张静态动作帧与发布快照位于 `game/static/dotarogue/assets/characters/kael/`；`HERO_ART`／`HERO_POSE_ART` 映射无球战斗帧，`kael-portrait.svg` 保留为带三球的旧标题头像，当前选人改用经典 `assets/art/dota1/heroes/kael.png`。战斗三球由 `drawKaelOrbs()` 按游戏时间在身体前后绘制；脚点、尺寸、减动效与重生成见[视觉设计](视觉设计.md)。保持 `kael` 运行 ID 不变。
- 普通皮肤保留红金配色；DotA1 皮肤的 18 张前／侧运行帧位于 `game/static/dotarogue/assets/characters/dota1/kael/`，采用白色外袍、紫色内衬和金色饰边。`game/docs/sources/characters/dota1/geometry.py` 复用普通版完整几何，`build_skin.py` 生成运行帧与该来源包 `art/source/` 下的两张分层源图。两套战斗帧均不含静态三球；DotA1 仅增大 Canvas 三球及轨道，提高头顶元素可读性，普通版保持原尺寸。
- 当前 Kael 地面角色、技能姿态和六个当前法术战场特效分别由 SVG 运行帧与 Canvas 程序效果表达；后续替换资源时保持 `kael` 运行 ID 和技能状态契约。寒冰之触、幽灵漫步、灵动迅捷、阳炎冲击仅保留在历史设计记录，不属于当前资源目录或随机池。

- 混沌之风已消费 `game/static/dotarogue/js/effects/wind.js` 及 `game/static/dotarogue/assets/art/effects/wind/` 下的 SVG 碎叶／气流片、PNG 尘雾，与独立风预览共用。两套战斗主题使用同一模块；缓存、脚点、时间、失败回退与具体消费者契约见[通用战斗特效](../../core/通用战斗特效.md)。
- 混沌陨石已消费 `game/static/dotarogue/js/effects/meteor.js`，由程序化岩壳、裂缝、阴影与 `fire.js` 组合；烟纹理复用 `game/static/dotarogue/assets/art/effects/fire/png/smoke.png`，不复制到角色目录，也没有新增陨石位图。游戏页缓存一个组合渲染器，未就绪或失败时使用简化岩石；预览新增陨石并默认选中，单独管理自己的缓存。位移、时间、抬升、两主题排序、减动效与生命周期统一回源[陨石契约](../../core/通用战斗特效.md)。当前六项法术共用正式技能实现；四项历史候选不创建新的资源条目。
- EMP、炽魂与震荡波继续由 `game.js` 及 `effects/hero-growth.js` 程序绘制，不新增外部技能素材。2026-10-30 EMP 扩至 280 范围，以 0.3 秒雷束及爆炸开始后 0.9 秒残电表达即时命中；炽魂按尺度 1.3 绘制两只、持续 12 秒并支持无目标归队；震荡波由 `kaelBlasts` 保存各次独立施放，基础与等级细节共同消费真实 `waves.radius/alpha`，波前到达才由战斗循环结算一次命中。位置、范围、时序与来源契约见[技能设计](技能设计.md)和[通用战斗特效](../../core/通用战斗特效.md)，不得在绘制层重复结算。

## UI 与音效

- 当前 HUD 使用文字技能槽和“最近法术”状态，暂停页可读六个当前法术池的文字说明；独立图标仍待制作。
- 工作台 Kael 场景每 14 秒重置，覆盖 12 秒炽魂和 10 秒冰墙的观察时段；受控预览与自然被动／回响的验证分别记录。
- 随机成功与主动回响目前共用合成音色并通过提示符号区分；专属音色仍待制作，不能把现有英雄音效登记为 Kael 专属音效。
