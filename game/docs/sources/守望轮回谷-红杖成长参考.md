## 采用边界

这些页面是公开的历史版本参考，不能证明当前版本的完整数值、配方或掉落规则，也不能证明本作必须复刻原作的 5／6 级。DotaRogue 当前仍遵循全部成品统一的 Lv.1～Lv.3 三合一契约；本轮把“同名成长、阶段能力变化、冷却与伤害同步增强、视觉层级随成长变化”抽象到红杖、风杖、死灵书和陨星锤，不直接复制原作波数、角色名称或技能数值。

## 本作映射

红杖当前 Lv.1／Lv.2／Lv.3 分别为单束冲击、双束分光、三束棱光；升级同时改变冷却、射程、技能伤害系数、目标数和扇角。其余三件法术装备沿用同一套三档强化契约，保持固定配方、三件同名同级免费合一、最高 Lv.3。若未来要开放 Lv.4／Lv.5，应先单独扩展全局装备契约、配方与界面，不在单件装备中暗改上限。
