# 炼金术士公开 SVG 资源

普通形态沿用本项目已有的地精与食人魔组合图。2026-10-30 为化学狂暴增加两种皮肤的独立完整动作，以及进入和还原的三阶段静态过渡。身份目标是保留绿色地精、背罐和握持关系，让食人魔以紫色皮肤、绷紧的胸肩、弯曲的肩肘链和刀刃亮边表达狂暴；不把它变成灵魂守卫的恶魔，也不改变两名搭档的接触关系。

这些资源是已有公开 SVG 的程序化派生，视觉参照既有 Warcraft III／DotA1 Goblin Alchemist 普通与化学狂暴方向。不是官方模型或动画导出，不读取或包含第三方模型、纹理、模型派生 PNG。普通皮肤和 DotA1 皮肤的原有普通帧均只读，保留原字节。源、输入和输出哈希见 [rage-manifest.json](rage-manifest.json)。

## 资源与动作协议

两种皮肤各增加 30 张 SVG，分别放在正式 `game/static/dotarogue/assets/characters/scavenger/` 和 `game/static/dotarogue/assets/characters/dota1/scavenger/`：

- 狂暴前视：`scavenger-rage-<pose>.svg`；右向侧身：`scavenger-rage-side-<pose>.svg`。`pose` 为既有 `idle-a`、`idle-alt`、`walk-a`、`walk-b`、`dash`、`attack-windup`、`attack`、`attack-release`、`skill`，每皮肤 18 张。
- 前视过渡：`scavenger-morph-in-0/1/2.svg` 与 `scavenger-morph-out-0/1/2.svg`；侧身在 `scavenger-` 后加 `side-`，每皮肤 12 张。进入按普通→半程→狂暴取样，还原反向取样；这是本作对源分层 SVG 的三阶段插值，不声称复刻模型原生 Morph 动画。
- `art/source/` 保存四张带皮肤名称的狂暴前／侧源 SVG，保留胸肩、腿、武器、地精和背罐分组；它们是生成的可编辑待机视图，不直接充当游戏动作帧。派生参数由 `build_rage.py` 维护，直接修改导出源不会反向更改生成器。

画幅统一为 256×384，`viewBox` 为 `0 0 256 384`；未做逐帧裁切或 fit。两种视角沿用各自整套既有姿态的原始坐标和脚点，运行显示高度仍为 94 世界单位、底部仍为 16；整组只增加以 x=128 为中心的 0.93 水平适配，不改变纵向脚点。肩、前臂、手和武器作为连续嵌套链一起变换，刀刃亮边烘焙在武器组内。SVG 没有自主动画，帧时序、暂停和还原由游戏时间驱动。

狂暴颜色仅作用于食人魔材质；地精、皮革、金属、药剂和玻璃保留身份色。前视的原有化学瓶在进入时淡出，食人魔始终持近战武器；还原最后阶段恢复原普通待机结构。全部颜色、肌肉路径和肩肘变换是本作的独立表达，不复制未确认许可的模型数据。

## 重生成与验证

在仓库任意工作目录运行生成器的绝对路径，或在仓库根目录运行：

```sh
python3 -B -X utf8 game/docs/sources/characters/scavenger/build_rage.py
```

默认输出位置根据脚本位置确定；`--output-root`、`--source-root`、`--manifest` 可指定独立审阅位置。生成器只写炼金新增的狂暴／过渡帧、四张源视图和自己的清单，不调用全英雄重生成，不覆盖普通帧或其他英雄。

本轮静态检查覆盖 60 张运行帧的 XML、唯一 ID、透明、非空和扩展画布边界；无脚本、外链位图、滤镜或自主 SVG 动画。两种皮肤的全部 18 狂暴动作与 12 过渡均制作浅／深底拼版，并按 94 世界单位显示高度审图；独立输出重生成与正式输出逐字节比较，普通输入哈希保持一致。它们仅证明静态资源与可复现性；连续实战、暂停／恢复、皮肤切换、手机与长局的真实结果见游戏 README，不由静态检查代替。

正式保留项为 60 张运行帧、四张源视图、`build_rage.py`、`rage-manifest.json` 和本说明。审图拼版、渲染脚本及独立重生成产物保留于本机 `.tmp/alchemist-rage-svg-20261030/`，检查报告位于根 `.logs/actual-test/alchemist-rage-svg-20261030/`；不提交这些本机产物。本轮未删除旧资源或其他任务证据。
