2026-10-30 的 `requiem` 绘制由本仓库自行编写，不包含 Warcraft III／DotA1 的模型、纹理、截图像素或第三方代码。经典魂之挽歌的放射布局、半透明灰绿魂体、伸臂与破碎烟尾作为形态参考；不是原版模型的导出或逐帧移植。

正式源与运行实现为 [`requiem.js`](../../../../../static/dotarogue/js/effects/requiem.js)。模块初始化时一次绘制八张 `160×208` 透明 Canvas 魂体及一张 `96×96` 不规则柔烟缓存；运行时复用缓存，程序路径仅负责沿实际径向的烟流。无需离线生成器、PNG 下载或运行时构建。缓存由游戏页面的单个渲染器实例持有，离开对局仍可复用；页面销毁时释放。

魂体有小头、肩、伸出的长臂与手指、扭曲躯干和分叉烟丝。主体始终直立，尾迹沿运动反向；完整圆形的世界坐标脚点与原技能半径一致。每次施法固定十八束，等级只改变体积及烟流局部厚度；减少动态效果停止魂体帧切换、移除残影并减少烟流层数。没有新增伤害、弹道实体、魂数消耗或战斗随机数。

当前模块的输入、生命周期、前后分层与真实消费者统一记录在[通用战斗特效](../../../../core/通用战斗特效.md)；素材与代码已创建不代表真实战斗或性能验证通过。
