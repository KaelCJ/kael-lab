# Luna 月蚀：月光表现来源

## 当前采用方式

2026-10-31 按经典 DotA1 实战录像观察月柱形态，由项目 Canvas 自行绘制。正式实现为 [`eclipse.js`](../../../../../static/dotarogue/js/effects/eclipse.js)，调用契约见[通用战斗特效](../../../../core/通用战斗特效.md#月蚀月光current源码接入2026-10-31)。没有引入录像、截图、第三方模型、纹理或代码，也不宣称原版特效文件移植或逐像素复原。

## 视觉参考

- 公开录像：[Luna Guide, Good Eclipse.wmv](https://www.youtube.com/watch?v=hxXj8OZP8Lc)，上传者 Xoraze（@Xoraze），页面标注发布于 2011-11-01；2026-10-31 实际播放并观察约 2.759 秒与 5.947 秒的解码帧。
- 采用特征：上宽下窄的青白纵向光丝、高处落下的半透明月柱、柱身下段的小型白月牙、前后落月交叠的淡青余幕，以及基部少量蓝紫亮尘。原录像的整场夜色与昼夜盘不属于本轮实现。
- 本作适配：保持现有随机落点、0.22 秒预警、0.25 秒安排间隔与十道月光；保留低对比的真实范围提示。光柱固定高 420 世界单位，月牙位于脚点上方 53～105 单位，不改变伤害与判定范围。原录像分辨率与镜头有限，精确模型、材质、原版时序及视角参数尚未确定。
- 录像及其中游戏内容权利仍归相应权利人。参考截图仅作本机审阅，不进入正式静态资源；不能从公开视频可见性推断第三方素材再分发许可。

## 绘制与技术参考

本模块沿用项目既有的预绘缓存和按事件寿命渐隐方式：页面初始化时制作一张 `128×640` 月柱 Canvas 和一张 `128×128` 柔光 Canvas，战斗及工作台复用；不生成 PNG，也不需要网络加载或离线构建。

技术思路核对 [Proton `CanvasRenderer.js`](https://github.com/drawcall/Proton/blob/b4fdef5e5416d70a788978bec0fb4a1be26514b4/src/render/CanvasRenderer.js)，固定提交 `b4fdef5e5416d70a788978bec0fb4a1be26514b4`，2026-10-31 所读文件 SHA-256 为 `450438efa837d9205fb0c8dcb077c00c21bda9f21856848b25b75b1a2da3695e`。该文件提供图片缓存、Canvas buffer 与透明度绘制的参考，没有 Luna 月柱成品；未复制其代码、示例纹理或框架。[上游许可](https://github.com/drawcall/Proton/blob/b4fdef5e5416d70a788978bec0fb4a1be26514b4/LICENSE)为 MIT，此处采用方式仅为技术思路参考。

具体构建、自然战斗、受控工作台与未覆盖范围统一回源[游戏 README](../../../../../README.md)。
