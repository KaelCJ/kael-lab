# 装备

## 当前武器系统（Current：源码接入，2026-10-26）

2026-10-27 已将装备平值统一为攻击力 `attackPower`，同一装备原有两项攻击属性相加迁移。所有英雄的基础攻击、技能、装备、Buff 与召唤共用伤害结算，近战、远程、弹射、分裂和控制仍是各自机制。普通吸血适用所有英雄的普攻；血精石 `skillLeech` 只读取英雄技能实际扣血。暗灭由普攻施加通用易伤，强袭为范围通用易伤；已结算的弹射与反伤不重复放大。现行逐件数值见[装备逐件设计](装备逐件设计.md)，下方原规则与验证保留旧构建事实。

装备池为49件：21组件、5中间件、23完整三级成品，共28固定配方。12格为生效作战格，满格获得的物品进入不限数量的待用储备；储备不提供属性、被动和羁绊。商店可装备、指定交换、移入储备或出售一件，两处共同取料。整理与合成按生效属性差量应用一次，保留当前生命／法力与冷却；升阶属性／总卖价按1／3／9守恒。

默认自动同名同级三合一，最高Lv.3；最多追踪两个有序成品目标，只在完整路线齐料时合成，不提前占用共享材料，可关闭并手动制作。圣剑须本局完成第10波才解锁铸造／直售资格，新局重置。基础品级1～5与强化Lv.1～3分开显示；相位鞋保持独立机动定位。

新增金箍棒（恶魔刀锋＋短棍＋攻击之爪）、陨星锤（秘银锤＋魔力法杖＋治疗指环）、圣剑（恶魔刀锋＋大剑＋阔剑）；定义与三级数值见[装备逐件设计](装备逐件设计.md)及[成品武器升阶设计](成品武器升阶设计.md)。六类羁绊只计生效的不同成品，重复、强化与储备不加件数；规则由下述专题拥有。源码接入与真实验证分别回源[游戏README](../../README.md)，下文旧构建记录保留历史边界。

## 原装备规则与历史验证（当前规则以开头为准）

九名英雄各有不占格的自动[基础攻击](武器.md)。对局装备容量为 **12 格**；基础组件、中间件和成品各占 1 格，持有后立即获得其属性及适用的被动效果。旧六武器槽及其同名合并规则、旧改装已退出当前装备池，没有独立的背包／装备切换层。

`../../static/dotarogue/js/equipment.js` 当前定义 **49 件装备：21 件基础组件、5 件中间件、23 件成品**。等级涵盖 1～5 级，其中动力鞋／相位鞋为 3 级成品，先锋盾／红杖／刃甲／风杖为 4 级成品，其余成品为 5 级。商店以组件为主，另有少量中间件和成品可直接购买；宝箱只开基础组件。商店另有独立的 25 件 Dota 命名永久增益池，Buff 不占装备格、不能出售，同名购买会叠加纯正面或正负属性，规则与扩展入口见[Buff设计](Buff设计.md)。商店顶部集中展示可合成／升阶动作，全部 28 条固定配方默认折叠；玩家选定目标后，优先使用已有中间件，并用当前组件一次完成其余中间步骤。配方不是可获得的卷轴，不占格；整条路线先校验材料，再以最终结果的属性和被动替换消耗装备，不自动选择共享材料的大炮／暗灭。

满格阻止普通购买／收箱，但可选择合成后的格数合法且实际消耗新物品的“购买并合成”或“收下并合成”；已有两件同名 Lv.1 成品时也可购买第三件并升阶。宝箱另可先合成已有装备或三合一腾格后再收下奖励，也保留拆解。同名同级库存聚合显示，数量和实际占格不变；商店“出售一件”只卖一件。当前交互与验证边界见[商店](商店.md)、[界面与交互](界面与交互.md)和[游戏 README](../../README.md)。

组件池在完成第 3 波后加入 2 级组件；商店各类商品的分波次概率、价格和刷新规则见[商店.md](商店.md)。逐件等级、基础价格、属性、全部配方和被动效果见[装备逐件设计.md](装备逐件设计.md)。

## 成品武器三合一（已接入源码）

全部 23 件 `kind: "finished"` 成品支持强化 Lv.1～Lv.3，包括先锋盾、动力鞋和撒旦之邪力；只有组件、中间件不参与。每件成品都保留固定配方，资格不因输出、防御、鞋或吸血定位而改变。波间商店或满格宝箱整理可手动免费合并 3 件同名同级武器，生成 1 件高一级武器，释放 2 格；满 12 格仍可操作，Lv.3 封顶。商店集中展示一组一份的预览，至少 6 件时可批量处理本次同名同级组，不自动跨级。固定配方与商店直购只产生 Lv.1，购买并升阶是购入一级后与已有两件合并，强化等级不改变基础等级或合成阶段。

可加属性按 1／3／9 倍保留投入，卖价按一级卖价的 1／3／9 倍计算；同类被动只取最强一份。升阶整体替换三个实例，当前生命、法力、材料、技能冷却和被动触发间隔保持不变。商店可预览结果、有效属性上限和释放空位；HUD、暂停与图鉴读取同一份强化结果。各级数值、战斗特效和验证要求见[成品武器升阶设计](成品武器升阶设计.md)。Lv.2 雷锤已完成真实获取、满格三合一、守恒核对及第 15 波闪电观察，见[游戏 README](../../README.md)。Lv.3、其余成品高阶、两主题完整特效矩阵和长局平衡仍待验证；隔离检查不替代这些范围的实战。

## 继续逐件设计

新增成品武器或补齐既有成长时，先按[新增武器工作流](新增武器工作流.md)创建／定位工作项，再同步设计和交付 Lv.1／Lv.2／Lv.3。逐件核对成品有固定配方，finished ID 集合与 `EQUIPMENT_UPGRADES` 键集合完全一致；组件和中间件不参与，未完成等级必须明确记录。
