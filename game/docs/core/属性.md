# 统一伤害与属性

## 统一结算契约

DotaRogue 仍使用统一的最终伤害结算，不区分物理伤害、魔法伤害或对应抗性；但普通攻击与技能有明确的成长轴。普通攻击读取 `attackPower`，英雄技能、法术型装备和装备召唤读取 `skillPower`。近战、远程、范围、穿透、弹射、控制和召唤属于机制，不决定伤害类型。

本轮契约由工作项 `RUslyllsEtU6MJCn7Ll2` 维护。运行定义位于 `../../static/dotarogue/js/heroes.js`、`equipment.js` 与 `buffs.js`；统一数值结算位于 `../../static/dotarogue/js/combat-damage.js`，战斗编排位于 `../../static/dotarogue/js/game.js`。本文说明结算规则，源码接入、真实入口验证和未覆盖范围分别记录在工作项与[游戏 README](../../../README.md)。

九名英雄各自配置初始生命，法力从 100／100 开始、基础每秒回复 3。生命与法力作为角色资源保存在 `run.player`；其他成长使用下列 `run.stats` 字段。

| 属性（源码字段） | 公共初值 | 作用 |
| --- | ---: | --- |
| 攻击力 `attackPower` | 0 | 只增强所有英雄的基础普通攻击；影魔收魂作为额外攻击力计入一次。 |
| 技能伤害 `skillPower` | 0 | 增强英雄技能、法术型装备和装备召唤的技能伤害系数；只有智力提供通用技能伤害。 |
| 伤害增幅 `damage` | 0% | 所有未结算伤害乘 `max(0.1, 1 + 伤害增幅 / 100)`，每个伤害事件只应用一次。 |
| 护甲 `armor` | 0 | 统一降低所受伤害；无其他减伤时使用 `15 / (15 + max(-5, 护甲))`，适用于接触、弹丸、技能与陷阱。 |
| 移速 `speed` | 0% | 基础速度 215，按百分比调整；化学狂暴与剑刃风暴另有短时增益。 |
| 基础攻击范围 `attackRange` | 0 | 加到每名英雄基础攻击的目标搜索范围及远程弹丸飞行范围；矮人火枪手被动另加 140。 |
| 攻速 `attackSpeed` | 0% | 基础间隔除以 `1 + 攻速 / 100`，实际间隔最短 0.09 秒。 |
| 暴击率 `crit` | 5% | 仅本人普通攻击直接命中判定暴击，概率上限 90%。 |
| 暴击伤害 `critDamage` | +80% | 暴击倍率为 `1 + max(0, 暴击伤害) / 100`，初值为 1.8 倍。 |
| 普攻吸血 `lifesteal` | 0% | 所有英雄本人普通攻击按实际扣除的敌人生命回复；与撒旦短时增益合计上限 65%，溢出伤害不回复。 |
| 主动技能冷却缩减 `abilityHaste` | 0% | 成功施放后计算主动冷却，最多按 60% 缩减。 |
| 闪避率 `dodge` | 0% | 受击前判定，上限 55%。 |
| 生命回复 `regen` | 每 5 秒 0 | 每 5 秒回复对应生命。 |
| 拾取范围 `pickup` | +0 | 材料与宝箱基础吸附范围 75，加上该值。 |
| 幸运 `luck` | 0 | 影响额外材料和商店永久 Buff 品质；不直接提高宝箱掉率。 |
| 法力回复 `manaRegen` | 每秒 3 | 战斗进行时持续回蓝；虚无宝石与坚韧球等装备可增加。 |

普通攻击原始伤害为该英雄基础值加 `attackPower`；英雄技能、法术型装备和装备召唤使用各自的基础伤害与 `skillPower` 系数。英雄技能另应用其等级档位及主动强化，均只计算一次。装备或 Buff 若明确标注为普攻触发，则继续读取 `attackPower`；两条轴不会在同一公式中重复计入。

未结算伤害统一应用伤害增幅、目标身上的暗灭标记、强袭光环范围增幅，以及符合资格时的暴击。正伤害四舍五入后至少为 1；无效或非正伤害不制造命中。Luna 月刃、弹无虚发和刃甲使用已经结算的伤害快照，不再重复放大或暴击。伤害来源用于规定触发资格，不引入新的伤害类型。

## 机制与触发边界

- 近战扇区、远程弹道和地形穿透分别由攻击定义决定。众神之王与召唤师的穿地形是独立机制，不能从伤害类别推导。
- 本人普通攻击可以暴击、普攻吸血并触发装备命中效果。装备追加、幻影、召唤、Buff 与弹射不回流普通攻击被动或计数。
- 血精石使用英雄技能来源的技能吸血；范围与持续伤害保留 25% 效率和滚动一秒回复上限。它不再通过普攻外观区分适用英雄。
- 吸血羁绊仍按所有来源的实际扣血独立回复，并保留其滚动一秒上限；尸体、溢出伤害和满血不消耗额度。
- 护盾、格挡、闪避、减速、击退、召唤数量和攻击频率保持各自的规则，统一伤害不会把它们折算成单纯攻击力。

## 属性迁移与验证边界

### Dota 三属性（Current：源码接入，2026-10-29）

英雄与装备现在额外拥有力量、敏捷、智力三项属性。属性分别派生 `attackPower`、`skillPower`、生命、攻速、护甲、回蓝和冷却缩减；不再使用“主属性才提供攻击力”的门槛，三种属性都按表中数值直接生效。

| 属性 | 派生值 |
| --- | --- |
| 力量 | 每点最大生命 +3、每 5 秒回血 +0.2、普通攻击力 +0.4。 |
| 敏捷 | 每点攻速 +1.5%、护甲 +0.15、普通攻击力 +0.4。 |
| 智力 | 每点普通攻击力 +0.4、技能伤害 +1、每秒回蓝 +0.12、主动与装备冷却缩减 +0.75%。 |

技能伤害不是物理／魔法抗性类别，而是专门给技能路线使用的成长轴。法师技能和红杖、风杖、死灵书、陨星锤等法术型装备按 `skillPower` 及各自技能伤害系数结算；普攻装备仍按 `attackPower`。力量和敏捷暂不提供通用技能伤害，只保留未来英雄专属技能读取它们的空间。智力带来的冷却缩减作用于主动技能及支持该规则的装备内置冷却，最高按 60% 计算。

英雄初始属性与装备属性定义分别位于 `heroes.js` 和 `equipment.js`；成品装备强化沿用 1／3／9 倍属性规则。生效装备提供属性，待用储备不提供；整理、交换和合成按差量应用一次。

2026-10-29 的真实入口记录属于前一版属性构建：当时召唤师由智力 7 增至 9，法力上限由 128 增至 136，回蓝由 3.84/s 增至 4.83/s，读数为攻击力 6.8→10.6、技能伤害 7→9。当前契约已改为三属性分别派生普通攻击力与技能伤害，实际初始读数应以当前 `hero-attributes.js`、暂停页和本轮真实入口复核为准。红杖技能伤害与内置冷却已通过源码断言和设计工作台受控观察；接续构建另核对 1470×684、390×844 与 844×390 暂停页的主属性标识和最多两位小数显示，影魔零灵魂时收魂攻击显示 +0。自然获得红杖后的完整战斗触发、自然储备交换和长局平衡仍待复核。本节的源码接入不替代这些验证证据。具体范围见游戏 README 的[本轮验证记录](../../../.logs/actual-test/dota-attributes-20261029/report.md)。

旧 `attackDamage` 与 `elemental` 不再作为运行属性并存；普攻相关贡献合并为 `attackPower`，法术相关贡献改由 `skillPower` 单独承载。原有配方、价格及三级 1／3／9 属性守恒规则继续适用。局内对局不持久化，浏览器只保存设置和战绩，因此不需要保留旧攻击属性的存档别名。

升级池提供普通攻击力成长；卡尔的法术数量成长跟随该攻击力选项，最高保留三档。统一后装备覆盖的攻击来源增加，现有价格与系数的长期平衡仍需自然长局验证。自动检查与工作台受控观察不能替代真实获取、升级、战斗、暂停和移动流程。
