# 击杀成长装备设计

**状态：Current：源码与原图资源接入，2026-10-29。** 用户已授权把封神之刃、灾星之戒加入游戏，并确定图标直接采用对应 Dota2 游廊原图；两件方案已进入装备定义、商店、图鉴和战斗源码，两张 88×64 原图及名称映射也已核验并接入。来源、版本、哈希与权利状态见[游廊装备图标](../sources/art/dota2-arcade/README.md)。完整自然成长、升阶／储备／重买和长局平衡仍按当前构建独立验收；实际覆盖回源[游戏 README](../../README.md)，当前运行数量与能力以源码和[装备](装备.md)开头的 Current 段为准。

目标体验是“尽早拿到一件能用的装备，带着它战斗，看到它逐步觉醒”。保留现有固定配方、三件同名同级合一至 Lv.3、12 生效格及待用储备；成长点另外记录，不成为第四个强化等级，也不增加新的操作按钮。

本轮范围为击杀成长两件。狂月之光、三相之力不纳入本次物品池；不新增物理／魔法攻击属性、抗性或永久局外成长。工作项为 `RUNXE6YJb1iiwI3MSYJO`。

英文为本作暂译，不声称是参考游戏的官方名称。“普攻／主动”只描述触发方式，全部平值攻击与伤害遵循[统一伤害契约](属性.md)。候选两件首版均记为“独立·成长”，暂不增加现有六类羁绊成员，避免同时引入未评估的套装收益；已有全伤害、通用易伤与全来源吸血仍依照各自规则生效。

## 共同成长规则

### 成长点与门槛

| 累计成长点 | 成长阶段 | 被动成长系数 `q` | 下一目标 |
| ---: | --- | ---: | --- |
| 0～59 | 初铸 | 0.25 | 60 点 |
| 60～179 | 聚魂 | 0.50 | 180 点 |
| 180～359 | 铭刻 | 0.75 | 360 点 |
| 360 | 觉醒 | 1.00 | 已满成长 |

- 一次有奖励资格的自然敌人死亡，普通／精英／首领分别给 **1／3／6 点**。资格为死亡结算的 `rewards === true && !enemy.summoned`，复用现有精英判定；不按材料价值、外形或末击伤害类型猜测。
- 击杀当下，至少一件该名称装备位于生效格，才给该名称的成长账本记分。只有组件或只有储备不成长，不追溯取得前、全部离场期间的击杀。
- 普攻、英雄技能、合法装备追加和其他允许奖励的伤害，都能贡献进度。两条路线由收益区分，不抢特定来源的最后一击。同一自然死亡可分别给同时生效的两件候选各记一次；同名多件仍只记一次。
- 敌方召唤物、分裂子体及 `rewards:false` 击杀不计。死灵书友方召唤目前不产生奖励；TB 魔影虽然同属 `summon` 来源，允许奖励的自然击杀仍可计分，不能一概排除召唤来源。
- 分数累计后取 `min(360, score + points)`，阶段从累计值推导。179 点击杀精英变 182 点，359 点击杀首领封顶 360；没有可交易的溢出点、循环奖励或局外继承。
- 记分本身只更新进度与阶段提示，不立即释放伤害。普攻出手时捕获该次被动快照；Q 尝试开始时只捕获局部快照，必须早于原 Q 首个伤害或增益，失败则丢弃，成功后使用该快照。快照包括是否生效、强化等级、成长系数与原始伤害／攻击力；该次事件造成的成长只影响此后的新事件，不回溯强化已经发出的弹丸或正在结算的伤害。

这些门槛是首版试作值，不承诺任何模式第几波必然觉醒。标准／速战、难度与取得时机的差异列入后续自然局验证。

### 重复、储备与三合一

每局按装备 ID 保存一份共享成长账本，实例只保存现有身份与强化等级。两件候选账本独立，进度既不存入可加属性，也不按实例累乘。

| 操作／状态 | 成长进度 | 属性与被动结果 |
| --- | --- | --- |
| 同名两件／三件生效 | 同一进度，成长速度不变 | 固定属性逐件累加；成长被动只取生效装备中的最高 Lv. 一份 |
| 全部移入储备／卖完 | 保留，不继续累计 | 固定属性、成长被动和该物品的触发全部停止 |
| 同局重买／重新装备 | 恢复原进度，不补算离场击杀 | 恢复对应阶段的被动，不额外治疗、回蓝或重置冷却 |
| 三件同名同级合一 | 读取原账本，不相加、不平均、不清零 | 固定属性和总卖价按 1／3／9 守恒，使用新等级被动，释放两格 |
| 高等级在储备、低等级生效 | 共用进度 | 只使用生效的低等级参数，储备不能抬高等级 |
| 新局／重新开始 | 归零 | 不改变现有设置和战绩格式 |

在途普攻另外约定：出手时没有生效封神之刃则快照为空，后来取得不追溯附加；出手时有，但命中时已全部离场，则跳过追加；命中时仍有同名生效件，才使用出手快照，不能改读后来成长或强化后的参数。成长是否记分始终以敌人死亡当下的生效状态判断。

例：三件一级封神之刃共享 180 点，合成前共攻击力 +42、攻速 +24%，只触发一份一级被动；合成后仍为 180 点、攻击力 +42、攻速 +24%，被动升到二级，成长点不变成 540 点。卖出觉醒装备也不增加售价。

## 封神之刃：普攻养成

### 固定属性与经济

| 参数 | Lv.1 | Lv.2 | Lv.3 |
| --- | ---: | ---: | ---: |
| 攻击力 | +14 | +42 | +126 |
| 攻速 | +8% | +24% | +72% |
| 满成长追加伤害系数 `r` | 0.25 | 0.35 | 0.45 |
| 卖价 | 40 | 120 | 360 |

### 被动“封神印”

每次本人普通攻击的**首个有效直接命中**，对该目标追加 `B × r × q` 基础伤害，`B` 为这次普攻暴击前、全伤害与目标易伤前的原始伤害。随后按装备来源应用一次统一伤害修正与取整。近战挥砍命中多人、散弹、贯穿或同一个攻击的后续直接命中，都不再次触发。

| 强化等级 | 初铸 | 聚魂 | 铭刻 | 觉醒 |
| --- | ---: | ---: | ---: | ---: |
| Lv.1：占 `B` | 6.25% | 12.50% | 18.75% | 25% |
| Lv.2：占 `B` | 8.75% | 17.50% | 26.25% | 35% |
| Lv.3：占 `B` | 11.25% | 22.50% | 33.75% | 45% |

- 原普攻及全部既有命中后续按当前顺序完成，包括英雄与既有装备的命中反应，最后才尝试封神印；若首目标已经死亡，则跳过追加，不能转移到下一人，也不用尸体制造二次奖励。首个有效命中的资格仍已消耗。
- 追加伤害为 `equipment`，不是新的普攻；不继承主攻击暴击、不触发普攻／技能吸血、不触发命中被动、英雄普攻计数、幻影或再次封神印。独立的全来源吸血按实际扣血及原上限处理。
- Luna 弹射、弹无虚发、风怒、TB 魔影、分身斧镜刃和其他派生攻击不触发。没有每件独立概率或额外攻速乘区，最高攻速沿用现有 0.09 秒间隔。
- 每次攻击按 `attackId` 去重，复用装备战斗已有的去重入口；不另建无限增长的攻击历史。

这件装备的定位是对存活目标持续补伤，不增加穿地形、击退、处决或范围分裂。成长也不直接增加通用攻击力，避免同时放大所有技能和装备的系数。

## 灾星之戒：施法养成

### 固定属性与经济

| 参数 | Lv.1 | Lv.2 | Lv.3 |
| --- | ---: | ---: | ---: |
| 技能伤害 | +8 | +24 | +72 |
| 最大法力 | +25 | +75 | +225 |
| 每秒回蓝 | +1 | +3 | +9 |
| 满成长单次总基础预算 `T` | `24 + SP × 0.4` | `48 + SP × 0.5` | `72 + SP × 0.6` |
| 最多追击目标数 | 1 | 2 | 3 |
| 独立触发间隔 | 8 秒 | 8 秒 | 8 秒 |
| 目标搜索范围，世界单位 | 500 | 500 | 500 |
| 卖价 | 42 | 126 | 378 |

`SP` 使用本次 Q 尝试开始、原 Q 首个伤害或增益之前捕获的技能伤害快照；失败施法的快照直接丢弃。实际本次追击总基础预算为 `T × q`；成长增加预算，强化等级还增加目标数。即使刚取得、0 点进度，一级追击也有 `6 + SP × 0.1` 的基础预算。

### 被动“灾星追击”

1. 只在本人 Q **成功施放**的公共节点尝试，使用施法前快照。原 Q 及其既有成功施法反应（包括紫苑引爆、激励）保持当前顺序完成，再选择戒指目标；不能在成功钩子重读已经被原 Q 击杀提升的成长参数。兼容炼金的自强化、TB 的变身和卡尔回响，不要求 Q 本身造成伤害。被动自动施法、回响的内部法术、多段命中和持续伤害不增加触发次数。
2. 装备生效、独立间隔已结束且人物存活时，在玩家中心 500 范围内选择存活且地形无遮挡的目标。所有目标按中心距离 `<= 500 + enemy.r` 检查，阻挡复用现有真实地形检测；主目标优先首领、再精英、再普通，同档选最近；副目标从剩余合法目标中按距玩家由近至远补齐，同距沿当前敌人遍历顺序。每人本次只选一次。
3. 在本次合法目标列表上分配总预算：主目标权重 2，副目标各 1，以**实际目标数**归一化。只有一个目标时获得全部 `T × q`；两目标按 2:1；三目标按 2:1:1。每个目标随后各自应用一次统一修正；取整及不同目标易伤会使实际总扣血与基础预算不同。
4. 追击是瞬时结算的装备攻击，表现为从玩家指向已选目标的星芒连线；不额外发射可命中的弹丸，不重复执行 Q。成功选中至少一个目标时立即写入 `readyAt = run.totalTime + 8`，再结算伤害，避免同步回调重入。
5. 没有目标时不消耗戒指就绪；原本合法的 Q 照常成功、耗原有法力并进入原冷却。下一次成功 Q 再尝试，不自动追击、不排队、不囤多次充能。失败 Q、蓝量不足、冷却中按键、卡尔无记录或目标无效导致的失败都不尝试追击。

追击不受蓝杖主动倍率、英雄技能等级倍率或技能吸血影响，不回流普攻与装备触发；伤害来源为 `equipment`。8 秒独立间隔不受主动冷却缩减影响，也不加入激励当前可推进的四种装备计时器。若原 Q 已触发激励，它仍按原规则执行，不因戒指被动不存在目标而取消。

计时器归该装备 ID 的局内状态所有。同名多件、三合一、切入储备或重买不重置；战斗时间正常经过可自然完成间隔，暂停、商店和读秒遵循当前游戏时钟，不用墙上时间绕过冻结。新取得时就绪，同局重新取得沿用旧计时器。

## 获取、成本与现有装备比较

- 两件都是三个现有组件的固定配方，3 格合 1 格、合成不另收费；生效格和储备共同取料，复用双目标追踪、自动合成、购买并合成和满格进入储备的规则。固定配方及直售只产出 Lv.1。
- 大剑、精气之球属于现有二级组件，按当前组件池从完成第 3 波后的商店具备抽取资格。新品不单设新波次锁，直售概率沿用成品池；这不保证第 3 波必然拿到，也不保证抽到指定组件。
- 原料基础价合计分别为 52、53，卖价 40、42 均低于原料基础价合计。实际购买按现有逐件波次涨价与无尽倍率计算，不把原料基础价当固定实购成本；成长点不影响购买、卖出或拆解金额。
- 标准非无尽、完成第 3 波时，若三个材料都在该次商店以现有公式购买，逐件取整后合计分别为 64、65；两成品直售分别为 84、88。这里只是定价公式样例，不声称同店实际出现或自然取得。

| 现有对照 | 立即收益与差异 | 新品需要保住的边界 |
| --- | --- | --- |
| 大炮，基价 92 | 立即提供攻击力与暴击收益 | 下述样例中觉醒封神一级的持续单体收益接近对照；初期应弱一些，不能兼得群伤与暴击放大 |
| 红杖，基价 64 | 每 6 秒自动爆发 | 灾星追击要求成功 Q、独立 8 秒间隔，满成长基础预算低于同级红杖；不自动补射 |
| 蓝杖，基价 84 | 已有主动强化、资源与冷缩 | 戒指不重复放大原 Q，也不吃蓝杖倍率；以额外追击适配非伤害 Q |
| 紫苑，基价 82 | 普攻挂标记后 Q 引爆 | 戒指不需要先挂标记，代价是进度投资和独立间隔；两者分别按原来源结算 |

一个用于讨论的连续值样例：火枪基础普攻 9，其他攻击力 +40，无其他增幅／攻速，公共暴击率 5%、暴击伤害 +80%，目标始终存活且无易伤。归一到每个基础攻击周期，一级封神初铸／觉醒期望总伤约为 **75.01／87.77**，一级大炮约 **87.86**。忽略逐段取整、首目标提前死亡、实际攻击节奏和其他被动；这是公式对照，不能当实测 DPS 或平衡通过。

## 展示与反馈目标

本节的展示要求已接入现有 UI：商店、库存、HUD、暂停、图鉴和无脚本说明读取同一份成长状态；没有另设养成页面。自然长局和所有门槛仍待真实验收。

| 消费者 | 应显示／支持的内容 |
| --- | --- |
| 商店、配方与升阶预览 | 固定配方、当前 Lv.、当前阶段和点数、下一门槛、当前实际被动；重买时显示保留进度；升阶预览明确“进度不变” |
| 库存与储备 | 同名同级仍按数量聚合，成长只显示一份；储备明确“不生效／不增长”；生效与储备不要展示成不同进度 |
| 战斗 HUD | 在现有装备信息内显示阶段及进度，不在战场中新增大面板；到达门槛时给一次短提示，不逐次击杀弹提示 |
| 暂停 | 显示各自成长点、阶段、实际系数；戒指额外显示就绪／剩余间隔，暂停时保持不变 |
| 图鉴与工作台 | 图鉴列三级固定属性、四阶段矩阵、资格和经济，未开局默认展示规则而非虚构对局进度；工作台可受控选择 Lv. 和阶段，明确不计作自然获得 |
| 无 JavaScript | 图鉴静态文字可读配方、强化与成长关系、门槛及被动限制；游戏仍沿用原有需 JS 的基础说明 |

简体、繁体、English 用同一份成长定义生成实际值，不在各消费者复制门槛或矩阵。短文案为“成长 179/360 · 聚魂 · 距铭刻 1 点”；满成长为“成长 360/360 · 觉醒”。成长名称与 Lv. 强化、品级颜色分开，不能把阶段再次显示为 Lv.4。

反馈设计：封神印使用目标命中点的小型刻印与短斩痕，戒指使用玩家至实际目标的星芒线；一级／二级／三级以 1／2／3 道可辨细节表达强化，成长阶段以刻印完整度表达，觉醒不扩大实际判定范围。封神单次装饰不超过 0.18 秒、同屏最多 8 份；戒指连线不超过 0.24 秒、一次最多 3 条；门槛提示 0.6 秒、同帧两件合并为一条。它们是待测预算，不能宣称已经达标。

所有装饰消费已经发生的结算事件，不调用伤害。正常两种角色皮肤及工作台两主题都保持可辨，减少动态效果保留静态命中标记、停止非必要闪动；暂停冻结，新局和离场清理。战斗刻印、斩痕与追击线继续按本节的事件反馈目标设计，物品图标按下节直接采用原图。

## 接线事实与风险

| 所有者 | 目标变化 |
| --- | --- |
| `equipment.js` | 两件定义、配方、三级固定属性／被动、三语言名称和说明；所有 finished 集合与升级表保持一致 |
| `equipment-combat.js` | 复用普攻去重和成功 Q 入口，维护两份局内账本、最高生效等级及戒指就绪时间；普攻与 Q 均在事件开始时捕获快照 |
| `game.js` | 自然死亡结算一次通知；开局清空、整理同步、参数快照，以及商店／HUD／暂停读数；失败 Q 不触发戒指追击 |
| 图鉴、工作台及现有战斗反馈消费者 | 消费同一份阶段定义与真实事件，保留自然局和受控观察边界；六张已核验游廊 PNG 从 `static/dotarogue/` 的同一图标映射读取 |

方案不增加网络请求、账号、服务端、浏览器存档字段或外部依赖；只有现有单页运行中的状态与调用变化，不触发跨系统时序图。当前实际工程路径和入口继续沿用，不新增兼容地址。

主要风险是早期强势取得更多击杀形成滚雪球、速战成长偏慢、无尽过早封顶，以及高攻击力下追加伤害叠加现有装备。优先通过门槛和来源限定系数调整，不用无限叠层或新增全局攻击力解决。缺点也需真实验证：封神可能因原攻击已秒杀而少触发；戒指可能因 Q 间隔长或无目标而收益不足；同价蓝杖可能明显更优。

后续验证须从 `game/static/index.html` 真实取得材料、合成、战斗成长、升阶及重新装备，覆盖 59→60、179→180、359→360、重复持有、储备、出售重买和两件共持；用火枪／剑圣检查两种普攻，用卡尔／炼金／TB 检查伤害、回响、自强化与变身 Q。两主题、三语言、桌面键鼠、手机横竖触控、暂停、资源与控制台另行验收。公式检查、工作台注入与旧版截图均不能代替这些流程。

本轮此前构建已从真实选择页进入对局，在第 4 波商店以 32 材料买精气之球后自动合出灾星之戒，第 5 波商店以 29 材料买大剑后自动合出封神之刃；灾星成长曾显示 29/360，第 6 波成功 Q 后暂停显示独立间隔 8.0 秒。该自然局早于最终命中钩子修复，只证明当时的取得与可见读数，不能证明最新修复或上述完整成长链路；当前构建的最终覆盖与未完成项由[游戏 README](../../README.md)及工作项测试记录维护。
