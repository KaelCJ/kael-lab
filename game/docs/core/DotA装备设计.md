# DotA 装备资料与本作边界

本文只保留回源入口和采用边界，不保存旧的全量装备提案。DotA Allstars 6.60b 的名称、历史效果和历史配方见仓库资料[装备对照与合成表](../dota/装备.md)；它是原作资料，不是《DotaRogue》的当前物品清单。

本作当前源码定义的装备、数值、固定配方和效果以[装备逐件设计.md](装备逐件设计.md)为准：**21 件基础组件、5 件中间件、23 件成品，共 49 件装备与 28 条配方**。各路线共用统一攻击力与伤害结算，以机制区分：雷神之锤、狂战斧、大炮、蝴蝶提供连锁、近战分裂、暴击和攻速；先锋盾、撒旦之邪力、魔龙之心、刃甲提供格挡、普攻吸血、恢复和反伤；蓝杖、红杖、血精石、紫苑提供主动强化、周期爆发、技能吸血和标记引爆。动力鞋／相位鞋提供机动分支，风杖与死灵书提供近身控制和召唤。商店少量直售中间件／成品，宝箱只给基础组件；12 格容量，配方手动免费合成，**没有卷轴物品或卷轴材料，配方不占格**。成品基础等级涵盖 3～5，与独立强化 Lv.1～Lv.3 分开。

沿用 DotA 中文与英文装备名是经确认的命名方向；配方结构、效果、价格、等级和数值按本游戏玩法改编，不能从原作资料直接推断本作行为。风杖与死灵书已随本次八件扩充进入源码，完整原作物品池仍未整体进入；宝箱继续只给基础组件。旧六武器槽、旧改装商品和卷轴提案不再是本作规则；当前全成品同名同级三合一是十二格体系中的独立成长规则，见[成品武器升阶设计](成品武器升阶设计.md)。

上述数量和规则已在源码接入；最终构建的宝箱、购买、合成、持有被动、出售与高波经济仍待从真实游戏入口完成验收。
