# 声音系统

## 当前实现（Current：2026-10-27）

`game/static/dotarogue/js/audio.js` 使用 Web Audio 播放本地经典录音，缺项或加载失败时使用原有合成音与 Speech Synthesis 短句。`game.js` 只在真实事件成功后调用；所有文件随静态站点提供，不依赖运行时外网。

`game/static/dotarogue/assets/audio/dota1/` 当前共 20 文件、191,502 字节：八名英雄各有选择／行动两条短语音（16 条），另有火枪、刺击、天神下凡、德鲁伊熊形态四个音效。对应矮人火枪手、山丘之王、炼金术士、剑圣、火焰领主、血法师、女猎手、恶魔猎手原型。刚背兽没有已确认的野猪人台词，继续合成回退。原录音保持英文，不伪装为三语言配音；三语言仅作用于现有回退短句和界面。

## 限流与生命周期

样本异步加载后核对当前代次、开关、暂停与事件年龄；音效超过 450ms、语音超过 1800ms 丢弃，避免迟到补播。非语音样本最多 24 个同时播放，普通战斗声共享 90ms 间隔，同种事件至少 60ms。角色短句有全局与单事件间隔；选人、开战、低生命和结果可越过普通全局间隔。

静音、暂停、重开和返回标题立即停止声音源并取消浏览器语音；暂停同时暂停音频上下文，恢复从下一条真实事件开始。切换语言取消旧短句。解码失败回退，构造异常不外溢到战斗；浏览器能力缺失时玩法仍能继续。

## 验证边界

文件已通过 PCM 解码、非零信号、哈希和本地 HTTP 检查。浏览器真实入口与声音输出验证记录回源 [游戏 README](../../README.md)及声音工作项；文件解码、受控 API 检查与真实对局分别记录，不把它们当成人耳听测或所有设备一致。密集音效听感、真实手机和长局仍需独立验证。
