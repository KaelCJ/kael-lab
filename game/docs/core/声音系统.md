# 声音系统

## 当前实现（Current：2026-11-05）

`game/static/dotarogue/js/audio.js` 使用 Web Audio 播放本地经典录音，音效缺项或加载失败时使用原有合成音；原有八英雄保留缺项 Speech Synthesis 回退，刚背兽只播放原版录音，未映射或失败的事件保持静默。`game.js` 只在真实事件成功后调用；所有文件随静态站点提供，不依赖运行时外网。

`game/static/dotarogue/assets/audio/dota1/` 当前共 26 文件、228,447 字节：八名英雄各有选择／行动两条短语音（16 条），刚背兽新增选择、行动和攻击各两段野猪哼声（6 条），另有火枪、刺击、天神下凡、德鲁伊熊形态四个音效。刚背兽的 `RazorMane` 音组与 `Bristleback` 共用这批声音文件，已由公开6.83d重建地图的英雄字段和原始声音表交叉核对，详见[来源说明](../sources/audio/dota1/README.md)。六段共36,945字节，保留源字节，不变调或重编码；三语言共用原音，不翻译为中文台词。其他八英雄经典录音保持原英文。

## 限流与生命周期

样本异步加载后核对当前代次、开关、暂停与事件年龄；音效超过 450ms、语音超过 1800ms 丢弃，避免迟到补播。非语音样本最多 24 个同时播放，普通战斗声共享 90ms 间隔，同种事件至少 60ms。角色短句有全局与单事件间隔；选人、开战、低生命和结果可越过普通全局间隔。

刚背每类事件在对应两段原音间交替轮换，重开重置；节流拦截的事件不推进序号。首次选择只预取两段选择音，开战和施法分别补各自一对，避免选人就加载全部音频。仍沿用0.72播放增益与单语音源，既有八英雄的录音和缺项回退行为不变。

静音、暂停、重开和返回标题立即停止声音源并取消浏览器语音；暂停同时暂停音频上下文，恢复从下一条真实事件开始。切换语言取消旧短句。解码失败回退，构造异常不外溢到战斗；浏览器能力缺失时玩法仍能继续。
