# DotaRogue · 角色图片创作流程

## 当前角色视觉政策

角色视觉不设必须原创的通用约束。用户指定 Warcraft III／DotA1 原型时，可以精确参考角色轮廓、武器、动作、施法姿势和特效；也可以接入已核对来源与许可证的外部资源。引入外部文件时，在角色 `manifest.json`、README 或制作记录中写明来源、许可证和改动范围。玩法数值、剧情、台词、音效和实际运行状态仍以本作代码与公开记录为准。

本文件下面的 Lanox 提示词和“从头重绘”文字是已有 Concept 产物的历史生成记录，不是当前角色视觉政策。新提示词应单独使用新版本，明确允许的 War3／DotA1 参考范围；不要回写旧任务的实际提交内容。

## 当前出图路线

六名英雄的首图使用用户已明确指定的 Lanox Image2 和现有本机 Lanox 凭据。模型为 `lanox-image-2`。此前“内置 image_gen 不可用”的事实只说明该工具不可调用，不代表现有 Lanox 图片接口不可用；等待该工具或重新索要 API 授权的旧停点已被本次用户指令替代。

本阶段的 AI 首图路线不使用 SVG：角色首图和缩小预览均为真实生成图片派生的 PNG。运行资源另按当前 9 帧 SVG 流程制作并接入 Canvas，不以首图 PNG 代替运行动画。

用户随后明确要求“AI 作图一次，再用 SVG 作图一次”时，允许在独立的 `art/comparison/` 制作同题对照：一张真实 Lanox Image2 图与一张新编写的可编辑 SVG。SVG 只能标为代码绘制对照，不能冒充 AI 生成图；本次例外不把其他英雄的首图路线改回 SVG。剑圣的共同题目见[同题对照 brief](../characters/jugg/art/comparison/comparison-brief-v1.md)。

本次剑圣对照的新 AI 任务与一次重试均因 `model_service_unavailable` 失败，当前使用上一轮真实 AI PNG 与本轮新绘 SVG 审阅。需明确标注两者来源，不能称为两张按本轮相同提示词新生成的图。实际产物见[AI／SVG 对照记录](../characters/jugg/art/comparison/README.md)。

已核对 Lanox Image2 的既有客户端协议，并确认当前本机凭据来源可用。凭据只在本机进程读取，不进入公开仓库、图片、提示词、消息或日志。本机调用入口由续接 session 提供，公开仓库只保存美术提示词、图片和不含秘密的制作记录。

## 旧图的实际来源

当前 `game/static/dotarogue/assets/art/` 的初版与像素图属于另一条旧制作路线（迁移前位于 `game/art/`）。已从归档制作记录核对：初版直接编写 SVG；角色、武器、敌人、技能与地图像素资源由 Python 的色板、矩形或多边形绘制后导出 SVG。浏览器截图与拼版只是预览，不能当作模型出图证据。这些旧图未被证明通过 Lanox Image2 生成，本次六名英雄改用真实 Image2 位图创作。

## 图片任务与产物

1. 读取本角色的 `art/concept/<id>-idle-v1.prompt.md`，保留 DotA1／War3 原型和 Kingdom Rush 的精致手绘小角色方向。每名英雄独立生成一张全身待机图；炼金术士完整包含地精与食人魔搭档。
2. 创建真实 Lanox Image2 异步任务：`POST https://api.lanox.ai/api/v2/lanox-images/generations`；使用模型 `lanox-image-2`、`aspect_ratio=3:4`、`resolution=2k`、`n=1`。使用稳定的幂等键；已有任务只继续查询，不因等待而重复创建。
3. 按返回的任务 ID 查询 `GET https://api.lanox.ai/api/v2/lanox-images/tasks/<id>`。`queued`／`processing` 表示等待；`succeeded` 后才下载 `data[0].url`，下载图片时不附带接口鉴权头。失败如实记录。
4. 此协议没有原生透明背景参数，先以无阴影、无渐变的纯色键背景出图，再用本机图像工具去除背景并保存真实 alpha。若原图已含有效 alpha，直接保留。原始图片保存为 `<id>-idle-v1-source.png`，所选透明图为 `<id>-idle-v1.png`；原始图与透明图都必须来自真实生成结果，已有版本不覆盖。
5. 以长边为准生成等比例的 128px／64px PNG 预览，查看原图与缩小图，核对完整身体、武器或自然武器、角色身份、轮廓可读性和背景边缘。除色键残留外，还检查浅／深背景上的半透明灰点与画布外框；清理时另存版本并保留原图。发现问题时按具体缺陷调整，避免盲目重复计费。

## 状态与接入边界

提示词、任务已创建、图片已下载、透明图已处理、视觉已检查分别记录，不能互相替代。AI 首图仍为 Concept；六名英雄的 SVG 源图、9 张静态动作帧、基础攻击和技能姿态已经进入当前游戏。完整多方向动作、长局平衡、台词和技能声音仍按各自记录区分。

六个角色各自维护自己的角色目录和工作项；公共索引、流程与运行代码由主 session 协调。只把可公开的派生图片带入本仓库，不修改作为事实来源的其他项目源码，不提交、推送或发布。
