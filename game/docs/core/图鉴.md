# 图鉴与设计工作台

本专题维护当前独立图鉴入口和加载边界。所有页面均为 GitHub Pages 可直接提供的物理 HTML，不需要服务端或运行时构建。

## 当前入口

| 页面 | 入口与职责 | 允许的领域数据 |
| --- | --- | --- |
| `catalog.html` | 标题与暂停的图鉴入口；四类目录、角色／特效设计直达链接 | 无；只读取导航文案和语言 |
| `heroes.html` | 九名角色、主动／被动、成长、卡尔六法术；搜索与折叠详情 | `heroes.js` |
| `equipment.html` | 74 件武器／装备、53 配方、三级强化、六类羁绊；商店直接进入 | `equipment.js`、`equipment-builds.js`、装备所需的 `hero-attributes.js` |
| `enemies.html` | 14 类敌人、旧战场肉山变体与三个固定中立目标；基准数值、招式、出场；搜索 | `enemies.js`、`neutral-camp-defs.js`、`jungle-buffs.js` |
| `buffs.html` | 27 种永久增益及三种野区限时增益；按类型展示效果、获取、品质／价格或时长；搜索与折叠详情 | `buffs.js`、`jungle-buffs.js` |
| `studio.html` | 一个设计工作台，分类观察角色、怪物、装备、Buff、特效、地图 | 点击进入后启动同源游戏演示 |

四类之间是原生页面链接，不使用隐藏分类 DOM、预先嵌入 iframe、跨类预取或统一大数据脚本。图片使用现有运行资源并设置延迟加载。图鉴的“在工作台观察”只提供链接，不在资料页启动设计运行时；`studio.html#category=heroes&id=kael&variant=idle` 和 `studio.html#category=effects&id=wind` 可独立直达。元素样张 `effects.html` 保持其已有设计观察语义。

标题和暂停进入总目录；商店固定配方入口直接进入武器页。暂停入口新开标签保留当前内存对局。各图鉴页与工作台均可返回游戏和图鉴目录，所有链接保持相对地址，支持项目子路径部署。没有新增别名或重定向页。

## 数据所有权

角色与 Buff 读取和游戏相同的模块。怪物的基础配置、精英轮换、波次与三语言名称由 `enemies.js` 拥有，游戏与怪物图鉴均消费；提取不改数值。怪物卡片明确展示生成前基准值，实际生命、伤害和速度受波次、难度、无尽压强等影响。经典图固定红／蓝守卫和固定肉山的配置归 `neutral-camp-defs.js`，三种限时收益归 `jungle-buffs.js`；两模块从 `neutral-camps.js` 原文提取为纯数据，游戏和所属图鉴共用。图鉴不导入营地战斗函数。经典固定肉山和旧战场第20波变体分别标注，限时收益不标成商店可重复购买的永久 Buff。招式说明以当前 `game.js` 为准，不把场景布景或未来计划标为当前能力。

## 图鉴导航与语言契约

稳定 ID：`dotarogue-catalog-ui`。所有者是 DotaRogue 图鉴，源码为 `js/catalog-ui.js`；样式为 `css/catalog.css`，均留在游戏私有目录。

- `readCatalogLocale()` / `writeCatalogLocale(locale)` 读取、更新原存档 `kael-lab-starcore-survivor-v1.settings.locale`，只接受简体、繁体和 English，保留战绩与其他设置；存储不可用时仍可浏览。
- `initCatalogPage({ copy, render })` 更新当前语言、标题、导航、搜索、空态与计数；回调 `render(locale, query)` 由各页创建所属卡片。共享模块不导入领域数据、不持有对局或工作台状态。
- 当前消费者：目录、角色、怪物、Buff 页使用初始化协议；武器页复用语言存储函数，保留其原有装备详情交互和私有布局。
- 正式游戏、工作台与元素样张有不同交互和状态，不接入图鉴卡片协议。入口、回调、DOM 标识或存储键变化时，须同步全部五页及导航消费者。

## 验证

从游戏选择页进入标题、图鉴目录，再分别进入四类；检查搜索有结果／空态／清空、键盘折叠和选择、三语言、桌面与手机横竖屏、返回链接、图片、控制台和无脚本基础内容。使用真实页面资源清单核对未请求其他分类与游戏运行时；静态模块依赖检查只作为补充。工作台对象直达、播放与暂停单独验收。图鉴隔离不等同真机帧率或弱网加载秒数改善，具体覆盖见本轮验证记录。
