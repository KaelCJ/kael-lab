# 地图

## 当前实现（Current：源码接入，2026-10-27）

当前有四个可选战场，默认第一张为“DotA 经典战场”（`dota`）；赤沙废港、荧菌裂谷、蓝霜残骸继续可选。战场选择参与本地最佳波次和通关记录的区分。正常游戏固定使用现有像素画面，标题、HUD 和暂停页不再提供画面切换；工作台保留两主题观察。

经典战场采用 3600×3600 方形场地，按 DotA1 经典结构缩制：近卫位于左下、天灾位于右上，上中下三路连接两侧基地，斜向浅河划分两片野区。玩家从近卫侧出生，归一化位置为 `(0.23, 0.79)`。场地固定布置 22 座防御塔、12 处野怪营地、肉山点，以及基地、兵营、泉水与商店。它们目前都是可穿行布景，没有攻击、刷新、掉落、治疗、购买、占领或胜负效果；肉山布景也不等于第 20 波实际生成的首领。敌潮仍按本作生存规则在玩家周围生成，不从这些固定营地出怪。

经典战场的浅河可通行，树石继续阻挡角色、敌人与飞行弹。地表、三路、河道、建筑和固定点由 `../../static/dotarogue/js/dota-map.js` 的同一份坐标数据绘制；它是结构改编，不是某一版本原版地形、距离或建筑外形的精确复刻。选择卡的 80×80 Canvas 预览及左上角小地图也使用该模块，不引入外部运行图片。小地图位于波次信息下方，显示全图地形与固定点、黄色玩家点和白色当前视野框，仅用于显示；旧三图隐藏小地图。工作台可观察经典战场的全图和地表，受控预览不显示战斗 HUD 小地图。

旧三图保持 2600×1700，固定树石与河流定义归 `../../static/dotarogue/js/maps.js`。它们各有地砖、树、石头、河流、动态陷阱与选择预览六张原创像素 SVG，共 18 张；地面叠加固定材质斑、草簇或雪痕，圆弧河道带流向高光、河中石块、小鱼与外扩岸沿。河流视觉、移动碰撞和导航阻挡共用中心线与宽度数据；河流按线段胶囊范围阻挡角色和敌人，飞行弹可以越过。树图为 64×96、石图为 64×80，脚点保持原碰撞中心。

每次新建普通局或工作台演示局时，`game.js` 先按地图配置世界尺寸，再以 64 世界单位重算导航网格；经典图为 56×56，旧三图为 40×26。右键目标落入障碍时调整到可行走位置，路径受阻时使用导航网格绕行；敌人追击也复用流场与局部绕行。电弧链、法术场域和爆炸范围暂不受树石视线影响。

四图沿用相同的敌潮和动态陷阱生成、预警及伤害规则。动态陷阱按玩家周围位置生成，不是固定营地、建筑效果或静态障碍；旧三图使用各自陷阱图，经典图由 Canvas 回退绘制。实际行为以 `maps.js`、`dota-map.js` 和 `game.js` 为准。2026-10-27 已从真实入口复验默认经典图的桌面 1280×720、手机 390×844 与 844×390、小地图位置、旧图隐藏状态、工作台全图／地面细节和初版观察；控制台未见地图模块 error／warn，受控无脚本 iframe 读到基础说明与返回链接。桌面键盘／右键与触控长局、跨河路径绕行、真实手机硬件和后期波次仍未完整覆盖，范围最终回源[游戏 README](../../README.md)。
