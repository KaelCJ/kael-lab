# 地图

## 当前实现（Current：源码接入，2026-11-05）

当前有四个可选战场，默认第一张为“DotA 经典战场”（`dota`）；赤沙废港、荧菌裂谷、蓝霜残骸继续可选。战场选择参与本地最佳波次和通关记录的区分。正常游戏固定使用现有像素画面，标题、HUD 和暂停页不再提供画面切换；工作台保留两主题观察。

经典战场采用 3600×3600 方形场地，按 DotA1 经典结构缩制：近卫位于左下、天灾位于右上，上中下三路连接两侧基地，斜向浅河划分两片野区。玩家从近卫侧出生，归一化位置为 `(0.23, 0.79)`。场地固定布置22座防御塔、12处野怪营地和肉山巢穴，以及基地、兵营、泉水与商店。其中两处营地与肉山巢穴已在2026-11-05接入为红 Buff、蓝 Buff和固定肉山，剩余10处普通营地及建筑仍是可穿行布景，没有战斗、治疗、购买、占领或胜负效果。普通敌潮仍按本作生存规则在玩家周围生成，不从普通固定营地出怪；三个中立目标的状态与奖励见下节。

经典战场的浅河可通行，树石继续阻挡角色、敌人与飞行弹。地表、三路、河道、建筑和固定点由 `../../static/dotarogue/js/dota-map.js` 的同一份坐标数据绘制；它是结构改编，不是某一版本原版地形、距离或建筑外形的精确复刻。选择卡的 80×80 Canvas 预览及左上角小地图也使用该模块，不引入外部运行图片。小地图位于波次信息下方，显示全图地形、普通固定点与红蓝／肉山动态标记、黄色玩家点和白色当前视野框；红蓝／肉山标记按存活、交战、回巢和重生状态变化。旧三图隐藏小地图。工作台可观察经典战场的全图和地表，受控预览不显示战斗 HUD 小地图。

旧三图保持 2600×1700，固定树石与河流定义归 `../../static/dotarogue/js/maps.js`。它们各有地砖、树、石头、河流、动态陷阱与选择预览六张原创像素 SVG，共 18 张；地面叠加固定材质斑、草簇或雪痕，圆弧河道带流向高光、河中石块、小鱼与外扩岸沿。河流视觉、移动碰撞和导航阻挡共用中心线与宽度数据；河流按线段胶囊范围阻挡角色和敌人，飞行弹可以越过。树图为 64×96、石图为 64×80，脚点保持原碰撞中心。

每次新建普通局或工作台演示局时，`game.js` 先按地图配置世界尺寸，再以 64 世界单位重算导航网格；经典图为 56×56，旧三图为 40×26。右键目标落入障碍时调整到可行走位置，路径受阻时使用导航网格绕行；敌人追击也复用流场与局部绕行。电弧链、法术场域和爆炸范围暂不受树石视线影响。

2026-11-03 起，静态导航节点和已检查的相邻连通关系按地形数组、世界尺寸与半径缓存，同一解析目标复用流场，避免敌人每 0.35 秒重扫整图。新局、换图或工作台替换地形会失效；动态陷阱仍不进入静态障碍。小地图地表和当时的57个固定布景标记按输出尺寸缓存，玩家点和视野框实时绘制；2026-11-05的三个活动营地标记已退出静态缓存，按实际状态覆盖绘制。四地图的隔离对照与真实短流程范围见[游戏 README](../../README.md#手机加载与战斗性能current2026-11-03)，不代表长局或真实手机性能通过。

四图沿用相同的敌潮和动态陷阱生成、预警及伤害规则。动态陷阱按玩家周围位置生成，不是固定营地、建筑效果或静态障碍；旧三图使用各自陷阱图，经典图由 Canvas 回退绘制。实际行为以 `maps.js`、`dota-map.js` 和 `game.js` 为准。2026-10-27 已从真实入口复验默认经典图的桌面 1280×720、手机 390×844 与 844×390、小地图位置、旧图隐藏状态、工作台全图／地面细节和初版观察；控制台未见地图模块 error／warn，受控无脚本 iframe 读到基础说明与返回链接。桌面键盘／右键与触控长局、跨河路径绕行、真实手机硬件和后期波次仍未完整覆盖，范围最终回源[游戏 README](../../README.md)。

2026-11-04 起，运行时静态障碍按256世界单位建立空间粗筛，河流分段同时缓存；点、线段和飞弹碰撞先选候选，再按原地形顺序执行原精确算法。地形数组或世界尺寸变化时重建；边界、水体和相切规则不变，地表缓存仍为3600×3600。隔离等价与真实页面范围见[游戏README](../../README.md#加载与重复计算current2026-11-04)。

## 固定中立目标（Current：源码接入，2026-11-05）

首版只在 `dota` 经典战场启用一处红 Buff `(1332,2592)`、一处蓝 Buff `(1656,1260)` 和一处肉山 `(2340,1944)`，不把旧三张地图或工作台演示误标为已接入。红 Buff 与蓝 Buff 的活动边界为半径270，肉山为半径360；单位在边界内以小范围巡逻，进入警戒范围后追击玩家。红 Buff基础生命340、蓝 Buff基础生命380，红蓝击杀后90秒重生；生命生成时乘难度倍率并按该营地累计击杀次数每次加25%。肉山基础生命为14,000，首次挑战已经是中后期目标，基础重击伤害95，前摇0.95秒，半血后进入暴怒，移速、伤害与攻击节奏提高，同时释放210范围砸地和朝锁定方向的三枚巨石。肉山每次重生生命提高25%，所以前期挑战会承受极高风险。目标当前生命和存活／死亡状态跨波保留；波间只取消未完成的攻击前摇。所有持续和重生计时使用战斗时间，暂停、商店与波间界面都会冻结。

红 Buff 击杀赋予75秒红 Buff：普攻命中令目标灼烧3秒，每秒造成 `6 + 12%攻击力`，并减速20%，重复命中只刷新。两种守卫击杀同时各给18材料和12经验。蓝 Buff 击杀赋予75秒蓝 Buff：每秒额外回4法力，技能与法术装备冷却缩减增加15个百分点，总值仍封顶60%。肉山击杀赋予120秒肉山之力（所有伤害+20%），立即恢复全部生命和法力，获得200材料与3个待开奖励箱。以上奖励是本作改编，不复制原版完整掉落。

经典图第20波（远征和无尽）不在玩家附近另刷第二个肉山；经典图原巢穴中的同一肉山会满血觉醒并成为本波唯一终局目标。提前击杀普通状态肉山不会立即结束远征。建筑战斗与交互、兵线、推塔胜负、其他地图专属敌人、不同陷阱伤害效果和可破坏地形仍未实现。后续完整奇幻视觉主题也未制作；本轮经典地图的结构与布景不表示这些能力已经进入游戏。

营地数值归 `neutral-camp-defs.js`，限时奖励归 `jungle-buffs.js`，运行状态机归 `neutral-camps.js`，游戏与分类图鉴读取同一配置。本轮3,173项模块断言与66项生产函数断言共3,239项通过。真实选择入口已完成剑圣第一波自然击杀红守卫、75秒与18材料提示、HUD倒计时、重生1:29及暂停冻结；蓝守卫靠近交战、离界后闲置满血也已观察。一级满血59刚背兽前期挑战肉山出现重击预警后迅速战败，不据此推定精确实伤或无敌潮干扰。桌面1280×720、390×844和844×390代表画面已审阅，旧赤沙废港Q耗蓝与小地图隐藏、键盘焦点及禁脚本sandbox基础说明／返回链接也已检查。

控制台有来源未定位的`Object`错误；自然蓝 Buff击杀与效果计量、肉山击杀奖励／暴怒、全部语言英雄组合、完整20波、真机触控、长局和正式部署仍未覆盖。隔离断言不能代替这些未覆盖的自然流程。精确验证与产物统一回源[本轮报告](../../../.logs/actual-test/neutral-camps-20261105/report.md)。
