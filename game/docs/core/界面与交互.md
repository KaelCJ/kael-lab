本文件记录当前 HTML、CSS 和 JavaScript 提供的界面与操作。游戏选择入口是 [`game/static/index.html`](../../static/index.html)，游戏页面是 [`game/static/dotarogue/index.html`](../../static/dotarogue/index.html)，图鉴目录是 [`game/static/dotarogue/catalog.html`](../../static/dotarogue/catalog.html)；本次角色与装备首版的真实浏览器验收状态见[游戏 README](../../README.md#本次角色与装备首版的验证状态)。

## 暂停摘要与分类图鉴（Current：2026-11-05）

暂停只显示装备图标、名称、强化等级和成长简读；羁绊达到门槛才显示“风怒 2/4”等计数；Buff 保留图标、名称、品质、层数和薄葬次数。角色技能和装备／Buff 长说明不在暂停渲染。

标题与暂停入口前往 `catalog.html`，选择角色 `heroes.html`、武器 `equipment.html`、怪物 `enemies.html`、Buff `buffs.html` 后才加载该分类的数据与图标。图鉴目录不导入各类数据，不嵌入游戏或工作台。四页均有原生分类导航，角色／怪物／Buff 支持搜索；武器保留合成阶段、配方、三级强化与羁绊。商店配方链接直达武器页，暂停图鉴在新标签打开保留内存对局。

设计演示统一由 `studio.html` 负责，角色、特效等可通过分类／对象链接直达；图鉴的设计观察链接只在点击后进入工作台。完整入口和加载边界由[图鉴](图鉴.md)维护，实际验证范围见[本轮报告](../../../.logs/actual-test/catalog-split-20261105/report.md)。

## 页面流程

```text
游戏选择页 → 轻量标题与开局设置 → 对局加载 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落与通关补给 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 远征第 20 波胜利：回收与逐箱选择 → 通关结果
                              ├─ 无尽模式：第 20 波后继续进入下一波，直到战败 → 无尽记录结果
                              └─ 战败：失败结果
结果再来一局／暂停重开 → 对局加载 → 新局；暂停继续 → 对局加载 → 原局
结果／暂停 → 返回标题；标题 → 游戏选择页／分类图鉴 → 返回标题
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级；前 5 波材料包含通关补给，速战的材料收入折算补偿也计入补给，结算说明另列补给合计金额。完成前 5 波后的结算读秒为 2 秒，商店确认后的下一波读秒为 1 秒；完成第 6 波起分别为 3.5 秒和 3 秒。两种读秒均可用按钮提前继续。商店显示下一波编号，战败不执行波末回收或补给；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和补给规则详见[掉落与结算.md](掉落与结算.md)。

## 永久 Buff 品质（源码已接入）

永久 Buff 使用固定的四档品质：白色普通、蓝色稀有、紫色史诗、橙色传说。商店商品卡、商店已持有 Buff 列表与暂停 Buff 列表均显示品质文字、层数和对应颜色；商店持有区只在已有 Buff 时出现，独立图例、空态及限制说明已移除。品质文字跟随简体中文、繁体中文和 English 切换；无 JavaScript 说明也保留四档含义。

品质与购买层数分别显示，重复购买只累计层数，不提升品质；Buff 品质也不等同于装备基础等级或强化等级。当前 Buff 位按完成波次和幸运计算白／蓝／紫／橙概率，命中档内等概率选件；锁定保留品质与价格，购买不立即补货，刷新和新商店按当时幸运重抽未锁定或售罄位置。当前没有保底防重复，品质本身不改变基础价格。具体定义见[永久 Buff 设计](Buff设计.md)。

## 布局与画面

宽屏标题和暂停页使用分栏；战斗 HUD 在所有尺寸隐藏技能说明卡，暂停页查看当前战斗摘要，完整技能与资料在独立图鉴。手机竖屏战斗时收起装备栏，保留法力与主动按钮；商店按宽度排成两列或一列。经典图小地图保持在左上波次信息下方，按窄屏和低高度横屏缩小，不参与触控操作；应核对其与中央生命／法力区、左下摇杆及安全区域的间距。低高度横屏缩小弹窗和战斗按钮，触控设备保留摇杆。

正常游戏默认普通皮肤，标题与暂停页可切换 DotA1 模型角色；皮肤选择保存于原兼容键的 `settings.skin`，仅接受 `pixel`／`dota1`，缺失、无效或旧 `draft` 均回退普通。切换不重建对局，不改变位置、生命、法力、装备、碰撞或冷却。暂停页切换后焦点留在当前皮肤按钮，点击继续后进入独立 Loading，准备所选皮肤下当前英雄完整姿态与变身（含 TB 恶魔与炼金狂暴／过渡），完成后才恢复原局计时；关键图失败保留重试页或返回暂停换肤，取消保持原局生命、法力与时间。地图、敌人、界面和技能／装备特效继续使用现有画面。工作台仍可选择像素风或初版作受控观察，初版素材覆盖不完整，缺图时使用 Canvas 或符号回退。原有八名英雄每人有前视与独立右向侧身两套无 SMIL 的静态 SVG 运行帧，各 9 张：两张待机、两张步行、冲刺、攻击蓄力／出手／收势和技能姿态。灵魂守卫另有普通／恶魔两形态，每形态前视与侧身各 9 张，共 36 张；普通皮肤原有 180 张运行帧，炼金另增 30 张狂暴／过渡 SVG；DotA1 默认消费 210 张无损 WebP，并保留 210 张原字节模型 PNG 基线与失败回退，独立 Luna 月刃仍为 SVG。普通皮肤灵魂守卫普通／恶魔显示高度为 98／126 世界单位；DotA1 按已认可的模型显示参数、脚点及攻击锚点绘制，详见[来源契约](../sources/characters/dota1/README.md)，视觉体型不改变碰撞半径，魔影复用当前形态的半透明姿态。首版装备图标按[视觉规范.md](视觉规范.md)在两套主题中共用；分层 `hero.svg` 与 `side.svg` 是可编辑源图，不由战斗 Canvas 消费。战斗 Canvas 在移动、冲刺或攻击方向偏水平时选侧身帧，朝左镜像右向帧；其余角度使用前视。游戏时间和动作事件决定具体帧，远程角色有独立弹道，普通近战角色有职业基础武器和挥砍；DotA1 模型已有的武器不重复绘制，使用逐英雄短攻击反馈，技能使用独立施法姿态及 Canvas 特效；暂停时游戏时间停止。运行图尚无独立向上、向下或背面朝向帧、骨骼系统或完整八方向逐帧动画。
