## 页面流程

```text
游戏选择页 → 标题与开局设置 → 战斗 ↔ 暂停
                              ├─ 波末：回收地上掉落与通关补给 → 本波结算读秒 → 逐箱选择 → 待选升级 → 商店 → 下一波倒计时
                              ├─ 远征第 20 波胜利：回收与逐箱选择 → 通关结果
                              ├─ 无尽模式：第 20 波后继续进入下一波，直到战败 → 无尽记录结果
                              └─ 战败：失败结果
结果 → 再来一局／返回标题；标题 → 游戏选择页／装备图鉴 → 返回标题
```

没有待开宝箱或待选升级时会跳过对应界面。本波结算页显示击败、材料、待开宝箱和等级；前 5 波材料包含通关补给，速战的材料收入折算补偿也计入补给，结算说明另列补给合计金额。完成前 5 波后的结算读秒为 2 秒，商店确认后的下一波读秒为 1 秒；完成第 6 波起分别为 3.5 秒和 3 秒。两种读秒均可用按钮提前继续。商店显示下一波编号，战败不执行波末回收或补给；刷新页面不能续接当前对局。宝箱回血、80% 材料折算和补给规则详见[掉落与结算.md](掉落与结算.md)。

## 永久 Buff 品质（源码已接入）

永久 Buff 使用固定的四档品质：白色普通、蓝色稀有、紫色史诗、橙色传说。商店商品卡、商店已持有 Buff 列表与暂停 Buff 列表均显示品质文字和对应颜色；商店商品区另有四色图例。品质文字跟随简体中文、繁体中文和 English 切换；无 JavaScript 说明也保留四档含义。

品质与购买层数分别显示，重复购买只累计层数，不提升品质；Buff 品质也不等同于装备基础等级或强化等级。当前 Buff 位按完成波次和幸运计算白／蓝／紫／橙概率，命中档内等概率选件；锁定保留品质与价格，购买不立即补货，刷新和新商店按当时幸运重抽未锁定或售罄位置。当前没有保底防重复，品质本身不改变基础价格。具体定义见[永久 Buff 设计](Buff设计.md)。

品质抽取使用 `m=max(0,1+luck/100)`、`B=min(.6,max(0,w-1)×.06×m)`、`P=min(.25,max(0,w-3)×.02×m)`、`O=min(.08,max(0,w-7)×.0023×m)`，四档概率为 `1-B`、`B-P`、`P-O`、`O`；公式回源 [Shop](https://brotato.wiki.spellsandguns.com/Shop)／[Luck](https://brotato.wiki.spellsandguns.com/Luck)，参数为本作独立调节。

## 元素特效预览

标题页及无 JavaScript 说明中提供“元素特效预览”，规范地址为 [`game/static/dotarogue/effects.html`](../../static/dotarogue/effects.html)。该页为简体中文独立观察页，不继承对局或主题状态；默认陨石，原生单选项可切火、风，返回游戏标题或游戏列表。三者支持播放／暂停、重播、大图／小尺寸及三种衬底；火、风提供 60%–140% 强度，风独有旋向；陨石独有左右运动方向，无效控件隐藏且禁用。火、风小尺寸约 90px，陨石岩石主体约 50px，与战斗一致；陨石固定位置展示虚拟滚动，页面明确其没有伤害或碰撞。陨石与风标记已接入卡尔，独立火页仍为样张。

按钮、滑块和单选项支持键盘／触控。启用系统“减少动态效果”时默认静止；页面不可见后暂停并等待手动播放。元素切换保留暂停偏好、强度、衬底和尺寸，重置当前效果时间。选中元素未就绪时禁用调节和播放，元素选择仍可用；异步旧请求不覆盖当前选择，失败提供该元素重试。无 JavaScript 时隐藏空舞台与选择控件，保留解释和返回链接。

此页没有技能触发；风模块已用于卡尔混沌之风，火模块经陨石组合用于混沌陨石，被动自然抽到后主动回响可再次施放。暂停法术池三语言说明同步直线龙卷风与燃烧滚石。资源与调用责任见[通用战斗特效](通用战斗特效.md)，桌面、手机触控模拟、键盘与无 JavaScript 验证见[游戏 README](../../README.md)。

## 成品武器升阶界面（已接入源码）

2026-10-16 的合成交互已接入源码：商店顶部“即时合成与升阶”默认展示可执行目标及真实占格摘要，不足三件的升阶组折叠在“升阶进度与预览”；固定配方可预览结果、消耗材料与经过的中间路线。选定最终目标后一次完成当前材料可达的配方链，保留大炮／暗灭等共享材料的独立选择。全部配方默认折叠，展开后可合成优先、再按直接材料进度排序；商品的购买合成／升阶选项也需明确展开选择。宝箱可直接收下并合成，满格时还可先整理已有装备再收下，不先消耗待领奖励。

全部 48 件成品的升阶控制按同名同级集中为一份，显示实际持有件数、可升阶组数和展开预览；库存卡聚合并显示真实数量／占格，出售按钮每次只卖一件。预览以三件输入合计为基准，列出产物属性、被动、每组释放两个空位及当前角色有效暴击／闪避／冷缩；不足三件禁用，Lv.3 显示“已满级”。普通升阶一次一组，至少 6 件时另可批量升同一级，不自动把新产物继续跨级合并。鼠标、触控和 Tab／Enter 使用可见按钮及原生展开控件；每次入店回顶并聚焦合成摘要；操作后焦点回到摘要、同目标按钮或宝箱可用操作，视口跟随焦点，普通购买／刷新保留滚动。保留约 0.45 秒收拢／点亮反馈与可关闭合成音，减少动态效果时直接显示结果。新文案提供简体、繁体与 English，无 JavaScript 说明同步基础规则；当前源码接线和隔离检查不代表这些真实操作已全部实测，本轮证据与未覆盖范围回源游戏 README。

## 操作与状态反馈

| 设备 | 当前操作 |
| --- | --- |
| 桌面键盘 | WASD／方向键移动，Q 施放角色主动技，空格冲刺，Esc 暂停或继续。角色基础攻击自动进行。 |
| 桌面鼠标 | 右键指定目的地并绕开静态地形；左键临时指定瞄准点。手动移动或冲刺取消右键目的地；技能与冲刺也有可点击按钮。 |
| 手机触控 | 左下虚拟摇杆移动，右下主动技能与冲刺按钮；基础攻击自动进行。 |

主动技能同时要求冷却完成和蓝量足够。战斗界面显示法力条；技能按钮显示蓝耗和冷却，冷却结束但蓝不足时仍不可施放。成功施放才扣蓝和启动冷却；冲刺有独立冷却，不按角色主动技扣蓝。战斗、波次结算读秒和下一波读秒均可用 Esc 暂停；页面失焦或被隐藏时也会暂停这些状态。可操作按钮有键盘焦点样式。禁用 JavaScript 时页面提供基础玩法说明和返回游戏列表的链接。

界面默认简体中文（`zh-CN`），标题页可切换繁体中文（`zh-TW`）或 English（`en`）。语言继续写入兼容键 `kael-lab-starcore-survivor-v1.settings.locale`；改名后沿用旧存档，缺少语言字段时回退简体中文。切换语言重新渲染界面，不清除已有对局状态。商店属性摘要当前显示生命、攻击力、技能伤害、全伤害、攻速和护甲；暂停页还显示暴击、暴击伤害、闪避、普攻吸血、回血、拾取范围、基础攻击射程、法力回复和技能冷却等。普通攻击力、技能伤害、可成长攻击范围与独立暴击伤害已接入当前[属性规则](属性.md)；“攻击力”升级为 +4，Kael 选择它时另将风／陨石数量由 1→2→3 提升，装备或 Buff 攻击力不触发数量成长。

## 布局与画面

宽屏标题和暂停页使用分栏；战斗 HUD 在所有尺寸隐藏技能说明卡，暂停页查看全部技能。手机竖屏战斗时收起装备栏，保留法力与主动按钮；商店按宽度排成两列或一列。经典图小地图保持在左上波次信息下方，按窄屏和低高度横屏缩小，不参与触控操作；应核对其与中央生命／法力区、左下摇杆及安全区域的间距。低高度横屏缩小弹窗和战斗按钮，触控设备保留摇杆。

正常游戏默认普通皮肤，标题与暂停页可切换 DotA1 自绘风格角色；皮肤选择保存于原兼容键的 `settings.skin`，仅接受 `pixel`／`dota1`，缺失、无效或旧 `draft` 均回退普通。切换不重建对局，不改变位置、生命、法力、装备、碰撞或冷却。暂停页切换后焦点留在当前皮肤按钮，恢复战斗使用所选资源；缺图／加载中回退普通姿态。地图、敌人、界面和技能／装备特效继续使用现有画面。工作台仍可选择像素风或初版作受控观察，初版素材覆盖不完整，缺图时使用 Canvas 或符号回退。原有八名英雄每人有前视与独立右向侧身两套无 SMIL 的静态 SVG 运行帧，各 9 张：两张待机、两张步行、冲刺、攻击蓄力／出手／收势和技能姿态。灵魂守卫另有普通／恶魔两形态，每形态前视与侧身各 9 张，共 36 张；普通皮肤合计 180 张运行帧，DotA1 另有 180 张姿态帧和独立 Luna 月刃。灵魂守卫普通／恶魔显示高度为 98／126 世界单位，视觉体型不改变碰撞半径，魔影复用当前形态的半透明姿态。首版装备图标按[视觉规范.md](视觉规范.md)在两套主题中共用；分层 `hero.svg` 与 `side.svg` 是可编辑源图，不由战斗 Canvas 消费。战斗 Canvas 在移动、冲刺或攻击方向偏水平时选侧身帧，朝左镜像右向帧；其余角度使用前视。游戏时间和动作事件决定具体帧，远程角色有独立弹道，近战角色有职业基础武器和挥砍，技能使用独立施法姿态及 Canvas 特效；暂停时游戏时间停止。运行图尚无独立向上、向下或背面朝向帧、骨骼系统或完整八方向逐帧动画。
