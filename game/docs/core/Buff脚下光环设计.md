# Buff 脚下光环设计

状态：**Current：源码接入，2026-10-18**。本稿回应用户“部分 Buff 应像 DotA1 一样在角色下面显示光环，尤其是强袭光环”的要求。强袭与冰心已经接入 `game.js` 的共享地面绘制层，游戏战斗与 `game/static/dotarogue/studio.html` 设计台复用同一表现；外部会话示意仍只用于参考比较，不能代替自然获取或长局验收。

2026-10-27 玩法说明已同步[统一伤害契约](属性.md)：强袭增幅统一作用于范围内目标所受的未结算伤害；魔影复用同一数值入口，不再有独立的物理增幅例外。本次文档同步不扩大 2026-10-18 的视觉或自然流程验证范围。

## 当前问题与设计目标

当前永久 Buff 由 `../../static/dotarogue/js/buffs.js` 定义，商店和暂停能看到持有情况；强袭与冰心已有真实范围计算，`drawBuffAuras` 在地形之后、拾取物和角色之前绘制持续脚下纹章。辉耀仍有独立世界范围环，位于后置 `drawEffects`。玩家可以从角色脚下读出已持有的首批范围型 Buff。

采用 DotA1／Warcraft III 风格的贴地魔法光环：大而扁的冷白圆环，中心透空，外圈只有少量尖角，四方与对角线伸出短直刺；运动缓慢、线层稳定，亮度轻微呼吸。强袭以参考图的线环和径向刺为基线，保留少量本作盾甲切角作为识别点，不再画成厚重盾牌齿轮，也不把品质紫色直接当主色。具体线宽、配色和周期是本作设计，不能标成原版贴图复刻；参考来源和核实边界见文末。

原光环设计只改变信息表达。Buff 的来源、数值、品质、层数、范围、伤害与减速规则继续由当前玩法维护；不因视觉上称为光环，就增加友军属性共享或新的作用范围。

## 哪些效果画在脚下

首批常驻范围光环已经接入；其余小型身份纹仍是后续设计。

| 当前效果 | 当前玩法事实 | 当前／计划表现 |
| --- | --- | --- |
| 强袭光环 `assaultCuirass` | 每层攻速+12%、护甲+2；目标距玩家中心≤240时，未结算伤害每层增幅8%，最多40%；普攻、技能、装备、Buff、召唤和幻影共用此规则 | **当前接入**：常驻冷白多线圆环、八向短刺和少量外缘尖角 |
| 冰心 `shivasGuard` | 每层护甲+3；240内敌人移动和攻击冷却计时每层减慢8%，最多40% | **当前接入**：常驻冷蓝细线断环；只用少量冰色断点区分，不做晶体大块 |
| 耐久光环 `enduranceAura` | 每层只增加自身6%移速 | 琥珀三组静态追风箭纹；小型身份纹章，不暗示有范围加速 |
| 奥术光环 `arcaneAura` | 每层只增加自身回蓝1/秒、冷缩6% | 蓝紫四组静态符文短弧；不额外画回血或周期治疗 |
| 祭品 `vladmir` | 每层只增加自身吸血4%、护甲1、回蓝1/秒 | 暗紫静态獠牙／弯月纹；吸血只在实际回血事件强化，不画绿色治疗场 |
| 辉耀装备 `radiance` | 现有最高阶光环范围165／185／205，每秒伤害，由真实被动驱动 | 继续承担大范围灼烧语义，金橙稀疏炭火弧；改地面层时保留真实半径 |

嗜血术 `bloodlust` 使用短时脚下红橙双爪纹：只在波内 `elapsed % 10 < 5` 的真实生效窗口出现，离开窗口即停止。薄葬 `shallowGrave` 可在尚有保护次数时显示紧凑的紫色护符，消耗时由真实抵挡事件碎开；次数仍以暂停／状态文字为准，不围脚画无限数量的符号。这两项优先级低于首批常驻光环。

强袭由 `buffDamageAmp` 提供范围倍率，统一在 `combat-damage.js` 的未结算伤害入口应用一次；`damageTerrorbladeImage` 仅把魔影标记为召唤来源，不再单独调用光环增幅。已结算的弹射和反伤不重复放大。耐久／奥术／祭品的自身属性纹章保持静态，遵守[独立设计与预览](独立设计与预览.md)中纯属性Buff不虚构独立技能动画的边界。

树枝、热血战魂、龙族血统、活体护甲、奔腾、血怒、贪魔的贪婪、恩赐解脱、牺牲、疯狂面具、臂章、集中火力、风行、神之力量和狂战士之血，不因持有就各增加一整圈；保持属性／身份或真实受击、移动、低血、回复事件反馈。弹无虚发表现弹道；霜冻护甲表现实际来源敌人的减速；反击螺旋只在真实触发时表现150范围旋斩，不能画成常驻伤害光环。

## 强袭光环主方案

以约86世界单位高的普通英雄为基准：

- **落点**：使用玩家地面脚点 `(p.x, p.y + 14)`，与现有阴影对齐。人物起伏、攻击倾斜或跳跃不抬高纹章；Luna坐骑和TB恶魔也沿用地面锚点。
- **轮廓**：两到三条细同心线，外圈约八个方向有短直刺；外缘最多保留四到六个不连续三角／斜角标记，中心透明。径向刺和外缘角标固定在环上，避免整圈变成不断转动的齿轮或命中锯刃。
- **尺寸**：单环外半轴约54×23，内留空约30×13；主线宽1.5～2世界单位，径向刺长约9～14世界单位。尺寸是待真实战斗审图调整的起点，不代表实机已读得清。
- **颜色**：主线冷银白 `#dcefed`，高光近白 `#f4ffff`，阴影线蓝灰 `#6f95a2`，暗轮廓 `#263840`；不使用蓝紫大面积填色，不铺实心亮色圆盘。深浅地面用明暗双线保持轮廓。
- **运动**：只让一至两段短弧或线层以约10秒缓慢错相移动；径向刺和外缘角标不单独旋转。呼吸只轻调线条亮度，不缩放整圈、不快速闪烁、不产生升空粒子。
- **获得与重复购买**：首次进入战斗可用约0.25秒显现；重复购买不重播爆炸，不新增同心圆，已有纹章保持稳定。它是可无限购买层数的Buff，不用武器Lv.1～Lv.3体系。
- **战斗反馈**：符合强袭范围条件的实际未结算伤害命中时，目标身上可短亮一条冷白横纹；纹章本身不制造持续伤害，也不为已结算弹射或反伤追加一次增幅。

常驻纹章整体透明度建议0.35～0.55；它必须在无发光、无运动、灰度下仍能凭甲齿识别。暂停精确停在当前相位；减少动态效果时保留固定符纹，停扫光与呼吸。10秒周期和本稿尺寸／透明度均为本作起始参数，不是从原版测出的数据。

## 小纹章与实际范围分开

脚下椭圆只回答“角色持有什么效果”，它的54×23不是强袭或冰心的判定范围。240作用范围继续以 `(p.x, p.y)` 为中心计算真实世界圆，不能跟脚点偏移，也不能压成椭圆。

普通战斗不同时铺两张半径240的有色圆盘。首版优先用小纹章表达持有、用实际命中／减速反馈表达目标受影响；若工作台或后续暂停查看需要显示范围，用细弱真实圆表示，强袭与冰心同半径时共用一条边界，区别由小纹章和文字承担。范围提示不得伪装成当前已经有的控件。

辉耀的灼烧范围保留真实半径与圆形几何；主体不改成脚下54单位小环。装饰火星可在边缘附近运动，不能让一个不断涨缩的粗圆被误认为准确伤害边界。

## 多光环共存

同类Buff无论多少层只画一份，叠层数与有效上限由现有面板说明。不同效果最多保留**两套完整纹章**：优先强袭、冰心，其次祭品、奥术、耐久；这个优先级只管理绘制，不影响任何效果。

只有一种时使用标准环带；两种时，主纹约52×22、次纹约64×28，间隔留清楚。超过两种的剩余光环压成前侧固定槽中的小型身份纹：祭品獠牙、奥术四角符、耐久双箭。它们仍可见，不再各叠一整圈，也不每隔几秒轮换隐藏效果。三种辅助纹各占固定位置，缺少的槽留空。

辉耀属于独立世界场域，不占脚下完整纹章名额；短时嗜血只在前弧显示爪形亮片，不再扩大半径。敌人预警、血条、投射物与拾取物优先。手机继续保留两种主要轮廓及辅助符号，先省略扫光和细刻线；不靠无限加亮补小尺寸辨识。

## 拟接线与所有权

当前 `drawCombat` 先画地面，再由 `drawBuffAuras` 绘制首批脚下纹章，之后画拾取物、按纵坐标排序的地物／角色，随后画危险提示、弹丸和特效。两主题共用此调用。现有英雄阴影与身体照常压在纹章上，前景树石自然遮挡；危险提示继续在其后绘制，始终清楚。不要把纹章放到 `drawEffects` 的末尾盖住角色。

现有炼金狂暴与撒旦在 `drawEffects` 内已有脚下椭圆和上升粒子；实施时清点该真实条件态，安排为短时强调层，不与同一来源的新地面纹章重复绘制。本稿不把它们或嗜血术混为同一增益。

游戏私有绘制模块只接受调用者提供的地面点、实际Buff层数／有效条件、游戏时间、主题及减动效标志；只画形状，保存并恢复Canvas状态。调用者负责状态与生命周期，不在绘制模块内计算伤害、选敌、消费Buff、启动独立战斗时钟或使用战斗随机数。是否拆出新文件由实际首批实现决定，不预建光环引擎或所有Buff注册表。

工作台的现有 Buff 分类直接消费同一绘制。持有层数控制沿用既有控件，受影响范围与场景说明同步；不保留一套仅在示意中好看的独立生产画法。当前 Buff 预览目标都在240内，且 `tickStudio` 不运行 `updateEnemies`，不能据工作台宣称冰心真实减速已验证；仍需增加边界内外目标或另做自然流程核对。当前 Buff 默认循环8秒，嗜血完整周期需另明确延长观察方式，不改正式5／10秒窗口。

## 实施顺序与验收门槛

1. 已实现强袭与冰心的脚下轮廓，保留真实数值和事件链；工作台可选一层或多层观察。下一步以剑圣、Luna、TB恶魔核对普通脚型、坐骑和大翼型，再扩大到其他身份纹。
2. 接入耐久、奥术和祭品及辅助槽，核对一层／多层／五类同持不复制环；再处理辉耀与纹章的地面层关系。短时嗜血和薄葬作为后续同方案扩展。
3. 从 `game/static/index.html` 正常进入、自然购入并进入战斗，记录实际取得的每个Buff；工作台能验证形态和层数，不能代替自然获得。重点看移动、受击、攻击、暂停恢复、切波与重开；没取得的Buff明确未自然验证。
4. 视觉检查覆盖像素／初版、沙地／草地／冻土、桌面与390×844／844×390模拟、前后朝向、三件进化武器共持、单／双／多环。静态看中心留白、脚点、前景和预警遮挡；连续画面看扫光、循环与暂停，不以单帧判断动画。
5. 单列逻辑检查：强袭／冰心按敌人中心距离≤240、不加敌人半径；强袭对普攻、技能、装备、Buff、召唤及幻影统一增幅一次，弹射／反伤不重复放大，TB魔影没有独立增幅路径；冰心与霜甲／冰眼取最强；辉耀沿用半径加敌人半径的命中边界；叠层上限、购买不新增玩法、嗜血真实窗口和薄葬真实次数。视觉层开关不能改变任何结算结果。

成本目标是单玩家最多两套完整纹章、三个辅助符号、每环不超过六组主体记号；时间函数确定、无逐帧创建特效对象。该数值只是设计预算，真实帧耗时、密集战斗、手机硬件和长局均未测，不能标为性能通过。

## 来源与产物状态

用户指定 DotA1 为视觉方向。公开参考：[Wildfire Games · Visual Auras](https://wildfiregames.com/forum/topic/26968-visual-auras/)，2019年的帖子明确标注示例来自 DotA 1 / Frozen Throne，并区分圣殿指环、强袭、二者叠加和受影响者。2026-10-18实际查看强袭GIF的三帧：冷白宽环贴地、两到三条细同心线、八向短直刺、少数外缘三角／斜角、中央基本通透。绿色细圈是选中标记，不纳入光环纹样。间隔画面可见亮度／线层变化，未测得精确旋向、速度或周期，未核对地图具体版本及游戏内模型资源映射；本稿不作相应断言。

该来源用于视觉观察，未提供可供本作再分发原游戏素材的明确许可。没有将GIF、贴图、模型或音频引入生产；参考截图只作为不提交的浏览器证据保存。本作将其提炼为冷白多线地环、八向短刺和透空中心，并另行设计少量角标、分型、时序与叠加规则，不把Dota2素材或记忆当成DotA1事实。

2026-10-18 的正式产物为 `game.js` 的共享绘制接入、本文及设计索引。会话内动态示意独立于正式游戏；临时脚本及观察材料留 `.tmp/aura-design-20261018/`，浏览器证据留 `.playwright-mcp/aura-design-20261018/`，均保留、不提交或删除。该轮未改变 Buff 规则、装备数值或结算逻辑，也未把受控工作台检查写成自然实战通过结论；2026-10-27 的通用增幅规则按本文开头和统一伤害工作项另行记录。
