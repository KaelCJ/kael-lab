# Life · 生活方向

生活是 Kael Lab 的第三个方向，当前从衣、食、住、行四份原创日常起步清单开始。独立入口为 [`life/static/index.html`](../static/index.html)，全站根首页的生活卡片和 `#life` 段提供入口；生活页可返回根 `index.html`。

## 当前内容与交互

页面延续根首页的米白网格、深绿文字和珊瑚橙重点，以四个主题卡片进入对应清单。内容围绕日常做决定之前需要确认的问题展开，不使用虚构价格、文章、来源或服务能力充当栏目内容。

- **衣**：穿着场景、已有搭配、舒适度与次日衣物准备。
- **食**：现有食材、用餐安排和采购准备。
- **住**：日常居家中需要记录、整理和改善的问题。
- **行**：出门前的时间、路线、随身物品和备用安排。

清单正文与复选框直接写在 HTML 中。原生 `details` 控件支持展开和收起，复选框支持逐项勾选；这些基础行为不依赖 JavaScript。`life/static/js/life.js` 增强勾选计数、重置和本机记忆；浏览器允许存储时，勾选保存在当前来源的 `localStorage` 中，不提供账号、服务端或跨设备同步。禁用 JavaScript 时不提供这些增强能力。

## 内容边界

当前已提供生活手帖页面和四主题起步清单。家与陪伴、食材价格记录、育儿及装修专题继续整理，未形成内容的主题只说明方向，不作为已上线知识库、比价工具、专业建议或 AI 服务呈现。后续专题须有可公开的内容与来源，再建立实际入口。

这些清单为本站原创的日常整理提示，不依赖实时数据或外部接口。页面不加载统计脚本、不引入第三方依赖，也不把用户参考截图复制为运行素材。

首屏生活桌插画为本页原创内联 SVG，无外部图片或字体依赖。页面采用系统 UI Sans 与 Mono 字体令牌；正文、标签、辅助说明分别使用 `body`（14/20）、`label`（13/18）、`caption`（12/16），舒展文字使用 `body-lg`（15/22）。Hero、分区标题、主题大字与说明标题采用本页独有的展示角色，不影响其他页面；中文优先使用系统可用字体，不依赖合成斜体。

## 文件与入口

- `life/static/index.html`：唯一生活首页与四主题清单正文。
- `life/static/css/life.css`：生活页专属样式。
- `life/static/js/life.js`：清单的浏览器端增强。
- `life/docs/`：内容边界、设计说明与验证方法，不承载浏览器运行依赖。

入口和资源使用相对路径，沿用根 [README](../../README.md) 的 GitHub Pages 项目子路径约定。新增的页面与运行资源归 `life/static/`，不创建根级生活 HTML、兼容跳转或旧链接。

## 本地预览与验证方法

在仓库根启动静态服务器后，访问 `http://localhost:4173/index.html#life`，通过生活入口进入 `life/static/index.html`；桌面预览工具的默认端口为 4187。每次页面变更都需从真实入口重新检查：

1. 在桌面与手机视口检查根首页生活入口、生活页首屏、四主题与清单，查看实际截图及文字、按钮的计算后样式，核对换行、对比度、遮挡、焦点和横向溢出。
2. 用主题卡片跳到四份清单，展开与收起内容，勾选后确认计数；刷新确认本机记忆，使用重置确认清单和保存状态一致。
3. 仅使用键盘完成导航、展开、勾选、重置和返回首页，检查可见焦点。
4. 禁用 JavaScript 后重新进入页面，确认正文、主题导航、原生展开控件与复选框仍可用；计数、保存和重置不属于无脚本验证范围。
5. 检查控制台、静态资源请求和 `/kael-lab/` 项目子路径下的根首页往返导航；浏览器验证不能由静态扫描替代。

引用变化后运行 `python -B -X utf8 scripts/check_static_paths.py`。暂存或提交前运行 `python -B -X utf8 scripts/check_workspace_hygiene.py`。此处登记验证方法，不作为本次浏览器已通过的结论；以实际验证记录为准。

正式页面与代码保留在上述归属目录；本机截图、测试脚本与验证记录沿用根 README 约定，不作为公开内容混入 `life/static/`，任务结束时清点保留与待清理项，不覆盖既有证据。
