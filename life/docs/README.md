# Life · 生活方向

生活方向是 Kael Lab 的日常资料入口。页面按层级组织：生活首页只做导航，食页承接采购参考，酸奶资料只在更深的三级页面出现。

## 当前入口层级

- [`life/static/index.html`](../static/index.html)：生活总入口，只展示当前可进入的主题，不直接展示单个商品或单价工具。
- [`life/static/food/index.html`](../static/food/index.html)：食 / 采购参考，说明比较价格和标签时采用的共同口径。
- [`life/static/food/yogurt.html`](../static/food/yogurt.html)：酸奶资料页，提供单价换算和奶类选购精要。

当前路径为：**生活 → 食 / 采购参考 → 酸奶**。后续增加衣、住、行或其他食品时，先在对应层级建立真实入口，再增加具体资料页；没有内容的方向不伪装成已上线服务。

## 酸奶资料页当前内容

- **单价换算**：输入整组到手总价、每份净含量（g）和份数，显示元/g与元/100g。金额可为0，克数必须大于0，份数必须为正整数；缺项不显示结果，非法输入给出就地提示。结果按最多六位有效数字显示。
- **奶怎么买**：分清产品类别；按统一的每100g／每100mL比较营养；依据保质期和保存要求决定购买量。

当前没有真实商品价格记录，不预填品牌、价格、更新时间或文章数量。后续价格条目须来自可公开的实际记录，并注明产品、总净含量、实付价格、日期及必要的购买条件。g与mL分别比较，不直接互换。

## 来源与实现

选购条目依据辽宁省卫健委公开文章《如何科学选购奶及奶制品？这几个误区要避开》（2025-06-03）：

<https://wsjk.ln.gov.cn/wsjk/jkln/jkzs/2025060311355430529/index.shtml>

本页用自己的简短表述整理产品区分、标签和储存要点；统一份量比较及单价公式属于数学换算。没有复制整篇文章、截图或机构视觉素材。来源链接仅在用户点击后访问，页面不主动请求外部资源。

页面继续使用米白、深绿与少量珊瑚色。生活首页和食页使用紧凑目录布局；酸奶页使用桌面双栏、手机单栏。文字角色为标题display-sm（24/32）、分区title（18/28）、正文body（14/20）、标签label（13/18）、辅助caption（12/16）；单价结果使用display（36/40）。沿用生活页既有UI Sans／Mono字体族令牌，数字通过tabular-nums对齐，不新增公共主题机制。

- `life/static/index.html`：生活总入口。
- `life/static/food/index.html`：食 / 采购参考二级入口。
- `life/static/food/yogurt.html`：酸奶三级资料页。
- `life/static/css/life.css`：生活入口、目录页和酸奶页共享样式。
- `life/static/js/life.js`：酸奶页浏览器内单价换算；不读写存储。
- `life/docs/`：内容、来源和验证说明，不承载运行依赖。

所有导航和正文直接写在HTML中，无脚本仍可阅读；酸奶输入区在JavaScript初始化后显示。页面不引入外部字体、依赖、统计或API。入口和资源均使用相对路径，支持GitHub Pages项目子路径。

## 验证方法

从根首页生活入口进入生活首页，再进入食页和酸奶页，检查层级、面包屑、返回链接和实际 URL。桌面与手机视口检查生活首页、食页和酸奶页的布局、截图、关键文字和焦点；酸奶页额外检查空值、有效结果、错误结果、键盘切换、来源链接与控制台。阻断脚本后确认生活首页、食页和酸奶页的标题、正文、面包屑与返回入口可读，明确这与浏览器原生禁用JavaScript的区别。

引用变化后运行 `python -B -X utf8 scripts/check_static_paths.py`，暂存或提交前运行 `python -B -X utf8 scripts/check_workspace_hygiene.py`。本机无python命令时使用python3。
