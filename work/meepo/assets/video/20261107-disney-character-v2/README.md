The castle photo is retained as a user-supplied scene reference for this experiment; it is not presented as an official park asset.

Three derived scene variants were created from the selected castle reference with Lanox Image 2. They preserve the same castle/time-of-day direction while providing wide plaza, elevated tower and low foreground viewpoints for video shot planning.
