# Character reference images

Two AI-generated historical costume reference sheets, published for the owner’s video-creation experiment and for importing these exact files into Seedance.

| File | Purpose |
| --- | --- |
| character-headed-reviewed-v2.png | Face close-up plus front, back and side full-body references |

Source: created with Lanox Image 2 using a user-supplied identity reference, then locally arranged and cleaned. The costume version was finished with local background repair. These are fictional costume studies, not historical photographs, endorsements or depictions of real events. Shoe fabric texture remains approximate.
